# 数据与地质图导出方案

日期：2026-10-18。状态：用户已确认执行；实施与验证记录见 `docs/progress/data-map-export.md`。

## 1. 目标与范围

交付两条明确的输出流程：

1. **导出数据**：导出导入原件、已经保存的生成/制作数据，以及制作某项成果实际使用的输入数据。
2. **导出地质图**：从当前图件、层位和版本生成包含地图与地质要素的正式图件，支持 PNG、PDF、SVG，并扩展 TIFF 图像输出。

两条流程可组合成成果交付包。导出清单、导出数据、导出图件分别命名；保存版本、导出、发布继续保持各自语义。未验证成果可以导出，随成果记录验证状态。

遵守 DESIGN.md、PALEO_QGIS_PLAN.md 和 UI_LAYER_PLAN.md。沿用现有原生 Qt/QGIS 界面、字体、主题、间距与通知通道。

## 3. 数据导出

### 3.1 三种操作

| 操作 | 输出内容 | 版本规则 |
| --- | --- | --- |
| 导出原始文件 | LAS、DAT、TXT、SEG-Y、Office 等已入库原件及必要配套文件 | 选择明确 RAW 版本，按字节复制，校验摘要；不从显示内容反推原件 |
| 导出当前成果数据 | 已保存的提取点、解释线面、栅格、预测/编图结果、数值表等 | 默认当前选中/显示的已保存版本，可选择历史版本；数据与版本一一对应 |
| 导出制作源数据 | 某项成果实际使用的输入版本，递归追溯到 RAW；可包含中间数据 | 固定历史输入版本，禁止用同资产最新版本替代历史输入 |

例如：导出 C6 单因素图的制作数据，可以同时取得该次提取的井点表、参与计算的约束线、计算结果及其上游井资料，另附参数、单位、输入版本和算法标识。

“制作源数据”的判定消费现有 catalog、生成证据、图斑解释证据及地图版本记录。计算输入、解释支持/约束/反驳、普通参考分别保留关系类型；仅供浏览的参考资料由用户选择是否附带。只有明确记录的关系才进入集合，缺失关系列为追溯缺口，不根据井名或文件名猜测。

### 3.2 格式与数据语义

| 数据类别 | 首选输出 | 规则 |
| --- | --- | --- |
| 任意已入库文件 | 保持原格式 | 原件/已生成文件直接复制；外链大文件流式读取，不加载整文件到内存 |
| 数值表、井点因子表、分类/统计表 | CSV（UTF-8）+ 字段/单位说明 | 导出真实数值、空值、井/实体 ID、层位和版本；与界面格式化字符串分离 |
| 空间矢量 | GeoPackage；可选 GeoJSON、Shapefile | 保留字段、几何、维度、CRS；GeoJSON 按标准输出经纬度，仅在坐标变换明确可用时提供 |
| 数值栅格 | GeoTIFF | 保留数值类型、波段、NoData、分辨率、CRS 与地理变换；默认使用数据值输出，不经颜色渲染 |
| 图层样式、版面 | QML、QPT | 作为可选配套；交付工程需要时输出相对路径 QGZ |

原格式复制与格式转换在界面明确区分。没有实际写出器的专业格式继续支持原格式复制，不承诺任意格式互转。Shapefile 提示字段名/类型等限制，并一并输出组成文件。GeoPackage 多子图层必须明确选择；当前图层导出默认只输出所选子图层，完整源文件复制则明确包含整个容器。

局部工程坐标原样保留并注明“未配准”，不伪造 EPSG 编号或经纬度。重投影、裁剪、重采样都是显式选项，参数随结果记录。

### 3.3 入口与结果

数据管理列表/右键提供“导出数据…”；生成成果列表提供“导出成果数据…”与“导出制作源数据…”。沿用现有列表与选择状态，支持单选、多选、按井/层位筛选。

执行前显示数据类型、具体版本、文件数、预计大小、目标目录及缺失项。输入关系扫描和大小统计走后台；界面仅消费结果。必要文件缺失或外链内容与版本留底摘要不符时，该项失败，不能标记为完整源数据包。

生成数据若只存在于未保存编辑缓冲区，明确提示先保存版本或选择导出临时快照；临时快照须标记未保存，不借用已有版本身份，也不回写 RAW。

## 4. 地质图导出

### 4.1 导出的内容

标准入口按当前图件种类、当前层位、选定版本与图层主题创建 QGIS 打印布局；已经设计的版面可以直接复用。单因素图读取实际因子名称与单位，沉积相图绑定实际相面及其分类，井位图绑定实际井点。

| 要素 | 内容和约束 |
| --- | --- |
| 主地图与图框 | 指定范围或比例尺、真实图层顺序、边界、标注、当前样式；遵守选定版本 |
| 图名与地质信息 | 工区、图名、层位/地质时代、因子及单位、版本 |
| 图例 | 使用同一渲染器的真实色块/纹理/符号；相→亚相→微相按显示层级聚合并保留父子关系 |
| 比例尺与方向 | 绑定主地图，随地图范围/旋转更新；未配准时标明工程网格方向，不冒称真北 |
| 坐标与网格 | 显示真实 CRS 和单位；局部坐标使用工程坐标注记，不能写作经纬度 |
| 图签 | 编制、审核、日期、数据来源、图件版本、验证状态；缺值留空或注明未填写 |
| 可选地质内容 | 井号及真实因子值、等值线/标注、断层、物源/方向/间隔线、研究区范围、位置插图、说明文字 |

复用现有井位图、单因素图、沉积相图模板与 A4/A3 横竖规格，自定义版面继续在已有设计器编辑。出图预览与最终输出使用同一布局快照，避免预览与输出读取不同版本。对分类图例较长、图签/标注溢出、无效图层给出明确提示；必要制图数据缺失按失败处理，可选图层缺失则在结果中明确列出。

### 4.2 输出参数

| 格式 | 定位 | 参数与限制 |
| --- | --- | --- |
| PNG | 汇报、插图、审阅 | 默认 300 DPI，可选 150/600 DPI；纸张决定像素大小，预估内存；支持透明背景 |
| PDF | 正式图件、打印 | 保留可用矢量内容；复杂符号/透明效果按 QGIS 规则处理，文字渲染方式可选；支持多页 |
| SVG | 后续矢量编辑 | 复用 QGIS SVG 输出；对不支持的效果提示可能栅格化；多页按文件清单输出 |
| TIFF 图像 | 高分辨率图件交付 | 使用 QGIS 图像导出路径；检测当前 Qt/QGIS 图像写出能力，缺少编码器时禁用并说明原因 |

图件 TIFF/PNG 是排版图像，与数值 GeoTIFF 分开命名。地理配准图像/world file 和 GeoPDF 作为高级选项，需验证实际后端能力、有效 CRS 和主参考地图；普通 PDF 出图不依赖 GeoPDF 能力。

单图先闭环，再把相同参数接入现有按层位批量与地图册流程。多页、多层位必须列出所有输出文件及每项状态。

## 5. QGIS 复用与架构落点

优先调用已 vendor 的 QGIS C++ SDK 和现有封装；遇到应用层代码才参考/适配同版本源码，保留来源与许可信息，不引入 `QgisApp` 单例或对 `libqgis_app` 的新依赖，不另建版面编辑器。

| 需求 | 复用点 | 放置位置 |
| --- | --- | --- |
| 矢量格式参数/保存 | QgsVectorLayerSaveAsDialog、QgsVectorFileWriter / 导出任务接口 | 原生参数对话框由视图承载；写出逻辑在 `src/qgis` |
| 栅格格式参数/保存 | QgsRasterLayerSaveAsDialog、QgsRasterPipe、QgsRasterFileWriter | 同上；确保数值路径不混入渲染色带 |
| 排版、元素、模板与出图 | QgsPrintLayout、QgsLayoutItem*、QgsLayoutExporter、现有 standardelements / layoutdesigner | `src/qgis` 实现，`src/ui/layout` 提供薄视图 |
| 版本选择、输入追溯、导出清单 | catalog / datagraph / 已有证据查询 | `src/catalog`、`src/services` 提供只读查询；供导出与追溯共用 |
| 原格式复制、配套文件、摘要、暂存文件 | 既有路径解析与文件服务；必要时补数据导出服务 | `src/io` / `src/services`，不含 QtWidgets |
| 计划、后台任务、取消、结果登记 | PaleoTaskService、既有快照/暂存/提交链 | `src/workflow`；UI 只发请求并展示进度与结果 |
| 界面接线 | 现有组装位置 | `src/app`，以及现有主窗薄接线；遵守分层检查，不新增非视图反向依赖 |

新增纯值类型可集中于 `src/domain/exportrequest.h`：导出种类、资产/版本 ID、范围、格式、文件集合、警告/失败。候选功能接口为 `DataExportWorkflow`、`MapExportRequest`，以实施时复用检查结果确定命名，避免增加平行入口。

本机 SDK 头文件可核实为 QGIS 4.2.2，superbuild 配方当前指向 4.2.3。实施按实际构建链接版本核对签名，不在本任务顺带升级 QGIS。公开文档只作能力参考。

## 6. 一致性、追溯与交付包

- 导出开始冻结工程会话、资产版本、地图内容/样式和导出参数；后台使用独立 QGIS 工程/图层，不跨线程操作活工程对象。
- 外链和受管文件使用已有安全路径解析；容器、配套文件和内存/编辑图层分别处理。GeoPackage 使用一致性快照/读取后写出，避免在写入中裸复制数据库主文件。
- 输出先落目标文件系统的暂存目录，校验回读成功再提交。多文件集合以独立批次目录提交；覆盖策略执行前明确，不在失败时留下冒充成功的半成品。
- 成功、部分成功、失败、取消分别返回；进度和取消复用任务中心，逐文件复制可中断。单次 QGIS 渲染调用按实际可取消边界处理，取消后的未提交输出清理。
- 地图成品沿用 OUTPUT 登记；原件导出只是版本的外部副本，记导出记录而不重复创建 RAW 资产。导出不改变 Published 状态。
- 原始/生成数据分别记录 SHA-256、源资产/版本、相对输出路径；转换输出另记源摘要、格式/参数、字段/单位、CRS/NoData、应用/QGIS 版本。
- 地图记录具体图件版本、版面/图层快照、全部输出文件及摘要。现有 `pdf_*` 字段和发布门先保兼容，通过通用导出记录扩展其他格式；不能把 PNG 登记成 PDF，也不能无迁移直接把 PNG 当作既有 PDF 发布条件。
- 来源不完整、参数/模型等未留档时明确标记追溯限制，不把“附有原始文件”宣称为“必然可复算”。远程底图记录来源和署名，离线瓦片打包不在本轮默认范围。

组合交付包使用相对路径，建议结构：

```text
<工区>_<层位>_<图件>_v<版本>_<批次>/
  maps/           # PNG / PDF / SVG / 图件 TIFF
  data/           # 当前成果：GPKG、数值 GeoTIFF、CSV 等
  sources/        # 可选：制作源数据；按版本区分并去重
  styles/         # 可选：QML
  layout/         # 可选：QPT、相对路径 QGZ
  metadata.json   # 文件/版本/摘要/参数/追溯关系/缺失项/验证状态
  README.txt      # 内容、字段、单位和使用说明
```

首轮交付目录形式；ZIP 封装排在完整数据和图件链闭环后，不成为大文件导出的前置条件。QGZ 只有在其声明的数据/样式/必要资源已收齐并重写路径后才标记为可独立打开。

## 7. 实施顺序与验收

| 阶段 | 工作 | 验收结果 |
| --- | --- | --- |
| E1 数据文件闭环 | 精确版本选择、原件/生成文件单选与批量复制、后台进度、取消、校验、导出报告 | LAS/DAT/SEG-Y 等字节一致；多文件资料完整；外链失效和磁盘失败有明确结果 |
| E2 制作数据与交换格式 | 现有血缘/证据查询复用、上游输入集合、CSV/GPKG/GeoTIFF 写出、字段/单位/坐标说明 | 历史成果找到历史输入；表/矢量/栅格可重新读取且数值正确；缺失依赖如实入账 |
| E3 标准地质图 | 修正固定厚度图 PDF 入口，绑定当前井位/因子/沉积相图及版本；统一 PNG/PDF/SVG 参数、保存位置、预览和登记；补 TIFF 能力探测 | 三类图各完成至少一组真实内容出图；地图、图例、比例尺、坐标、图签一致且可读 |
| E4 批量与组合交付 | 接现有按层位/地图册路径，输出数据+图件+制作源数据包，记录全部文件 | 多层位不串图、不串版本；多页文件齐全；取消/部分失败报告准确 |
| E5 回归与真实工区验收 | 定向自动化、分层检查、真实工程视觉检查、文档与使用说明 | 符合 DESIGN.md；无错误版本/数值/坐标；不修改原件和既有发布快照 |

每阶段完成后给出改动、验证结果及产物示例，再进入下一阶段；实施不自动合并分支。

### 测试重点

1. 原文件导出比对摘要；重复名称按 ID/版本消歧；缺失、篡改、同名目标、取消不产生假成功。
2. 数值导出回读：字段/行数/单位/空值、几何和 Z/M、坐标、栅格类型/NoData/分辨率；显式转换按约定误差验证。
3. 追溯：多父输入、历史版本、共享输入去重、悬空父版本、异常循环、解释证据关系与缺失来源。
4. 制图：复用/扩展 `tst_layoutexport`、`tst_standardelements`、`tst_layoutdesigner_full`、`tst_horizonbatchexport`；回读格式、页数和 DPI 像素，核查选中图层/版本和多文件清单。
5. 生命周期：导出中切换/关闭工程、数据变更、后台失败与登记失败，不误写其他工程；预览/导出不污染活工程样式。
6. 人工检查真实工程的中文字体、三级相图例及纹理、标注遮挡、长图例、图框网格和浅深主题；局部坐标与已配准工程各覆盖一例。

新增测试走 `add_paleo_test(... LIBS ...)`，执行 layering / layering_strict / layering_selftest；构建与测试并行度不超过 `-j8`。本轮为方案阶段，不把尚未执行的检查记为通过。
