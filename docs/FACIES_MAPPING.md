# 三级相编图与证据

在智能编图的「编图流程」页，先完成预测或单因素计算，再生成综合相图、
转相面并复制为编辑副本。历史结果与原始数据继续保持不可修改。

## 对照已有图件

勾选本层位的单因素图、测井相点或地震相栅格，点击「联动显示勾选的参考图」。
每个参考窗口与主图双向同步位置和范围，鼠标位置在另一幅图以十字标记显示。
窗口宽高不同时，QGIS 按各自视口比例调整范围，中心相同。不同 CRS 经
QGIS 坐标转换；取消「联动主图范围与光标」后可以独立查看。
「打开参考窗口」也提供同一功能。参考窗口保留自己的图件和层位，主图
切换层位不替换参考数据；关闭窗口会解除联动。

## 数据管理与单因素图

编图、预测和单因素图共用工程的数据目录和版本谱系。单因素页的「高级工具」
完成同步或异步计算后，新保存图件也会自动进入编图的同层位参考列表、证据
来源列表，无需重开工程。刷新保留已勾选的历史输入，不自动换成最新重算结果。

在编图的图件列表选择结果，点击「在数据管理中定位」，可以查看对应资产、
保存版本及来源谱系。工作副本定位到最近保存的图件版本。
在数据管理的数据属性区选择已保存的编图或单因素版本，点击
「在编图中联动参考」，会打开该版本的参考窗口并进入智能编图。该操作保留
主图的当前目标和正在进行的编辑，不切换主图层位；参考窗口可对照其他层位。

每个保存版本使用自己的图层标识和受管文件。单因素重算、制图工作场重算、
目录刷新或重开工程不会将旧版本的参考和证据悄悄换成新版本。图层同时记录
资产 ID 和保存版本 ID，保存工作副本后更新关联。

单因素分析场可以按现有阈值分类和融合流程进入编图；解释性制图工作场及
制图等值线可作为对照和证据来源，仍按现有约束禁止进入定量融合或相分类。

## 相 → 亚相 → 微相

分类表的每行是一个最细可用类别，填写相、亚相、微相三个字段。编码是该行
的稳定标识，父子关系由完整分类路径确定，同名亚相在不同相下不会混为一组。
已有结果使用生成时的分类快照；修改当前层位分类仅作用于后续新结果。

显示层级支持手动锁定和自动模式：

| 比例尺分母 | 自动显示 |
| --- | --- |
| > 8,000,000 | 相 |
| > 4,000,000 且 ≤ 8,000,000 | 亚相 |
| ≤ 4,000,000 | 微相 |

阈值、层级名称和锁定交互对应参考项目
`paleo_project/main/geo-viz-engine/.../canvas.py` 的 `_SCALE_THRESHOLDS`，
以及其 `facies_hierarchy_service.py` 的三层选项。

缺失某层数据时，先取最近的上级，再取最近的下级。例如「湖泊 / 空 / 空」在
三级都显示湖泊；「空 / 空 / 河道」在三级都显示河道。填充仅用于显示，源字段
保留空值。每组采用分类表中编码最小的成员的颜色、纹理，避免随着视野内成员
变化而跳色；同名但不同路径的图例补全路径。图例只列图件中实际存在的类别，
随层级、改类、撤销、重做和保存更新，未知编码统一显示「其他 / 未分类」。
测井点沿用统一点符号，文本名称随层级变化。

## 拓扑与编辑

三级相面由一套基础面分区表达，QGIS 在显示时按层级分类合并面边界
（`QgsMergedFeatureRenderer`），避免保存三套互相漂移的几何。
某个基础面的几何改变，会立即反映到它所在的微相、亚相和相的合并区域。

- 「编辑层级」与显示层级分开选择。相／亚相改类作用于选中父类的全部成员；
  目标树内存在同名下级时保留该解释，其余采用所选目标行的合法下级。
- 微相改类作用于选中要素，所属亚相和相由目标分类行同步更新。
- 「选中同级分类的全部面」按编辑层级扩展选区，便于整体查看、边界编辑和
  批量添加证据。相同分类的离散面也在同一组内。
- 编辑副本强制使用共边节点拓扑编辑；移动、加点和删点沿用现有拓扑工具。
  整形等其他工具的结果在提交前再检查。
- 提交编辑及保存版本前使用 QGIS/GEOS 覆盖验证检查无效几何、面重叠和
  共边节点不匹配。失败时保留编辑缓冲，可撤销、修复或放弃；不发布新版本。
  合法无数据区域可保留，不自动填充几何空洞。

每次父类改类、证据增删均为一个原生撤销命令。版本保存记录共享分区模型及
显示模式；QGIS 工程保存实时显示状态。版面主题跟随当前相图层级刷新，导出
使用当前显示样式，导出前可手动锁定所需层级。

## 手工解释证据

在画布选中编辑副本的要素，在「选中要素的解释证据」输入解释。上方的编辑
层级决定证据属于相、亚相或微相；可选择已有图件作为来源，也可纯手工记录。
要给整个相区添加证据，先用「选中同级分类的全部面」扩展选区。

证据记录内容、层级、解释时分类路径、UTC 时间和稳定 ID。选择图件来源时
引用其**已保存的不可变版本**，保存编图版本时将该来源加入版本谱系。
原图件工作缓冲中的未保存修改不会冒充来源版本。
证据存入要素的 `facies_evidence` JSON 字段，随 GeoPackage 快照持久化；
选中要素后可查看、移除、撤销或重做。相分类后续改变时，旧证据标为需复核，
保留原解释内容与当时分类，避免悄悄归给新类别。
