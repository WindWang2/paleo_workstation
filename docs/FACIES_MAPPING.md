# 统一三级分类契约（2026-10-17）

所有新预测和编图使用完整的“相 → 亚相 → 微相”体系。`facies_code` 是微相编码；
`facies`（要素字段 `facies_name`）、`subfacies`、`microfacies` 是该微相的完整路径。
井属性表对应 `facies`、`sub_facies`、`micro_facies`。相、亚相是父节点，不能作为
模型的最终输出。项目分类是归属真源，冻结到每份结果版本；内置模板只提供可编辑
的初始解释，不代表所有工区通用的沉积模式。

“维护微相”中的三级模板选择提供 43 条路径（原有 7 条，加 36 条可选扩充），
涵盖河流、湖泊、三角洲、滨海等环境。在分类表选中一行后，选择完整模板路径并
点击“应用所选微相及父级归属”，再保存分类；新行仍通过“新增微相”建立。
应用模板保留该行的项目编码，不把模板编码当作已有数据的分类编码。
默认分类仍为原有七类，新模板不会自动加入任何工程、预测输入或图例。
模板属于可编辑的解释起点，使用前应结合工区资料复核；历史大相继续落「未细分」，
不能凭模板自动指定为某个真实微相。

- 分类面板的“三级图例”树按相、亚相、微相展开，“维护微相”按叶节点维护。
- 每个编码和完整路径唯一；同名微相跨父级允许存在，模型须用完整路径消除歧义。
- 测井服务逐深度返回微相标签及置信度，客户端依据分类补齐父级；组合道显示三级。
  平面结果仍取当前地层累计厚度最大的微相，完整井段预测保存于测井结果缓存。
- 地震远端请求携带 `predictionLevel=micro_facies`、三级分类快照；本地 Mock
  的聚类类别同样映射至微相编码，并保留模拟/待复核标记。
- 未登记微相、父级标签、歧义名称必须先维护分类，不创建“同名父子”占位。
- 旧图件保留原快照；读取旧快照分类时自动迁入三级体系（微相可识别则用模板路径，
  相／亚相级落「未细分」，无法识别的落「其他／未归类」），展示不出现未定义相。
  新增预测与综合编图须先补齐当前分类；
  不自动把历史大相编码改成某个微相。

# 三级相编图与证据

在智能编图的「编图流程」页，先完成预测或单因素计算，再生成综合相图、
转相面并复制为编辑副本。历史结果与原始数据继续保持不可修改。

## 对照已有图件

勾选本层位的单因素图、测井相点或地震相栅格，点击「联动显示勾选的参考图」。
每个参考窗口与主图双向同步位置和范围，鼠标位置在另一幅图以十字标记显示。
窗口宽高不同时，QGIS 按各自视口比例调整范围，中心相同。不同 CRS 经
QGIS 坐标转换；取消「联动主图范围与光标」后可以独立查看。
「打开参考窗口」也提供同一功能。参考窗口保留自己的图件和层位，主图
切换层位不替换参考数据；关闭窗口会解除联动。

## 数据管理与单因素图

编图、预测和单因素图共用工程的数据目录和版本谱系。单因素页的「高级工具」
完成同步或异步计算后，新保存图件也会自动进入编图的同层位参考列表、证据
来源列表，无需重开工程。刷新保留已勾选的历史输入，不自动换成最新重算结果。

在编图的图件列表选择结果，点击「在数据管理中定位」，可以查看对应资产、
保存版本及来源谱系。工作副本定位到最近保存的图件版本。
在数据管理的数据属性区选择已保存的编图或单因素版本，点击
「在编图中联动参考」，会打开该版本的参考窗口并进入智能编图。该操作保留
主图的当前目标和正在进行的编辑，不切换主图层位；参考窗口可对照其他层位。

每个保存版本使用自己的图层标识和受管文件。单因素重算、制图工作场重算、
目录刷新或重开工程不会将旧版本的参考和证据悄悄换成新版本。图层同时记录
资产 ID 和保存版本 ID，保存工作副本后更新关联。

单因素分析场可以按现有阈值分类和融合流程进入编图；解释性制图工作场及
制图等值线可作为对照和证据来源，仍按现有约束禁止进入定量融合或相分类。

## 相 → 亚相 → 微相

分类表的每行是一个微相叶节点，必须填写相、亚相、微相三个字段。编码是该行
的稳定标识，父子关系由完整分类路径确定，同名亚相在不同相下不会混为一组。
已有结果使用生成时的分类快照；修改当前层位分类仅作用于后续新结果。

显示层级支持手动锁定和自动模式：

| 比例尺分母 | 自动显示 |
| --- | --- |
| > 250,000 | 相 |
| > 50,000 且 ≤ 250,000 | 亚相 |
| ≤ 50,000 | 微相 |

这两个值为默认比例尺分母，可在智能预测、单因素图、智能编图 ribbon 的
“相图显示 → 自动切换设置…”中修改；前一个值必须大于后一个值，且均大于零。
支持恢复默认、取消和确认保存，作为应用偏好在下次启动恢复；主图和已打开参考图
立即使用新阈值，不需要重新生成数据。原先 1:8,000,000 和 1:4,000,000 的阈值
仅适合更小比例尺概览，已不再作为默认值。

ribbon 的“自动／固定相／固定亚相／固定微相”作用于当前可见相图；下方显示当前
实际层级，与右侧参数面板同步。切到固定层级后，放大、缩小均保持该层级；
切回自动后恢复比例尺规则。没有可见相图时层级选择禁用，仍可设置自动阈值。
约束过程、约束源、单因素数值图和等值线等图件即使带有分类快照，也不作为
相图显示目标；选中它们时，ribbon 继续控制本层位可见的相图，参数面板的
显示层级选择禁用。当前选择属于其他层位或已超出图层显示比例尺时，也不作为目标。
既有单个相面的显示锁定继续优先；测井图件保留最终预测相显示。

历史结果缺失某层数据时，该层按「其他 / 未归类 / 未分类」路径归组显示，源字段
保留空值，不把相或亚相复制成微相。新结果发布前须补齐归属。
每组采用分类表中编码最小的成员的颜色、纹理，避免随着视野内成员
变化而跳色；同名但不同路径的图例补全路径。图例只列图件中实际存在的类别，
随层级、改类、撤销、重做和保存更新，未知编码统一显示「其他 / 未分类」。
测井点沿用统一点符号，文本名称随层级变化。

地图画布、QGIS 图层树、图件设计器和导出图例共用当前版本的三级归属，
按当前显示层级聚合，避免一个父类因包含多个微相而重复列出。
符号直接取实际渲染器：相面保留纹理，井点使用点符号，栅格使用纯色色块。
每个参考视图的“图例”按钮在地图下方展开可滚动的三级树，默认收起；
标题标明显示层级及 Mock，切换来源时清空旧图例。参考版本锁定显示层级时
图例保持该层级，自动模式才随本视图比例尺更新。

## 拓扑与编辑

三级相面由一套基础面分区表达，QGIS 在显示时按层级分类合并面边界
（`QgsMergedFeatureRenderer`），避免保存三套互相漂移的几何。
某个基础面的几何改变，会立即反映到它所在的微相、亚相和相的合并区域。

- 「编辑层级」与显示层级分开选择。相／亚相改类作用于选中父类的全部成员；
  目标树内存在同名下级时保留该解释，其余采用所选目标行的合法下级。
- 微相改类作用于选中要素，所属亚相和相由目标分类行同步更新。
- 「选中同级分类的全部面」按编辑层级扩展选区，便于整体查看、边界编辑和
  批量添加证据。相同分类的离散面也在同一组内。
- 编辑副本强制使用共边节点拓扑编辑；移动、加点和删点沿用现有拓扑工具。
  整形等其他工具的结果在提交前再检查。
- 提交编辑及保存版本前使用 QGIS/GEOS 覆盖验证检查无效几何、面重叠和
  共边节点不匹配。失败时保留编辑缓冲，可撤销、修复或放弃；不发布新版本。
  合法无数据区域可保留，不自动填充几何空洞。

每次父类改类、证据增删均为一个原生撤销命令。版本保存记录共享分区模型及
显示模式；QGIS 工程保存实时显示状态。版面主题跟随当前相图层级刷新，导出
使用当前显示样式，导出前可手动锁定所需层级。

## 手工解释证据

### 分割、新建、覆盖与合并

编辑条的“相面编辑”菜单提供以下操作，几何捕捉使用 QGIS 原生 CAD 与吸附。
“目标微相”下拉框列出该图件冻结分类中的完整三级路径，不读取其他层位的新分类。

- 分割：先选面，再画穿过面的折线。切开的各部分继承完整三级归属与值域；每块
  获得独立稳定身份，记录直接来源与根来源，继承证据需要复核。分割线与未选邻面
  的交点同步插入共边，切线未穿过面时无修改。
- 面内新建／覆盖绘制：先选择目标微相，再绘制多边形。新面填入覆盖区域，所有
  原面同步扣除该区域；剩余部分被分开时生成多个独立面。绘制限于原始有效覆盖，
  原来的无数据孔洞保留。完成后只选中新面，避免批量改类误改剩余原面。
- 合并：先选至少两个具有公共边界的相邻面。同一微相可保留原类；不同微相必须
  选择目标叶节点。仅属于相同相／亚相不构成自动合并理由，父级显示聚合继续保留
  内部微相分区。合并登记全部直接来源与根来源，全部来源证据进入待复核解释。

创建和改类同步相、亚相、微相属性。人工新面不沿用原预测置信度；改类后清除旧
类别的连续分级值域，避免人工解释仍被标注为原来的定量范围。同类同值域合并
可以保留区间，纯分割保留区间。几何与分类修改的证据引用保持不可变来源版本。
现有相界类型是要素级属性，新分割线与覆盖边界不会自动认定为断层、尖灭或相变。
受影响面的原相界类型、渐变带宽度和定量属性保存在直接来源记录中，新边界清空
旧类型并进入待复核状态；单纯共边插点保持原有地质边界语义。
多个来源的备注或测量属性不同时，新面不采用第一条来源的值；原属性逐面保存在
来源记录中，避免合并后伪造一个适用于整面的测量值或丢失其他来源的说明。

每次操作先验证几何，落入原生编辑缓冲后同步共边节点并立即检查覆盖拓扑。
失败整体撤销，成功一步撤销／重做，重做不生成新身份或重复追加审计。
工作副本版本冻结原始覆盖的 WKB，提交及保存版本时再次比较覆盖范围，误删
形成的新孔洞、越界和覆盖重叠均不能保存。合法的原始空白保持原样。
普通新增面复用覆盖绘制；普通删除、整面移动、独立整形和跨层拓扑在相面副本
上禁用，并提供替代入口。共边节点编辑继续可用。

保存编辑后再保存新图件版本；历史文件、来源版本和证据不被覆盖。重开工作副本
恢复同一覆盖约束与分类快照，显示层级和图例继续根据微相基础面聚合。

在画布选中编辑副本的要素，在「选中要素的解释证据」输入解释。上方的编辑
层级决定证据属于相、亚相或微相；可选择已有图件作为来源，也可纯手工记录。
要给整个相区添加证据，先用「选中同级分类的全部面」扩展选区。

证据记录内容、层级、解释时分类路径、UTC 时间和稳定 ID。选择图件来源时
引用其**已保存的不可变版本**，保存编图版本时将该来源加入版本谱系。
原图件工作缓冲中的未保存修改不会冒充来源版本。
证据存入要素的 `facies_evidence` JSON 字段，随 GeoPackage 快照持久化；
选中要素后可查看、移除、撤销或重做。相分类后续改变时，旧证据标为需复核，
保留原解释内容与当时分类，避免悄悄归给新类别。
