# 连井剖面、画布相标注与时深对齐

## 实施方案

1. 复用 SBM 地震引擎 ReadSection / SeismicTaskService 与现有 SeismicSectionCanvas。
   新增井序选择、地图任意折线拾取、逐井时深校正面板；入口覆盖数据、预测、单因素及智能编图。
2. 折线节点先通过地震道头拟合测网换算，再在每段分别将引擎距离（测网步长）转换为米。
   越界节点整条拒绝，不静默删除中间节点；绘制支持退格和 Esc。
3. 时深表保持源文件顺序，深度与 TWT 双向严格递增，不外推。
   TVD 分层只对 TVD 列，MD 曲线只对 MD 列；缺少对应列时不伪造时间。
   用户可按井启用常速近似或设置时间平移，近似状态可见。
4. 保存路线、层位、逐井校正和源版本依赖为 catalog 的不可变 section 版本；可恢复。
5. 相面/测井相点用 QGIS PAL 标注；选择隐藏、标识、相名或两者组合。
   属性缺失用“其他 / 未分类”，表达式直接读取当前属性，改相后同步。

## 坐标与显示契约

- 当前工程井口、地震头坐标及地图使用同一米制平面坐标，暂不自动推断或转换未知 CRS。
- 地震垂向仍是 TWT；公共深度尺是明确标注的常速参考，不能当作逐井校正后的深度迁移地震剖面。
- 井的曲线与分层按各自 TD 表定位；无表、无对应列或超范围留空。
- 井轨迹当前以井口投影竖线呈现；不是三维斜井轨迹重建。

## 验证

- 弯折、各向异性测网的距离/地图坐标换算。
- TD 严格单调校验、边界、正反换算、无外推。
- 多井独立平移、TVD/MD 区分、版本保存恢复。
- QGIS 文本标注表达式及缺失属性回退。
- 现有地震、编图、UI 与架构分层检查。

## 使用方式

- 数据、预测、单因素与智能编图页的「井震剖面 → 连井 / 时深对齐」打开设置；剖面自身也有「连井 / 时深」按钮。
- 勾选井，拖动或上下移动顺序，点击「按顺序生成连井剖面」。任意路线可选「地图绘制任意折线」：左键加点，退格撤回，右键完成，Esc 退出。
- 剖面「井与分层」菜单控制井、曲线、层位及井口偏距；点击剖面可定位地图。原有不带地震背景的连井曲线面板改名「测井对比」。
- 在设置中选井，查看原始 TD 样点，设置对齐方式/时间平移并应用。命名后「保存路线与对齐新版本」，恢复入口列出工程中的所有版本。
- 恢复时校验井源版本与活动地震体；源版本变更要求重新生成，避免用新数据冒充旧结果。当前记录路线和解释参数，未保存地震图像缓存。
- 三个编图页选择相面或测井相点，在图件操作下方选择文本标注方式并应用。样式偏好随工程保存；图层重新实例化时保持。

## 实现边界

目前使用井口在剖面折线上的最近投影位置，展示一条主要测井曲线（优先 GR）。没有进行斜井轨迹重建、自动波形相关标定或地震体深度迁移。TD 校正支持已有时深表与整体时间平移；新增/修改原始 TD 样点仍走数据导入。
