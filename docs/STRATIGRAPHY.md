# 原生地层对比

地层对比使用当前 Paleo 工程的工区数据服务，界面为原生井组、连井曲线和分层结果表。
输入、区域界面、三级／四级旋回、标准模板及运行记录保存为工区内的解释修订。

## 操作流程

1. 打开工程并导入井资料、时深关系及地震层位，在 Ribbon 的“地层对比”中打开视图。
2. 勾选参与对比的井。“加载井道图”可先查看 GR；“计算区域界面”自动选择唯一资料并执行时深优选。多个来源须明确选择，缺失项集中说明。
3. 在“更多设置与历史”中填写有依据的“项目约定”及“坐标与时深”设置；“选择输入资料”可指定 GR、时深、轨迹、人工三级／四级旋回道、组段道与层位面。来源声明和原始采样保留。
4. 检查区域界面，再“按统一模板划分”三级／四级旋回。所勾选井须与已加载井一致；可在更多设置中限制 E12、E3、E4 或全部段。
5. 在井道图上双击拾取深度，填写名称后“新增内部界线”。该深度须处于有明确顶底的区域段中；已有四级旋回时仅拆分所在旋回，共用一个端点对象并保留三级父级。
6. 点击界线或结果表选择对象。可在图上拖动，或填写精确 MD、名称、人工保护后“应用界线属性”。拉平 T70 等界面后，拾取和拖动仍换回真实 MD；一次拖动对应一次撤销。
7. “确认／采用候选”显式确认候选；“删除界线并合并相邻旋回”只允许同段、同三级父级的相邻四级旋回。区域界面和三级旋回端点不能按此方式删除。
8. 选中旋回维护名称、正／反方向。“编辑三级组合”按深度顺序给连续四级旋回指定同一组号和方向；0 表示无父级，不能跳过断开的端点，也不能仅修改级别数字来伪造层级。
9. 用“撤销／重做”复原界面、旋回和相关曲线状态。内部编辑使 CDMT 待重算；区域界面编辑使相邻段派生结果待重算，旧数组及初始深度保留。
10. 保存分层版本。需要用于后续井预测和单因素分析时，选择井并“应用分层到工程”。版本下拉明确选择要读取的方案及修订；保存后定位新修订，重读版本清除旧选择和属性。

## 高级计算及结果

人工标准模板、曲线形态分组、组别人工修订、井序和所选模板传播均沿用示例规则。
人工传播先逐井、逐段确认模板，优先推荐同组标准井，支持保留本段；
标准井默认保留原人工解释，不强制向整个井组应用同一模板。
井道图支持“全图”、显示深度范围及完整井组 PNG 导出（包含深度尺）。
算法参数随解释保存；修改参数后既有曲线标为历史结果，重算不会更改原始 GR。
端部外推、候选优选、统一模板数量／父子关系及分段重算使用 ZIP 的原始计算代码。
没有信号、资料歧义、来源约定冲突及人工方案冲突按原算法报告，不能静默补造结果。

“计算结果”查看完整曲线、质量标记、参数、来源及数值分页，并可导出完整 CSV。
费舍尔 CDMT 的轴为有序旋回序号，数值是厚度偏离平均值的累计量，单位米。
不能将该序号轴当作 MD 深度画到井道；MD 派生曲线则与原始 GR 按同一深度对齐。

## 数据与视图

保存的修订、输入快照及模板通过 Data_service 管理；重新打开工程读取已保存结果。
分析分层读口消费保存的地层划分，应用后更新当前工程的层位集合。
地层划分与沉积相分类各有对应语义：预测和相面编辑继续采用“相 → 亚相 → 微相”完整路径。

QGIS 作为工程常驻的中央地图视图。Ribbon 选择保留当前可视化内容；打开地层对比视图时
收起地图停靠面板，切回后恢复用户的面板可见意愿。

算法定义见 [Data_service 算法说明](../vendor/Data_service/docs/stratigraphy-algorithms.md)，
接入与验证记录见 [版本实现记录](progress/facies-stratigraphy-20261029.md)。
