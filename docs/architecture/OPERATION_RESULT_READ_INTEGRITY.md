# 操作结果分页的完整性与成本

`paleo.operation_read` 沿用 `paleo.operation.v2`、operation/port、十进制 offset、
base64 与最多 24 KiB 的原始页预算。每页认证返回字节属于 manifest 中完整 SHA-256
所标识的冻结工件。成功页附加：

```json
{"integrity":{"scope":"returned_bytes","artifactSha256":"<完整工件 SHA-256>"}}
```

调用者按同一 SHA 组装各页。这里认证实际返回范围；未请求区段的当前健康状态由完整
工件校验任务检查。尚未请求的区段损坏不会使已认证的其他区段变成错误数据；请求损坏
区段时失败且不返回部分字节。发布、恢复和提交凭证的整工件 SHA 校验保持原有流程。

## 可信索引

首次读取在 worker 内用同一个 `QFile` 顺序扫描，计算完整 SHA 和每个 64 KiB 块的
SHA。只有完整 SHA 匹配持久 manifest、形状匹配且未取消时，才在内存保留块摘要。
首个返回页直接从该扫描流捕获，避免校验后重新打开文件获取未经校验的数据。

后续页重新读取覆盖范围的完整块，逐块匹配可信摘要，从刚通过校验的同一缓冲区取出
返回字节。覆盖末块的 EOF 读取同样需要认证；空文件绑定 SHA-256(empty)。大小与文件
类型检查只是额外约束，同大小、恢复 mtime、路径替换仍需通过实际内容认证。

缓存身份包含 canonical 工程、document、epoch、可信 caller scope、operation、port、
路径、字节数及 SHA；字段按结构化值编码。每次请求仍授权并核对 managed/private
路径，warm cache 不绕过这些检查。损坏/失败的索引被淘汰，部分冷扫描不产生可信条目。
索引不持久化；进程重启或淘汰后重建，沿用现有日志和 manifest，无需迁移工程。

## 生命周期、线程与回收

每个 recovery owner 的索引最多 8 条，摘要预算 4 MiB；工件继续沿用 1 GiB 上限。
冷扫描前腾出预算，避免临时摘要突破上限。单个 reader 在 worker 中串行扫描/认证，
同键并发冷页共用第一次完整校验；等待锁时定期检查取消。串行化可能让热页排在其他
工件的冷扫描后，作为目前避免重复扫描和复杂并发状态的取舍。

document/epoch/工程切换、显式 host 失效或 owner 销毁使 reader 永久失效，后续使用新
实例。失效用原子标志及非阻塞 tryLock，owner 不等待磁盘 I/O。扫描和认证检查失效/
取消；最终 owner 回调再次核对 Read 效果、文档/epoch/工程、授权日志、manifest/
stagePlan 以及 reader 实例。旧页不会在新宿主交付，订阅者销毁后不回调。完成回调在
recovery owner 线程执行，单次连接随后释放请求和页缓冲。

索引只包含内存摘要，不创建文件或新磁盘 GC 根。现有 schema-v2 operation 持久引用
保留私有和 managed 工件目录，存储治理及最终 physical purge 继续核对引用。无需为
分页长期持有会阻塞写者的独占 `CatalogPurgeLease`；外部删除/替换仍在实际读取时检查。

## 成本与验收

令工件大小为 N，除冷扫描首个请求外，后续页覆盖的完整块字节之和为 C。
索引命中且未失效的一轮分页实际
读取量为 **N + C**（冷扫描已经捕获第一页，不重复读取它）。每页认证最多读取页长加
两侧不满块，不能把任意 1 字节随机页宣称为只读 1 字节。淘汰、重启、身份改变需要新的
完整扫描；未更改身份的续页不重复完整 SHA。

真实计数回归使用 32 MiB 文件与 24 KiB 页，共 1366 页：完整扫描 1 次、完整 SHA
33,554,432 字节，总读取/块 SHA 各 145,358,848 字节（138.625 MiB）。旧实现的重复
完整 SHA 单独需 45,835,354,112 字节（42.6875 GiB）；这组输入的应用层读取量为旧整
SHA 读取开销的约 1/315，总 SHA 处理字节为约 1/256。计数包含实际 QFile 读取与哈希，
不以墙钟或文件属性代替。

`tst_authenticatedartifactreader` 覆盖多页成本、跨块/末页/EOF/空文件、同大小同 mtime
篡改与替换、删除/截断/追加、坏 SHA、取消/失效、并发冷页、身份隔离和 LRU 上限。
`tst_capability_recovery` 覆盖实际分页/GC、返回范围、授权效果、取消、宿主变化、显式
失效、订阅者释放和 owner 线程交付。最终构建与回归证据见
[实施记录](../progress/operation-read-integrity-20261114.md)。
