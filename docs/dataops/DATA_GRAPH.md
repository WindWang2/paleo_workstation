# 多元数据管理：资料图谱

资料图谱是现有数据管理和文件预览的中央工作区。它消费同一 DataCatalog 和
数据管理 sidecar；不建立另一份目录，也不直接执行导入、删除、回滚或改关联。

## 入口与联动

- 数据管理 ribbon → 数据列表 → **资料图谱**。
- 单个文件资料的列表右键 → **查看资料关联图谱**。
- 文件预览标签右键 → **查看资料关联图谱**，携带正在预览的真实版本。
- 图中单击资料/版本/实体，定位现有数据树与属性区；井实体同时走地图选择信号。
- 双击资料或版本打开现有预览。双击类别/阶段分组展开资料。
- 详情区可定位数据管理、预览、打开文件所在目录、追溯成果。
- 图谱标签可以关闭、重新打开；工区切换关闭工作区、取消任务、丢弃旧结果。

## 视图与模型

1. **工区概览**：按资料类别及当前版本阶段聚合；一份资料可以属于多个类别，
   分组计数不能相加当作工区唯一资料总量。选类别、阶段或搜索后展开当前资料。
2. **资料关联**：选中实体、文件资产或指定版本的有界邻域；可包含历史版本。
3. **成果追溯**：沿有向边分别查询上下游。共享祖先的同级产物不会冒充下游。

节点是实体、资产、不可变版本、生成记录、分组、缺失/回收来源或待关联占位。
资料类别（测井/井、地震、辅助、框架、综合图件）与阶段
（RAW/INTERMEDIATE/DERIVED/OUTPUT）独立；外部链接与受管文件另行标注。

显式 entity_asset_links、version.assetId、parentVersionIds 是关系事实。
editBaseline / rollbackTo 独立显示为虚线参考关系，不改变目录过期传播语义。
已持久化的 `paleo_evidence_v1` 投影为生成记录，显示输入、模型、参数、支撑
及软件信息；它以成果版本 ID 为投影身份，不冒充独立的运行日志或任务中心 ID。
证据记录的输入版本与父版本取并集。早期未记录来源的版本如实提示。

软删、实体显示名、改写类型与标签，来自现有列表管理 store 的纯值快照。
移入回收清单的资料不显示于正常目录；仍被成果引用的来源以回收来源占位展示。
sidecar 变化独立使索引失效，不依赖 catalog mutationSeq 是否增长。

## 后台与性能

- `services/datagraph.*`：索引、分类、查询、布局、生成记录投影与诊断，纯值返回。
- `workflow/datagraphworkflow.*`：现有 JobRunner / PaleoTaskService，180 ms 合并请求。
- `ui/pages/datagraphpage.*`：Qt Graphics View 绘制与导航意图，复用主题 token。
- owner 线程取得 COW staging 目录快照和文件管理呈现快照；worker 不访问活目录。
- 关系索引按目录路径、mutationSeq 及呈现快照变化失效；隐藏图谱不重建。
- 构图、迭代 SCC 环诊断、子图查询和稳定分层/重心布局都在任务中心后台运行。
- 默认最多 200 节点、600 边、两层邻域，可调深度 1–6。完整目录索引在后台
   建立，画布不一次性绘制全工区。界面显示未展开数量与边预算截断信息。
- 遍历与布局检查取消；数据更新、筛选更新、关页、换工区均淘汰旧结果。
- 发布核对 owner、路径、请求代次和 mutationSeq；只读投影不写目录。
- 节点按 ID 复用，边集合有上限；保持用户缩放，只有“适配视图”主动 fit。
- 缩小时降低标签细节。缺失来源、待关联、过期和计算血缘环均有文字说明。
- 证据 JSON 在后台格式化，详情最多显示前 64K 字符；原版本证据保留完整内容。

此版过期状态沿用现有目录：只显示已写入的 stale。OUTPUT/INTERMEDIATE
尚未正式标记过期，不能由图谱自行把它们改成 stale。文件内容与缺失源文件的
检查继续使用现有预览和资料体检入口，图谱构建不会扫描整个工区的文件内容。
