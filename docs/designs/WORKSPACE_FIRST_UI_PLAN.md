**评审稿 · 2026-11-26**　[打开交互原型](../../prototype/workspace-first/index.html) · [离线原型包](../../prototype/Paleo-Workspace-Prototype.zip)（解压后双击 `index.html`）

地质师打开一张相面图，首先应当看清研究区、当前层段和成果版本。点到某个图斑之后，再看到该图斑的解释、支持井和可做的修改。建议以这条操作顺序重新分配主窗口空间。地图、井道、剖面、对比图和数据表各自占用同一个中央文档区；工具围绕正在看的资料出现。

本次交付为设计与交互评审。桌面壳以 `master@d555220e` 为基线；原始簇面、井预测赋相及人工版本的设计依赖已提交的 [PR #1118](https://github.com/WindWang2/paleo_workstation/pull/1118)。原型使用示例坐标、井和图斑。正式应用继续从当前工程目录与模型服务读取数据，D 盘工程及其文件沿用既有存储约定。

## 三、主要操作路径

1. **打开图件。** 在工区选择目标层段与图件。中央直接展示图面，图例和版本随已显示成果更新；浏览、平移与缩放不创建草稿。
2. **点一个图斑。** 地图标出轮廓，右栏显示图斑号、簇号、当前微相、来源版本及井证据。同簇不同图斑分别显示“本图斑支持井数”和“全簇支持井数”。无证据、分歧与无数据各有文字；原始簇图例使用簇号。
3. **调整解释。** 先选目标微相。默认范围是当前图斑，显式选择“整簇”才扩大范围。应用前显示受影响数量，并在地图上描亮相关图斑的边界。只读源通过创建人工工作副本继续；工程本身只读时提供查看与对照。正式版的分割、合并、共边节点和拓扑检查走既有矢量编辑链。
4. **保存新版本。** 修改后显示“未保存”，撤销作用于当前文档。解释说明可补写或后台生成，保存地质修改不依赖 Agent。写入成功后才更新版本标记；失败保留副本、已选图斑和重试入口。
5. **对照复核。** 主图显示当前解释，参考视图明确标出其成果类型、版本和层段。对比原始簇、井建议与人工版本时，参考图保持只读。范围和光标可联动或解除；两边使用各自的图例。关闭参考，继续原图斑的编辑。新增井预测可生成新的建议版本，已保存的人工版本仍可按原身份重开。

正式版把“激活文档”“地图选中要素”“编辑目标”“参考版本”作为四种独立状态。切换参考版本只刷新参考区，切换工具类别只刷新命令。切换正在写入的编辑目标、关闭草稿或关闭工程时，使用已有保存/保留或放弃/取消流程，依工作副本是否已持久化显示准确选项；取消操作回到原位置。打开只读项目时仍能对照、查看证据和复制坐标。[编辑方案](vector-editing-implementation-plan.md) · [参考与图件版本](../workflows/MAPPING_WORKBENCH.md)

## 四、五个工作流共用哪块工作区

| 工具页 | 首要操作面 | 右侧随对象出现的内容 | 可修改的对象与主要边界 |
| --- | --- | --- | --- |
| 01 数据管理 | 中央资料表、地图或文件预览；左侧搜索井、曲线、地震体和图件 | 当前资料的字段、来源、井筒归属和单位 | 原文件预览只读。显式导入或调整归属通过现有工作流提交，LAS 与 SEG-Y 沿用文件通道。 |
| 02 地层对比 | 连井曲线与界面图居中，需要时切换结果表 | 所选井、深度、界线名称与保护状态 | 拾取和拖动仅在解释状态生效；锁定界线维持保护。一次拖动可撤销一次，图表共享选中对象。 |
| 03 单井相分析 | 井道与当前井段居中，保留 MD 单位与选定深度窗 | 当前井段预测、曲线来源、分类和版本 | 原始井曲线只读；修订预测生成工作副本。切换页签保留深度与井道组合。 |
| 04 地震相分析 | 地震剖面、切片或簇图可成为活动文档 | 所选层段、体、聚类参数、井建议和覆盖范围 | 剖面浏览与原始簇只读；显式的拾取、预测及赋相分别受任务与项目权限控制。 |
| 05 古地理编图 | QGIS 地图居中，按需并排参考 | 当前图斑、支持井、分类和修改范围 | 人工副本支持改相与几何修订。单斑、整簇和拓扑编辑各自显示作用范围。 |

Agent 由用户从当前工作区打开，沿用会话面板的表格、引用、代码与工具结果。输入附带当前工程、层段、版本和只读状态的快照；写入时仍由宿主复核实际状态。查看回复与引用不切换地图；点击“定位”才跳转到对应井或图斑。关闭助手后回到原选择，普通编辑和文件导入入口可独立使用。[Agent 视图](../../src/ui/ai/aiassistdock_layout.cpp) · [导航适配](../../src/ui/paleomainwindow_agent_navigation.cpp)

## 六、验收方法

以下为正式 Qt 版本的**建议目标**。开发起点先在同一工程、同一版本、同一图面范围下采集旧版截图、画布尺寸与任务操作次数，再比较改版。HTML 预览与历史截图使用各自的窗口条件。

| 验收项 | 方法与达标条件 |
| --- | --- |
| 画面有多大 | 在 1440 × 900 逻辑客户区，用地图 viewport 面积除以整个主窗口客户区面积，独立记录两侧宽度及工具区高度。初次浏览、左栏开右栏合，目标 ≥65%；专注目标 ≥82%。展开双图时另记两幅 viewport 的尺寸；1440 宽时并排的每幅至少 400 × 300 逻辑像素。图例、工具等覆盖选中要素时，应可收起或重新定位。 |
| 小屏与 DPI | 分别在 1366 × 768 和 1920 × 1080 **物理分辨率**的 Windows 显示器测 100%、125%、150%，记录 Qt 实际逻辑客户区。空间不足时先折叠低频工具、可把参考改为同位置切换；键盘可到达显隐、保存及退出专注。重要按钮不截断，界面字号随系统缩放。 |
| 操作与上下文 | 从已打开的地图看到某图斑当前相与版本，只需一次点选。连续切换五类工具不改变范围、当前井深、选择或编辑目标。进入/退出专注各一次，恢复左右栏、浮动面板和当前工具。 |
| 地质语义与安全 | 在 D 盘独立测试工程中使用同簇两个图斑。单斑修改后另一个保持原值；整簇修改前后数量一致；平票/无井显示待赋相。叠加旧相图后分别激活原始簇与相面，图例正确切换。保存失败仍可重试，重开可分别找到原始、井建议和人工三个版本。 |
| 键盘与性能 | Ctrl+1…5 选工具、Ctrl+Tab 换文档、Ctrl+K 查命令。Esc 优先取消当前捕获或关闭弹层，随后才退出专注。Tab 顺序从文档工具到主体、检查器和返回入口，焦点可见。大工程打开详情按需取数；连续点选、关闭面板、切走工程时，旧结果不得覆盖新选择。缩放与编辑笔画不触发全图统计。 |

验收保留 Windows 原生浅深主题截图、DPI、逻辑尺寸、缩放倍率和操作录屏。复用 `tst_shell_chrome`、`tst_dockmanager`、`tst_mappingworkbench`、`tst_datapreview`、`tst_seismic_sectionui` 与快捷键回归；编译、串行运行相关测试和源码门禁后再进入原生交付。

## 七、怎样评审原型

打开 HY 三角洲演示工区的 T70–T72 / S1 微相图。可按下面的顺序走查。

| 试一次操作 | 观察结果 |
| --- | --- |
| 平移地图后记住一个井点，点击附近图斑 | 主图保留所在位置。右栏的图斑、簇号与井证据对应当前选区。 |
| 从当前微相改选“河口坝”或“席状砂”，先看单图斑，再看整簇范围 | 修改前可以辨认涉及的图斑数量；取消或撤销后仍能继续解释。 |
| 保存人工解释，打开“对照”并选择原始簇图 | 通过两幅图各自的标题与分类看出当前版和参考版。联动时，同一井点在两边可追踪。 |
| 进入“专注”，返回，再切换工具页与井道、剖面、资料表 | 展开或收起面板时仍认得原来的文档；切换工具类别和打开新文档有各自清楚的反馈。 |
