# 导入完整测井与补充曲线

在现有数据管理面板选择“导入测井数据”，多选文件；也可从“导入文件”或文件夹入口
批量导入。正常流程是选择文件、查看预览、确认导入。沿用原有拖入入口时使用同一批量确认表。

预览直接显示井名、曲线数量与名称、索引范围、单位和前五行采样。无歧义的数据不需填写
额外字段。内容明确声明的井名与工程中唯一同名井匹配时自动归入该井；已有近似名称或
多口同名井时必须选择。无井名的单曲线文件可选已有井，或选择新建并输入井名。
文件名不会自动决定所属井。手动覆盖内容井名时，确认表会显示归属差异。

完整 XML 与后来补充的 CSV 可以属于同一口井。现有井树的测井资产显示曲线数量与名称，
选择或双击后沿用现有预览与业务入口。同名但不同来源的曲线会分别保留并标明来源，
不覆盖已有值；不想导入某份数据时，取消该行勾选即可保留现有数据。相同字节的文件
再次导入会跳过。井与曲线的来源、版本等信息保留在已有属性和提示中。

## 支持范围

- LAS、DLIS、LIS 使用项目已有解析器，能力边界与原解析器一致。
- XML 支持 SpreadsheetML 工作簿内以“测井曲线”或“离散曲线”开头的工作表，
  不是通用 WITSML。井名可来自井名/井号列，或如“测井曲线-A1井”的表名。
  非曲线的地层、岩性等内容继续由已有综合柱状图查看器处理，不自动改写解释成果。
- CSV、TSV、TXT 使用 UTF-8，第一行是列名；CSV/TSV 支持引号单元格，不支持跨行引号。
  索引列必须明确为 MD、TVD、TVDSS、TIME、DEPTH、DEPT 或“深度”。
  单位可写为 `MD[m]`、`GR[API]`，井名可用 `# Well: A1` 或 WELL 列声明。

例如：

```text
# Well: A1
MD[m],RES[ohm.m]
1000,25
1000.5,27
1001,NA
```

原始文件和单位保持不变。不同来源可有不同采样间隔，不会在导入时插值或重采样。
同一 XML 的工作表需要相同轴基准和单位，输出按精确索引并集保留缺失位置。
空白、NA、NAN、NULL、-999.25、-9999 是缺失值；其他非法数字、重复或逆序索引、
列数不一致、混井会拒收并提示文件位置。文本/XML 上限为 64 MB、400 万单元格、256 列。

测井管理可保存不同轴的数据；要求 MD 的综合井图、预测、剖面、属性建模和交会不会
把 TIME/TVD/TVDSS 或未声明的深度冒充 MD。已知英尺会明确换算为米；新来源缺单位或
单位无法解释时，相关业务显示原因并跳过或拒绝该来源。`DEPTH[m]` 本身并不声明 MD，
需要 MD 业务时应由数据提供者确认后使用 `MD[m]`。

## 失败、取消与旧工程

预览不写入正式工程。确认后若源文件已变化，需要重新生成预览。批量中的坏文件会
逐行报告，其他有效文件可继续；提交失败或取消会丢弃本批未提交结果，不留下半口井。
导入过程中关闭确认框或取消本批任务会取消这一批，不影响其他排队的导入任务。

结果表保留失败原因和重试入口。修正源文件内容后重新选择文件生成预览；权限、空间或
临时写入问题可在解决后重试。未完成的文件提交在下次打开工程时核对恢复记录，
只清理未登记且摘要吻合的受管副本。若恢复证据有冲突，保留证据并提示处理，原件不覆盖。

没有数据库结构迁移，也不要求重新导入旧工程。旧的资产、版本和关联 ID 保持原样；
新导入仅在已有版本扩展字段保存曲线目录。旧版本缺少这些字段时按原路径读取，
仍可能需要较长的首次加载。旧未决关联继续使用现有属性关联操作，不会因重导相同文件
自动按文件名改挂。
