## 目标与约束

优先保证后台任务安全、数据完整、工程可重开，再完善跨页面操作与专业计算。
新增资料模式继续兼容旧格式、旧工程和新旧资料混用。

- 架构和分层沿用 [PALEO_QGIS_PLAN.md](../PALEO_QGIS_PLAN.md)、[AGENTS.md](../../AGENTS.md)。
  数据层解析与问答，功能层编排，视图发意图，GIS 能力使用 QGIS 封装。
- 视觉或交互改动前读取 [DESIGN.md](../../DESIGN.md)。本计划不新增视觉规范。
- 工作分支使用独立 worktree/build；依赖接线遵循 [BUILDING.md](../../BUILDING.md)。
  构建并行度不超过 8，Windows 本机测试串行。
- 基线只缩不涨。不能通过跳过测试、放宽阈值、补登违规基线或猜测 CRS/深度单位完成验收。
- 每批提交独立、范围可评审的 PR；合并按用户指令执行。

## 每批完成条件

1. 在 findings 中补充当前源码证据和待解决的问题，冻结本批输入、影响面与失败路径。
2. 完成实现与有意义的验证；按影响面选择测试，不以文档中的计划用例冒充运行记录。
3. 运行适用的源代码闸门；涉及 UI 时检查 DESIGN，涉及存储/格式时验证旧数据与工程重开。
4. 在 progress 中记录提交、命令、结果、未覆盖项；同步关闭或调整 TODOS 中对应条目。
5. 自审完整差异后提交 PR。只有验收满足且证据完整时才把任务标为完成。
