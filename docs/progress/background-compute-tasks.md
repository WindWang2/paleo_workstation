# 耗时操作后台执行与任务中心接入

分支：`codex/background-compute-tasks`，基线 `origin/master` 的 `5318c15a`。
本轮沿生产 UI 入口检查算法、编图、预览、验证、清理和出图的调用路径。

## 调整范围

| 入口 | 后台执行的工作 | 主线程保留的工作 |
| --- | --- | --- |
| 单因素、约束插值 | IDW、距离变换、等厚、结构插值、本地方向、克里金、SGS、协克里金、Surfer IDW；输出暂存、摘要与结构样本写入 | 参数与输入快照、目录登记、图层声明 |
| 编图页厚度链 | 逐井分层/TD 读取、厚度样本、网格 IDW、等厚栅格与井点写入、摘要 | 样本表展示、成果一次性登记与上图 |
| 综合编图/一致性检查 | 栅格合成、点到网格分类、井与相面/栅格比对、报告写入 | 输入快照、成果发布与报告展示 |
| 等值线 | GDAL 提线、结构线与解释性工作场、分析场摘要 | 参数、声明与图层挂载 |
| 栅格预览 | 概览统计、直方图、极值、剖面采样、预览等值线 | 样式应用、预览图层与图表展示 |
| 地图册/按层位出图 | 独立工程和版面重建、逐幅渲染、复制、摘要、私有目录 journal | 工程/版面快照、受控文件 rename、一次性 journal 提交 |
| 编图页 PDF/演化帧 | 独立版面渲染或 PNG 编码、复制、摘要 | 画布抓帧、快照、成果登记及发布门更新 |
| 工程验证 | 文件检查、井上时间残差、TD 读取 | 声明快照、验证表展示 |

| XML/Office/图片预览 | 私有副本、摘要、解析、图片解码 | 文档或图片展示 |
| 存储管理、回收站、图件删除 | 扫描、SHA 复验、目录健康检查、物理文件回收 | 确认、目录事务与列表更新 |
| 测井预测准备 | 使用任务服务的有界线程池准备输入 | 现有远端异步预测、聚合任务与结果发布 |

已有异步入口继续保留；原来使用全局线程池而没有任务记录的入口统一接入
`PaleoTaskService` 的有界池。预览任务使用 quiet 标记，仍进入任务列表，但不会
反复拉起任务中心。无任务服务的同步 API 保留给独立宿主和测试壳；正式组装根注入服务，
UI 调用异步入口。正式版面导出遇到不能隔离的图层时显示失败原因，不再自动前台渲染。

## 性能处理

- 栅格合成的井点最近邻改用一次构建的空间索引，避免每个像元遍历所有井点；
  等距点按要素 id 保持确定的选择顺序，未预测相不参与分类。
- 栅格统计与直方图使用有界缓存，键包含数据源、文件大小、修改时间及统计参数。
  选择或样式已变化的预览回包不覆盖新操作。
- 成果摘要在 worker 计算，发布时核对路径、大小和修改时间，再使用已有摘要；
  同文件系统暂存成果通过 rename 落位，避免主线程重复复制和读取大文件。
- 批量导出在私有目录副本上完成复制、摘要与 journal；主线程一次性提交目录，
  避免逐幅保存目录引发反复刷新。工程或目录代次变化时拒绝登记旧结果。
- 修正进度节流时间戳：只有实际发送进度时更新时间戳，连续高频报告不会永远被抑制。
  阶段进度可用于没有字节总量的任务；任务面板合并刷新事件。

以上是调用路径与复杂度层面的优化，本轮没有测量真实工区的加速倍数或交互延迟。

## 线程、取消与发布

worker 使用不可变声明、矢量 feature source、目录副本或独立重建的 QGIS 对象；
不修改主线程工程。Processing 的坐标变换上下文由 owner 更新为受保护的值快照，
worker 不读取正在切换的活工程。

任务记录覆盖进度、错误、取消和终态。发布失败会把任务标为失败，过期成果会标为取消。
循环或 GDAL 回调中的取消可提前结束计算；单次不支持中断的渲染/底层调用在返回后检查
取消，批量导出在版与版之间检查取消，已完成的版保留账目。

页面销毁和工程切换取消读取/计算任务，暂存数据由作业状态清理。目录已经提交的物理
回收阶段不能取消；独立观察器确保关闭页面后仍按实际完成情况更新任务终态。

GUI/QGIS 要求所属线程执行的图层实例化、界面绘制、编辑、快照和短目录事务保留在
主线程；将活工程、活版面直接传进后台执行不属于本轮方案。
