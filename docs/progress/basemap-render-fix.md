# 网络底图显示链路修复（2026-10-21）

用户在主菜单和预览下拉都看不到网络底图。瓦片端点和独立 provider 读取
不足以验收：实际预览 TOC 会把新增的底图当作分析栅格，按全球范围启动
波段统计和直方图；没有任务服务时同步阻塞，有任务服务时也会产生大量
与当前视野无关的瓦片请求。回归探针复现了持续扫描和大量 GDAL 错误。

修复：

- TOC 对 `paleoBasemap` 保留原生图像渲染，不启动统计和伪彩拉伸。
- 预览选择新底图时暂时隐藏已有背景，并同步 TOC；移除选择恢复先前显隐，
  不改变地质层。切换失败保留当前可用底图。
- 文件菜单在地图预览可见时交给当前预览处理，避免仅修改隐藏的主画布；
  其余地图工作区仍通过 QGIS 工程图层树处理。
- 自定义 XYZ 复用预设的 QGIS WMS/GDAL provider 回退及错误传递；
  GDAL TMS 图层也采用在线底图的工程坐标门控。

验证使用真实预览组件与修复源码，链接本机同版本依赖和已有未改模块。
新增 `tst_basemap_rendering`：检查底图入 TOC 不创建统计任务、实际输出
瓦片颜色、背景互斥与恢复、失败保留、当前可见预览路由。夹具全部本地生成，
不依赖互联网。另运行既有 `tst_wellbasemap` 与 `tst_onlinebasemap`。

本机真实工程只读接入完整主窗口探针：主菜单选择 Esri 影像能出图；
修复后预览在不透明离线底图存在时也能显示同一区域影像，探针正常退出。
源码闸门保持基线不增长；独立构建链接修复版应用供本机复验。

以上联网结果代表本机当时线路；不据此承诺所有大陆运营商或所有预设永久可达。
