# 岩心照片放大与分层沉积相命名（2026-10-21）

对应反馈 16、17。独立 worktree，基线 master `07193ce9`。

## 照片放大

- 综合柱状图图片道内双击照片，或右键选择“放大查看照片…”，通过画布意图信号由面板打开原生非模态查看窗口。
- 绘制和命中共用 ImageTrack::imageRect：点锚、井段照片、等比留白、横向滚动、部分裁切均使用同一几何，重叠时优先后绘制照片。锚点在视口外但照片可见时仍可查看。
- 窗口显示井名、照片名和深度，提供放大/缩小/适应窗口/原始大小（100%），滚轮缩放和左键拖动；不修改井道比例、照片锚深或任何原件。
- 缩略图先显示，复用 imagelod 服务后台按需读取单张原图（含 EXIF 方向）。工作线程只返回 QImage，GUI 线程生成 QPixmap。关闭/销毁窗口后，QPointer 丢弃过期完成通知。
- 没有原件或解码失败时说明实际状态，不把缩略图标成原图；原始大小入口在原图可用后启用。原生控件与间距/字体遵循 DESIGN.md，工具行窄窗可滚动。

## 术语与表格一致性

“分层沉积相属性”说明表的实际组织方式：每井每地层单元（组/段）一行，保存沉积相三级路径及厚度汇总，不另造“地层相”类别。预测页与井道入口、表名、提示、错误文案及操作说明统一。

- `dominant_facies` → 分层解释微相；`predicted_dominant` → 分层预测微相。二者原有的解释修订/模型结果保留规则不变。
- `dominant_thickness_md` → 最大累计厚度；`dominant_ratio` → 最大厚度占比（分母为已分类厚度）；`coverage` → 已分类厚度覆盖率（分母为地层厚度）；并列与厚度构成明确为统计含义。
- 核对了预测写入和人工相段解释保存两条路径：两者都可更新汇总统计，直接改解释文字不重算厚度。不能把这些统计一概标成“预测厚度”。
- 打开旧表时刷新显示名称与别名（只读工程同样刷新内存显示），持久字段、GeoPackage 路径、图层 ID、统计算法与数据内容保持兼容。
- 术语参考见 docs/WELL_VECTOR_ATTRIBUTES.md 的 SLB facies / formation 定义链接；名称以实际数据语义为依据。
