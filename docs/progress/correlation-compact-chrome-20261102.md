# 地层对比井柱的紧凑显示

- 对比井柱显式使用 `Comparison` 模式。每口井只有一行常用显示操作和一行比例尺、视口及隐藏道菜单，不显示额外读数、预测状态和隐藏道 chip 行。
- 对比面板不创建井相预测工作流，也不订阅全局分析层段，避免模型就绪度或缺父层段记录干扰界线编辑。整井预览和单井相分析维持原有独立口径。
- 主操作保持一行；全图入口保留，详细范围及整幅导出放入默认折叠的更多设置。界线列表按需展开，默认将空间留给井道图。
- 工作流加载 MD 井柱时返回简短成功摘要。原始时深、测斜及空间定位诊断仍完整保存在输入快照和解释文档中，由资料与计算诊断查看；不自动选时深或确认直井。
- 页面状态单行显示，完整消息留在提示中。任务错误仍直接反馈，不把失败显示成成功。

验证包含无时深井的加载和手工界线编辑、对比井柱不创建预测服务、上下单行几何约束、界线列表开关、更多设置中的范围入口，以及既有拉平、拖动、撤销、导出、保存与重开回归。测试使用临时合成工区，不改用户工区。
