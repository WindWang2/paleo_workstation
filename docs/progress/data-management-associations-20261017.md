# 文件归属、资料知识图谱与井位导航

## 操作

- 文件列表中右键单个文件，选择“调整资料归属（井 / 地震）”。可选择目标井或地震测区，再选择该对象允许的资料用途（测井、分层、轨迹、时深、地震体、层位、断层等）。
- “添加补充资料”保留现任主文件；尚无主文件时首份资料补为主文件。“替换此用途的主文件”显式切换当前主文件，旧资料及历史版本保留。
- “更改已有归属或用途”只修改用户选择的一条关联，可把文件从原井/测区及用途调整到另一个对象及用途。其他关联保留。重复添加不会重复建边。
- 编辑器保持打开时，目录或工程发生变化，保存会拒绝过期操作，需重新打开编辑器。保存提交后刷新实体、图谱与已打开的该文件预览；旧关联身份对应的会话撤销栈清空。

## 图谱

默认“资料知识图谱”直接展示井/地震测区集合及其关联文件，集合标明去重后的资料数量，连线标明资料用途及主文件状态。共享文件仍只有一个文件节点，可连接多个集合。双击集合展开关联，双击文件打开预览。

集合用椭圆、文件用矩形表示，采用有界且确定的网络布局并避让标签卡。分类统计概览、版本血缘和下游影响仍保留；版本血缘继续使用有向列布局。关系只来自目录或已记录的证据，不推测井与测区之间的关系。查询沿用节点、边与后台任务上限；按集合名称搜索时包含其关联文件。

图谱导出增加明确的 `entity_type` 与 `member_count`，集合不是某个文件的别名。

## 地图导航

测区全景及井位预览点保留 `entity_id`，单击井位按唯一标识定位并打开该井的主资料。无文件的井仍可在井属性区查看。漫游拖动、空白点击、量测与剖面工具不会触发井导航。重叠井位提供选择菜单，避免依赖同名井或任意第一条命中。

关联变更复用目录事务、增量落盘与后台导入日志：`updateLink` 原子修改一条关联，处理同一用途的主关联冲突，失败回滚。数据查询和布局在服务层，变更编排在功能层，QGIS 拾取在封装层，视图只接收和发送操作意图。
