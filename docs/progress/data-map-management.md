# 数据管理：删除与现有图三级整理

- 数据列表搜索行下方提供独立操作行，常驻删除、三级相整理和可回收清单按钮，复用可撤销软删及可回收清单。仅真实且未删除的资产进入选区；
  概况、井等结构节点不作为资产删除。程序化定位会刷新按钮可用态；只读工程禁用操作。
- 选中现有古地理图后，通过「三级相…」或右键「整理三级相与系统纹理…」重新处理。
  从工程内留存 RAW 配套文件生成新 DERIVED GeoPackage，沿用资产身份、原始来源和各自层位。
  微相字段自动识别／手动指定；复用项目分类、内置三级模板和系统纹理。不可识别的类别
  不推断归属，提示字段、配准或分类问题。已有三级结果可重整；内容和策略未变时不重复登记。
- 原件与每个配套成员先核对摘要，缺件／变化拒绝整理。批次沿用私有目录快照与原子发布，
  取消、切换工程、目录或回收清单变化时不发布过期结果。已删除图件须先恢复。
- 永久删除扩展 bundle_members，按安全路径清理同目录登记成员；仍被保留版本引用的成员
  不删除。工程外原件不动，继承目录血缘保护和受管路径／符号链接检查。
- 三级分类沿用共享微相分区，父级视图按分类聚合；本改动不生成三套独立几何。
