## 口径（语义决策）

1. **完整树优先**：降级路径的存在让大资产工程「看起来资产少了」——
   误判面比滚动性能更重要；>300 资产用例钉住不回退。
2. **分组即语义层**：顶级五组（测区/测井/地震/成果图件/辅助资料）+
   保留组（计划井/层位/不确定性集合/标签）是数据管理的组织词表；
   新资产类型先定组再进树（岩心照片走井节点 L3 分支 :159-256、
   挂辅助实体的综合柱状图归参考资料 :476 注释）。
3. **软删/改写表贯穿**：计划井组过滤 recycle + `m_plannedVisible`
   回调（:543-546）；显示名一律走实体改写表（ovStore->displayName）。
4. **收拢状态稳定性**：重建不得把树跳回一级收拢态（:55 注释——
   展开键 navExpandedKey + 滚动位置保持）；点击三级节点不得重置树
   （:806 注释）。
5. **分页与树解耦**：分页器只服务表/图标视图（数据页契约），树视图
   永远全量——两视图共享资产集合、互不暗示对方分页状态。
