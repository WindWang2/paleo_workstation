# 文档关系与井震状态第二阶段（2026-11-05）

接续文档来源及 Swarm 修复，仍提交到 PR #904 和配套 Data_service PR #12。
三路子代理分别负责关系模型、地质失效与快照/会话，主代理负责实际时深读取、
后台目录发布、消费侧守卫、部署接线及统一回归。本阶段没有改动视觉设计。

## 文档的必要数据与状态

| 数据 | 必须保存 | 不作为身份或就绪依据 |
|---|---|---|
| 文件来源 | SourceRef、原始文件修订、模型身份、来源行、定位和验证状态 | 文件名、显示名、当前物理路径 |
| 井内对象 | 类型、实际对象 ID、所属井/来源、对象修订 | 同名关系顺序、列表第一条、文件指纹未变 |
| 关系用途 | 文档/模型、用途、方案固定修订、层段/子层段、井、可选目标体 | 全局单一时深表或单一分层道 |
| 选择状态 | 候选、确认、唯一主选；每次解析重新验证修订 | 已选不代表单位、起算面或时间基准已确认 |
| 派生成果 | 冻结输入/方案修订、所用几何、有效/待复核状态 | 当前界面选择、显示名称 |

`ModelObjectRef` 支持 TimeDepth、IntervalTrack、SeismicVolume。
`InterpretationContext` 按文档、模型、用途、方案修订、层段与目标地震体建立稳定键；
`RelationUseSpec` 再固定井和关系类型。位置变化不会修改上述身份。
类型化记录使用保留的 `document-relation-v1` 标记存入现有 SourceBinding；旧不透明
scope 保留原义，不自动变成已验证的类型化关系。跨井、跨来源、跨方案修订、错误对象
类型及未登记井 ID 映射均拒绝，不按显示名回退。

文档会话提供异步登记、确认、主选、解析及显式元数据升级命令。工作线程接收值快照，
只读校验元数据；提交回所属线程时检查会话世代和目录修订。关闭、取消、目录变化
丢弃旧结果；只读会话可解析，不能升级模型。原生文件来源的旧绑定仍兼容，类型化关系
目前要求工区模型和明确的目录井到模型井映射。

## 修订与数值读取

SDK 的对象描述接口按主键读取元数据，不解析时深点、区间行或地震振幅。
附加表与触发器维护 epoch 加递增计数修订；时深数值/语义、分层行、地震采样及几何
变化产生新修订，显示名和纯位置更新不产生新修订。删除再用同一编号也不能复用旧令牌。
只读打开旧库返回修订未知且不写库；升级是单独的可取消事务，普通可写开库确保追踪结构。
修订令牌用于识别过期数据，不保存旧数值；历史数值仍由解释快照承担。

`ProjectDataFacade::tdTableFor(RelationResolveRequest)` 使用文档保存的唯一已确认主选，
并核对目录修订、当前来源版本、对象 ID 和修订；不会误读同名的第一张表。
SDK 在同一个只读事务内检查修订并读取数值。宿主最多接收 100,000 点，SDK 另限制
JSON 字节数与点数，失败/取消清空输出。MD、m/ft、MD 起算面、ms/s、OWT/TWT、
时间基准和符号必须明确；换算仅做已声明的单位与单/双程统一，不自动确认物理含义。
原始文件离线不妨碍读取已入库的明确对象。

## 更新、失效与后台发布

井相成果按实际井的层段范围比较；地震相成果按层位资源及子层段顶底比例比较。
W1 编辑不误伤 W2，层位重绑使地震成果失效而不误伤仅消费 MD 范围的井成果。
四分层聚合按实际组成部分比较，旧通用指纹接口保留兼容。

SDK 的待复核状态是权威，宿主批量投影到 Catalog 的对应 DERIVED 及实际下游。
目录写入失败不发布半份操作；SDK 状态保留，下次刷新可重试，不能把历史成果重新标有效。
后台刷新将目录操作日志与视图数据一起准备，在所属线程核对世代后原子应用。
即使目录序号未变，新的 SDK 修订刷新也不能接收上一世代已经算完的旧投影。
当前同步仍遍历目录版本与 SDK 绑定元数据，大历史库的增量分页尚未实现；索引和缓存
减少重复查找及开库，不承诺整体同步为常数成本。

## 性能和快照部署

来源、对象及修订校验为元数据查询；读取时深只读取选中对象。会话工厂盖目录修订戳，
实际消费不为校验唯一选择而全扫所有来源；任意目录修改后需重新取得请求。
成果失效按方案和状态索引查询，不读取历史成果的大字段。
SEG-Y quick 仍最多 64 KiB，SF3P 仍为有界头检查，不以快速身份核验冒充全振幅完整性校验。

SQLite 快照现在由随应用部署的 Qt Core/Sql 辅助进程执行，使用同一套 SQLite 驱动，
避免混用第二个 SQLite 动态库的锁和 ABI。父进程轮询取消及超时，终止任务后清理私有
暂存目录；成功且核验 SQLite 头后才发布目标路径，已有目标不覆盖。若操作系统未能
终止子进程，仅保留私有暂存目录并报错，不发布半份快照。默认超时五分钟，可配置。
快照包含已提交 WAL，保留对象 ID 和 BLOB，不包含未提交写入；原库及原始数据不改。
完整快照仍需与库大小相关的时间和磁盘空间。辅助程序已接入应用构建、安装及两套
Windows 便携脚本，不从 PATH 搜索替代程序；缺失会明确失败。

## 范围与后续

本阶段提供类型、会话、指定时深读口和已有成果失效的闭环。各业务视图仍需逐批改用
新会话；时深优选/语义修订到全部实际消费成果的依赖清单及反向索引尚未完成。
纯振幅查询与仅使用 MD 范围的井预测不消费时深，不能无差别标旧。
同一层位/地震资源 ID 内的点值、坐标与时间语义变化尚未纳入本阶段的方案几何指纹；
旧地图、综合和单因素成果缺消费者元数据时仍采用保守的全局比较口径。
通用分层体系、跨体系映射、显式分段时深、对目标体的完整物理兼容及地震框架跨来源
采集仍为后续工作。此处的对象可解析不等于井震可直接换算。

验证结果以 PR 说明为准；私有 HY 数据、临时数据库、构建与测试日志不入库。
