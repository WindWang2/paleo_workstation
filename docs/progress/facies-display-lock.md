# 编图三级尺度与单面显示层级锁定

2026-10-18。

智能编图沿用三级共用面覆盖与现有自动比例尺阈值：分母大于 800 万显示相，
大于 400 万且不超过 800 万显示亚相，不超过 400 万显示微相。
图层的「显示层级」仍可选择自动或固定层级。

在「相类别与标注」中，用「选中相面」选择锁定层级，再点击
「应用显示层级到选中相面」。操作面向相面编辑副本，支持多选；
选择「跟随图层（解除锁定）」恢复图层设置。下方显示当前选中面数和锁定状态。
锁定独立于分类改写：不更改微相编码、三级归属、几何或证据。

锁定写入相面属性 `facies_display_level`，合法值为 `facies`、`sub_facies`、
`micro_facies`；`auto`、空值或未知值跟随图层。旧成果无需迁移即可显示。
第一次锁定以同一原生编辑命令添加字段并写值，支持撤销、重做和放弃编辑。
按现有工作流保存编辑、保存图件新版本后，锁定随 GeoPackage 快照保存，
后续编辑副本继承；历史成果仍只读。

渲染器同时按显示层级和微相编码选择符号，因此相同微相编码的两个面可以
分别显示相和微相。标注复用相同条件。图例按实际出现的各级分类组合，
父类已有真实符号时复用该节点，不重复创建同名父标题；画布、QGIS 图层树、
版面和导出继续共用渲染器符号。主图图例标题在混合层级时标明包含相面层级锁定。

回归用例位于 `tst_mappingworkbench`：跨三级比例尺切换、同码不同层级、
原始分类/几何不变、图例树节点唯一性、原生 QGIS 图例节点、解除/撤销/重做/回滚、
非法设置拒绝、批量锁定、保存版本与复制继承、历史版本只读，以及页面意图与使能。

验证：`tst_mappingworkbench` 覆盖混合层级渲染、图例节点、撤销与版本继承；
分类及标准图件元素回归也通过。`layering`、`layering_strict` 与
`layering_selftest` 均通过。浅色与深色主题下检查了新增控件布局。
