# 相面编辑交互与 QGIS 复用核对

核对对象为 PR #521 的实际分支，保留主 checkout 的其他改动。
以原生 Qt 主窗口和内存相面夹具逐步操作截图，再用编图工作副本测试检查持久化。

## 发现并修复

1. **绘制失败无提示**：工具发出的原生 `QgsMapTool::messageEmitted` 未接入界面。
   现在警告和错误统一转到既有状态栏；无效覆盖保留工具、选区和编辑缓冲，可重画。
2. **错误原因被覆盖**：顶点拓扑验证的具体原因紧接着被“无法移动节点”等泛化提示覆盖。
   现在分区验证失败整体回退并保留具体原因，其他图层的聚合失败提示不变。
3. **保存拒绝后无法恢复**：原生撤销已恢复合法覆盖，提交许可仍为 false。
   现在只记录本分区检查的拒绝，撤销／修复后重验并释放；独立 beforeCommit 拒绝仍生效。
   重复点击保存不会抹掉恢复状态，证据审计失败也不会被拓扑恢复覆盖。
4. **入口说明不同步**：普通“添加面”在相面上实际使用覆盖裁切，却显示普通新增说明。
   现在与覆盖工具共用完整说明，分区菜单开启原生 tooltip，禁用项说明选择条件。
   地图上下文给出左键绘制、右键完成、退格回退与 Esc 结束。
5. **合并后保留旧草稿**：合并成功时结束旧绘制工具，避免尚未完成的分割线／覆盖草稿
   继续作用到新的合并选区；失败仍保留原工具以便修正。
6. **过期错误反馈**：成功编辑、撤销和重做清除上一次工具错误，避免成功结果旁仍显示
   “新面必须覆盖有效区域”等过期原因。

## QGIS 原生能力与适配边界

| 能力 | 采用的实现 |
| --- | --- |
| 点击、橡皮线、完成／退格、CAD、吸附、图层坐标转换 | QgsMapToolCapture、QgsAdvancedDigitizingDockWidget、QgsSnappingUtils |
| 分割、覆盖、合并 | QgsGeometry::splitGeometry / intersection / difference / unaryUnion |
| 共边节点 | QgsVectorLayer::addTopologicalPoints，双向补齐未选邻面接点 |
| 覆盖合法性与原始范围 | QGIS/GEOS validateCoverage、拓扑相等比较 |
| 编辑事务与撤销重做 | QgsVectorLayer 原生 edit command、undoStack；没有另建几何撤销栈 |
| 树、画布、分类聚合、图例、属性表 | 现有 QGIS 原生控件与渲染器 |
| 三级归属、来源身份、证据、需复核及版本 | Paleo 地质业务适配，与原生事务绑定 |

核对 [QGIS 4.2.3 捕捉源码](https://github.com/qgis/QGIS/blob/final-4_2_3/src/gui/maptools/qgsmaptoolcapture.cpp)
确认线捕捉移交所有权、面捕捉借用对象，以及完成／取消及坐标转换行为。
未改用会自动避让其他图层的 QgsMapToolCaptureLayerGeometry：本产品的覆盖操作需要
保留用户画出的区域，再裁切原面，自动避让会改变这一语义。

完整 QgsVertexTool 仍属 QGIS app-only，不是当前支持的嵌入库接口。沿用已登记的
QgsMapToolEdit、原生顶点标记及几何编辑适配，不新增一套几何或吸附实现。
限制见 docs/QGIS_NATIVE_ADOPTION.md 与顶点工具头部的接口证据。
