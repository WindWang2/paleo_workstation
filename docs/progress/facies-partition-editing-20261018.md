# 三级相面分区编辑

几何只有一套微相基础面，父级显示聚合继续由 `FaciesHierarchyRenderer` 负责。
新增 QGIS 分区编辑器和原生捕捉工具；功能层继续管理不可变版本、分类与证据。

## 操作契约

| 操作 | 约束与结果 |
| --- | --- |
| 分割 | 选面后画线，拆出独立图元；继承完整三级分类与区间，同步未选邻面的交点 |
| 新建／覆盖 | 指定目标微相，裁切所有相交原面，保留剩余碎片；只选中新面 |
| 合并 | 至少两个连通面；同微相可保留分类，不同微相必须显式选择目标叶节点 |
| 顶点 | 同层共边联动；移、增、删后即时校验，改变原覆盖或破坏拓扑则整步拒绝 |

原覆盖范围（含已有无数据孔洞）冻结为版本元数据中的 WKB，重开后恢复。
覆盖绘制裁切到有效范围，不提供隐式工区扩展。分区、公共节点、分类、身份与
证据修订均在一个原生撤销命令内；失败没有可重做的半成品。重做复用原身份和审计。
提交与保存版本再次检查几何、覆盖关系和合法微相编码，删除编码字段也不能绕过。

新图元记录直接来源与根来源。分割、覆盖、合并汇集来源解释、未保存复核事件及
证据，转为需复核状态；保存继续冻结来源版本，历史图件不被覆盖。来源普通属性
逐面留档，多来源存在不同值时不把第一条测量或备注冒充整个新面的属性。
新图元不沿用预测置信度；改类同步三级属性并清理失效区间，保留合法同类同区间
合并和分割的范围。新相界不继承旧要素级断层／尖灭／相变类型，原属性进入来源记录。

## 界面与兼容入口

编辑工具条和三个编图页 Ribbon 共用“相面编辑”菜单与完整三级路径下拉框。
普通新增面在相面副本中走覆盖绘制；普通删除、整面移动、独立整形和跨层独立
撤销禁用并给出原因。新的绘面入口复用联动证据面板。只读图件和其他层位继续
沿用已有门控，点与线的普通编辑行为保持原契约。

## 验证范围

- `tst_faciespartition`：分割、交点双向补齐、面内与跨面覆盖、碎片、合法无数据孔洞、
  合并目标、非连通拒绝、分类字段保护、失败回退、身份与原生撤销重做。
- `tst_mappingworkbench`：完整工作副本流程、三级属性、全部来源证据、相界与数值
  属性留档、多轮合并复核、版本往返、历史文件哈希、图例和操作门控。
- `tst_edittools`：实际顶点拖动拒绝越界并允许公共边界调整，兼顾原有编辑工具回归。
- `tst_ui` 定向用例：Ribbon 目标同步、页面作用域、图层与地图同步；保存真实控件截图。
