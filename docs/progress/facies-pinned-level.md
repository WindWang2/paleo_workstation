# 编图相类固定显示层级列表

2026-10-24。

在三级尺度显示（自动比例尺 / 图层固定层级）与单面显示锁定的基础上，
支持按相类固定显示层级：在地图上右键相面 →「固定显示层级」→ 相 / 亚相 / 微相，
即把该相面在所选层级上的节点（含整棵子树）固定显示为该层级，不随比例尺或图层
显示层级变化；已有固定作用于该相面时，勾选当前层级，选别的层级即改这条（最近
一级）固定的层级，并多出「取消固定」。已固定的相类列在编图流程页「固定显示层级
的相类」分组（单独成组、默认展开，位于默认折叠的「相类别与标注」之前、图件列表
之下），只列已固定项：每行可改层级（相 / 亚相 / 微相）或点「删除」；分类中已不
存在的固定项标注「（不在当前分类中）」，同样可删除。无固定时显示添加提示。

优先级：单面锁定 `facies_display_level` > 相类固定（最近的固定祖先优先，
叶节点固定覆盖父节点固定）> 图层显示层级 / 自动比例尺。

固定项保存在图层自定义属性 `paleo/faciesPinnedLevels`（JSON：节点键 → 层级），
随 .qgz 工程保存，与 `paleo/faciesDisplayMode` 同一机制；不改 GeoPackage
结构，无迁移，旧工程没有该属性即视为无固定，显示不变。非法键或层级在
读取时丢弃。井预测图层同样可固定（固定项覆盖其默认微相显示）。

渲染器在显示层级表达式中按微相编码插入固定层级分支，图例按实际出现的
编码分别归入有效层级，画布、图层树、版面和导出共用同一渲染器。

回归用例：`tst_faciescatalog`（最近祖先解析、非法项丢弃、编码往返）与
`tst_mappingworkbench`（跨比例尺与图层固定模式下的子树固定、单面锁定优先、
改级 / 非法请求 / 移除、工程保存重开持久化与旧工程无固定、列表增删改意图）。

后续补齐（PR #691 Low 项）：

- 编辑副本与新保存版本：固定项写入版本记录 extra 的 `pinned_levels`
  作为种子；新图层尚无属性时由 `styleLayer` 带入，已有属性（含显式清空
  写入的 `"{}"`）以图层为准。存储仍是图层属性，GeoPackage 无改动。
- Ribbon 显示层级控件：下拉选项与行为不变，有固定时状态文字与提示附加
  「N 个相类固定」。
- 参考窗口：以主图图层当前固定为准传入，与主图同口径显示。
- 编码匹配：按字段原值类型生成带类型字面量（`QgsExpression::quotedValue`），
  不再经 `to_string`，整型与文本编码字段均可匹配。

新增用例：`classPinsCarryIntoSavedVersionsAndEditingCopies`、
`classPinLiteralsKeepFieldTypes`、`referenceCanvasHonoursClassPins`、
`ribbonDisplayControlIndicatesPinnedClasses`，以及
`wellIntervalsReviewUndoAndPersistence` 中的测井固定段。

界面调整（2026-10-24）：原「下拉选相类 + 层级 + 固定 / 移除固定按钮，列表只列
已固定项」改为上述全量相类树与逐行下拉框；后端存储、`pinRequested` 意图与排队
投递均不变。行下拉框未改选时不发意图。回归用例：`tst_mappingworkbench` 的
层级页用例（全部 11 个节点成树、改选与「自动」即移除）与
`faciesPinTreeListsStalePinsAndFilters`（陈旧固定、加粗、筛选）。

已知 Low（不阻断，记录取舍）：
- 刷新后恢复滚动位置在布局更新前设置，极端情况下可能回到顶部；
- 相类名称本身含「 / 」时无法按路径推断父节点，该行退为顶层显示；
- 被筛选隐藏的行仍创建行内下拉框（相类数量在百级以内，开销可忽略）；
- 图层属性中出现未知层级值时下拉框显示为「自动」，选「自动」即可清除。


## 改为右键固定 + 仅列已固定项（2026-10-24 晚）

用户认为全量相类树藏得太深，改为：画布右键相面加「固定显示层级」子菜单
（`src/ui/faciespinmenu.*`，挂在既有「更改此要素的相」右键钩子上，直接调用后端
`setPinnedLevel`）；页面列表退为只列已固定项，行内改层级 / 删除仍经排队的
`pinRequested` → `pinFaciesLevel` 命令。

位置取舍：放在编图流程页独立展开分组、图件列表之下，而非新建停靠窗——固定
作用于页面所选图件，与图件列表相邻最好理解，且不新增停靠窗布局状态；代价是
页面较长时需滚动才见（停靠窗可常驻，但与所选图件的关联不直观）。

已知 Low：
- 右键作用于画布当前图层，列表跟随页面所选图件；两者不同时列表不显示刚加的固定；
- 改层级沿用最近一级固定的节点，因此节点层级与固定层级可不同（如亚相节点固定为
  相），列表照实显示；
- 刷新后恢复滚动位置在布局更新前设置，极端情况下可能回到顶部。
