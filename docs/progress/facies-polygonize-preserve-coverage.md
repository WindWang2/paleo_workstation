# 地震相栅格转面保持有效区覆盖（2026-10-24）

用户反馈：相栅格覆盖测区，转成相面后只剩分散图斑，出现大片白底。
对现场 D61 数据的只读核对证实这属于几何丢失，并非纹理、透明度或图层显示问题。

## 原因

共享边界图只按相邻面编号分弧，没有把所有面环的起点及图节点分叉处作为弧端点。
当相邻环从一条既有共享弧的中途开始遍历时，环引用的却是完整弧；重建的大背景面因此
自交。最终 noding 按与来源面的相交面积归属图斑，无效来源面的相交失败会使大片区域
无人认领，被跳过；剩下的面仍然可以通过原来的 coverage 拓扑验证。

现场分步诊断（相同去噪/聚合参数）：

| 阶段 | 面数量 | 有效性/面积 |
| --- | ---: | --- |
| GDALPolygonize + dissolve + 首次 noding | 34 | 全部有效、覆盖约 2.11677 亿平方米 |
| 旧边界图直接重建（尚未圆润化） | 34 | 4 个无效面 |
| 旧圆润化后最终 noding | 31 | 仅剩 83840386.796 平方米，约 39.608% |

因此问题发生在边界图重建阶段，关闭圆润化也不能从根本上解决。旧圆润化还会切割有效区
外圈，使输出范围额外收缩。

## 修复

- 所有环起点、度数不等于 2 的拓扑节点统一断弧；两侧始终引用同一段完整共享弧。
- 外圈及 NoData 边界不参与圆润化；GEOS coverage 简化也保留外边界。
- noding 前拒绝无效来源面，避免把相交失败误当成“无覆盖”并静默丢弃。
- 去噪/聚合后的分类域冻结为参考覆盖范围。输出除了通过面间拓扑验证，还必须通过与
  参考范围的对称差面积校验；出现漏面或越界时拒绝保存不完整成果。
- PROVENANCE 增加 expected_coverage_area、output_coverage_area、coverage_difference_area。

去噪、聚合和内部边界圆润化继续生效。原有小 NoData 孔聚合规则未改变：D61 原始有效
像元 263332，既有聚合处理填了 4 个小孔，校验参考域为该处理后的 263336 个有效像元。
本次修复不额外填充大面积无数据区。

## 验证

- 新增 `tst_faciescoverage`：**8 passed / 0 failed / 0 skipped**，含初始化/清理计数。
  覆盖 4 个固定种子的复杂多相网格、环/分叉连接、NoData/外圈固定、内部圆润化及简化，
  以及显式启用的真实 D61 数据验收。修复前新增覆盖断言 6 项全部失败。
- 原有转面回归 `tst_algorithms::faciesPolygons*`：**13 passed / 0 failed**，含初始化/清理；
  包括确定性、去噪、小斑块/小孔聚合、面积占比门限、简化、圆润化与约束线吸附。
- D61 修复输出 34 个面，全部有效，合并面积 **211676877.884786 平方米**，与去噪/聚合后
  的参考覆盖域对称差为 **0**。占比最大的相编码 6 恢复到约 1.32052 亿平方米。
- 原始栅格 ver-412 和原转面成果 ver-413 的 SHA-256 与目录记录一致，未覆盖现有成果。
- 严格分层、文件预算、UI 大小/tokens/invariants、i18n、文档漂移与 diff 空白检查通过。

真实数据测试通过 PALEO_FACIES_COVERAGE_INPUT 显式启用，无该变量时常规 CI 跳过；
PALEO_FACIES_COVERAGE_OUTPUT 可将验收成果保存在指定的独立路径。本地验证使用隔离目录
重编算法单元并链接静态库副本，未做完整应用构建，也未替换当前运行的程序。
对照图和验收 GeoPackage 保留在本地验证目录，未提交用户数据。更新构建后需重新执行转面，
已有不完整的派生成果不会由代码升级自动重建。
