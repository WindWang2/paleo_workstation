# 相图自动比例尺设置与 ribbon 固定显示

旧默认阈值为 1:8,000,000 / 1:4,000,000，工区地图需要缩小很多才能显示相和亚相。
现在缺省使用 1:250,000 / 1:50,000，并提供可保存的阈值设置。

- 数据层 `FaciesHierarchy::ScaleThresholds` 定义与验证阈值，`resolveLevel` 接收显式
  参数，固定层级优先。`FaciesDisplaySettings` 通过 QSettings 保存应用偏好并通知变化。
- 功能层统一解析主图层级；偏好变化时重新检查已显示图层。参考图订阅同一设置，
  在本视图实际比例尺上重新渲染和更新图例。
- 原生 ribbon 的三个地图工作流提供“相图显示”组，含自动与三种固定模式、当前层级
  和自动设置入口。视图控件仅收集值并发信号，主窗口转发到工作流。
- 当前可见且选中的相图优先，若当前选择不是相图则选择本层位的可见相图；提示显示
  作用图件。无图件和测井点不启用固定选择。设置对话框支持校验、恢复默认、取消，
  只有确认才保存。固定显示继续保存到图层的既有工程属性；不修改分类或几何。

验证覆盖默认与自定义阈值边界、无效值、固定层级、应用偏好落盘、既有主图与参考图
即时更新、设置对话框及实际 ribbon 的目标、同步、缩放和隐藏行为。
