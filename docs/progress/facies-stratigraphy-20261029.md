## 实现

Ribbon 为数据管理、地层对比、单井相分析、地震相分析、古地理编图。
工具类别与中央视图解耦；显式打开功能激活可关闭的可视化标签。
Ctrl+1…5 选择工具，Ctrl+Tab 循环已打开视图。预测与单因素功能保留内部任务标识，
验证合入编图工具，右侧旧高级工具保持可达。

单井任务复用当前地层内井段预测、优势微相井点及分层沉积相属性服务，
单因素入口归入单井相分析。地震任务调用预测服务，保存栅格后通过 QGIS
后台转面，保留原栅格版本、相分类和计算父版本，面产物标识 seismic 来源。
真实推理依赖工程中配置的预测服务；Mock 仍需显式选择。

地层对比替换主入口的外部 Web 工作台，采用原生连井曲线与结果表，支持
选择输入资料、确认项目约定、区域界面计算、统一模板 L3/L4 划分、共享界面拖动、
深度数值调整、撤销、保存与重开读取。人工编辑经原算法校验，保留初始深度，
相关派生曲线按原算法标记 stale。

保存进入同一工区 Data_service 的不可变修订、快照、模板和运行记录；
ProjectDataFacade 分层读口读取模型中的新划分。
保存后可显式将所选井的有序界面应用到 project_area.json，更新层位 chip、
层位下拉与预测／单因素计算的层位集合。项目参数以 QSaveFile 写入。
