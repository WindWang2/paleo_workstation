# 数据导入按钮对话框

2026-10-22，承接已合并的 #630。

数据页八个入口（井数据、测井、地震、边界、普通文件、工区目录、现有古地理图、
古地理图目录）统一先打开资料来源对话框。支持文件多选、移除、目录模式和粘贴
目录路径，空选择禁用下一步，路径不存在或类型不符时留在表单提示。

确认来源后复用原有分类／显示名／复制方式确认及后台任务；古地理图继续显示层位
归属和三级相选项。取消任一步均不写入工程。来源及单文件确认期间工程切换后拒绝
继续，导入失败通过通知显示原因。

井资料筛选加入 XLSX，地震筛选包含 SGY／SEGY。边界入口对 SHP／GPKG／GeoJSON
预选 boundary，并将其补入分类确认词表，中文名为“测区范围”；仍允许用户调整。
通用矢量不按文件名猜测是否为测区范围。

单独选择 SHP 也走数据集确认，自动发现同目录同名配套文件。归组复用 domain
sidecar 词表，包含编码、投影、索引、样式和全名元数据；必备件齐全时按一项复制。
保留默认外部索引及显式复制选项，不改变源文件。
