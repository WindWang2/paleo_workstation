# 批量导入：层位解析性能与尾部进度

日期：2026-10-25

大层位导入时，原实现读取文件头也会解码、拆分整个文件，并在逐点解析时反复构造空白分隔正则。现在逐行解码，文件头在首条数据处停止扫描，每次解析只构造一个分隔正则。坐标拟合、网格装箱、缺失值和重复点处理规则保持原有实现。

## 本机对比

同机、相同 Release 编译参数和八份本地层位文件，分别调用旧、新 `binHorizon`。输入读取不计入时间；每版各运行一次，结果仅表示本次层位解析阶段，不能作为完整工程导入的加速倍数。

本次解析合计约快 6.6 倍，减少约 39.2 秒。八份输出的完整浮点网格 SHA-256、行列数、已填格数、冲突及拒绝数、坐标变换参数、几何残差和深度极值逐项完全一致。未修改原始输入数据。

复测入口为 `tst_horizonbinner benchmarkLocalHorizons`：通过 `PALEO_HORIZON_BENCHMARK_INPUT` 指定包含 `.dat` 的目录，可用 `PALEO_HORIZON_BENCHMARK_OUTPUT` 保存包含摘要及耗时的 JSON。未设置输入时跳过该可选基准，不影响常规回归。

## 进度与验证

目录导入和多文件导入在最后一个文件处理后切换到“文件处理结束，正在核验分层与准备提交”，使用未知百分比和剩余时间，避免以文件数量推算恢复清单、分层核验及提交耗时。完成后仍显示 100%。逐文件回调次数、取消、事务提交和失败隔离机制保持不变。

- 层位常规回归：9 passed，0 failed，1 skipped（可选本地基准）；涵盖 LF、CRLF、CR 和无末尾换行。
- 含八文件基准的层位测试：10 passed，0 failed。
- 导入针对性回归：10 passed，0 failed；涵盖并发提交、并发写入重试、提交前失败/取消、排队取消、单文件取消及混合好坏文件，并验证尾部进度不再给出错误估计。
- 分层、文件预算、UI 尺寸/令牌/不变量、国际化、文档漂移检查通过。

验证使用隔离输出目录编译修改单元并链接测试。未运行完整桌面 GUI 导入计时；其余数据转换、磁盘复制、校验和界面加载仍会影响整体耗时。
