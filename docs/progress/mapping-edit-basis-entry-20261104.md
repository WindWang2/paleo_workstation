# 编图解释依据入口（2026-11-04）

用户在绘制或修改相面时收到“请先设置本次解释依据和修改目的”，却无法找到输入入口。
原表单仅位于右侧编图流程中；参数面板隐藏、停在高级工具或滚到页面下方时，提示没有导航作用。

## 操作

1. 古地理编图 Ribbon → 编图链 → **解释依据…**。
2. 右侧编图参数自动显示，切回编图流程并定位“本次解释依据”。
3. 填写有明确标签的“解释说明”和“修改目的”；已保存的本层位参考版本可选，允许纯人工依据。
4. 点击“启用本次解释依据”，再选择绘制、分割、合并或节点编辑工具。

填写说明不等同于启用，启用仍使用原有 9000 字、层位及参考版本有效性校验。
不代填地质解释，不自动重放被拦截的操作。

## 实现

- 主窗口组装直接入口，复用原 MappingEditBasis 和 setEditEvidence 命令，不另建数据模型或解释副本。
- MappingWorkbench::needsEditEvidence 与实际解释写入使用同一条件。
- 通用编辑工具栏接收宿主注入的修改前检查；选择、会话保存及撤销仍可用。
- 缺少依据时，在安装修改工具或执行合并之前打开表单，保持图面；已装工具因上下文清空而被拒绝时也能找回入口。
- 表单恢复到首个未填字段；面板足够高时保留整个依据组可见。
- 参考证据入口继续独立，避免其自动打开逻辑抢走解释表单的输入焦点。
- 未改 DataService 与原解释证据持久化/撤销契约。
- 规模基线仅收紧：attachWorkbench 函数 295 → 289；无新增 Qgs 散布。

## 验证

新增主窗口集成回归覆盖：隐藏参数面板、停留高级工具、滚动到页尾后的入口恢复；缺依据时不启动绘图或写要素；
填写并启用后真实绘面成功，说明进入解释记录；清空上下文后节点工具重新引导到表单。
另复验表单交付、空白图依据/覆盖/撤销、参考版本固定、已有图手工模式、相面工具和分区操作，共 7 个定向用例通过。
