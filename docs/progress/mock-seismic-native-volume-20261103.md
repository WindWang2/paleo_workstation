# 当前地震体的 Mock 层段预测（2026-11-03）

旧 Mock 虽有 DataService 窗口分支，但还查找旧层位文件，原生聚类结果没有带回
地震体 CRS。已保存的单井预测又被通用点写出器无条件标成局部工程坐标，实际 UTM
井点无法转换到当前地震网格，导致真实工区在井点校准环节失败。

## 修改

- 当前有效 UnitSelection 直接使用所选体的 DataService 逐道顶底窗，冻结方案修订
  及 S1–S4，不再访问旧 DAT 或时间栅格。旧界面工程仍可用原文件与 ±12 ms 窗。
- 读取门面同时交付实际体 ID、源路径、CRS 和冻结单元，真实模型输入与 Mock 共享
  这份坐标口径。Mock 保留均值、RMS、过零率特征和原有确定性聚类/井点多数票规则。
- 输出范围包含有 XY 的缺测道，缺失边缘不缩小网格；同格最近道缺测时仍保留无值。
  网格每轴最多 64，较小体按实际采样轴数量确定尺寸，避免人为放大成稀疏空格。
- 校准井来源按方案、父单元、子层段和修订几何匹配；同显示名的其他单元不能借用。
  分类、每井最新记录、平票小编码及固定种子只从已观测类别选取的规则保持不变。
- 新测井预测按 DataService 的工区 CRS 写出井点。旧系统生成的默认局部 CRS，只有
  在稳定井身份、米制约定和数值坐标逐点匹配 DataService 时，才在内存中采用该井
  CRS 校准，并记录 `dataservice_verified_legacy:<wellId>`。不同坐标拒绝，明确声明
  的其他 CRS 仍正常转换；没有重标或改写已发布文件。
- 新结果保留 Mock 标记，登记体、修订、完整层段窗、16 点取样、有效格数、特征及
  校准来源；不会把原生层段误记成 ±12 ms。栅格、相面和 DataService 绑定按现有
  发布链登记；取消不发布，方案几何变化使已登记绑定失效。
- 当前层段下收起旧层位文件入口，并更新提示和中英文资源。
