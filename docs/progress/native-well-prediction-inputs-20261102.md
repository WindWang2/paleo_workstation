# 原生井批量预测取数修正（2026-11-02）

用户所报 8 口 XML 井在批量井相预测中被同时报为 MD 未声明和
`area source requires an explicit curve group selection`。原来的准备过程只传递文件
路径，无法保留 DataService 中一个来源下多个测井组的身份；随后把组选择错误包装
成了深度单位错误。井道预览已使用原生井读口，因此同一份资料在两个入口表现不同。

## 修改

- 原生井按 `areaModelWellId` 通过 DataService 的井道数据读口取得曲线，保留
  `modelSourceId` / `modelLogSetId`；每个组继续验证其已声明的 MD 及 m/ft，米化后
  成对排序并去重。不回退到按 XML 路径猜测曲线组，也不补写未知深度元数据。
- 原生井不再为了曲线列索引或分层资产仲裁重读大 XML。结果依赖登记其关联的
  测井、组段分层和岩性版本，原生地层组段用于模型匹配，显式解释岩性选择仍优先。
- 批量井相和分析页都先按冻结方案的 MD 子层段截取输入，再校验模型、曲线、岩性
  和窗口要求。S1–S3 半开，S4 保留已有类别覆盖的最后样点；不从层段外补值。
  计划失败时保留真实原因，不一律覆盖为“有效样点不足”。预览整井模式不受影响。
- 兼容文件读口仍拒绝非 MD 或未知单位文本；未选择层段、缺分层、无适用模型、
  空值和窗口不足均继续阻止对应井段预测。
