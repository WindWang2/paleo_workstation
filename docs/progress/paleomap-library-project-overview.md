# 现有古地理图、工区统计与编图基础图

数据管理新增“现有古地理图”，按层位显示逻辑图件，原始文件保存为受管 RAW 版本。
原生 ribbon 提供“导入现有古地理图”“导入图件文件夹”“导入文件”，保留工区文件夹入口。
图件导入可指定层位；也可按文件名／目录识别唯一层位，缺失或歧义时使用明确选择的层位。

Shapefile 的 SHP、SHX、DBF 为必备成员，PRJ、CPG、QML、QMD、QIX、SBN、SBX
和对应 XML 等受支持附属文件一起复制、校验和登记；列表只显示一个图件。
全组摘要参与版本判断，只有 DBF 或样式变化也产生新版本；重复导入会检查受管成员是否完整。
后台生成私有目录和 catalog 日志，在工程会话与目录版本未变时整体提交。
失败／取消不发表半套数据；部分文件失败会保留其余成功项并报告原因。
原始数据导出核对成员摘要；存储治理识别配套清单，避免误删仍被主件引用的样式及坐标文件。

支持 SHP、GeoPackage、GeoJSON、栅格及图片、PDF/SVG 参考文件。
有 CRS 的空间数据可进入本层位的基础图选择；未配准图片和文档作为参考资料。
没有微相字段、或关闭「识别微相」的旧图保留原有 QGIS 样式，不套用工程分类或自动伪彩色。
GeoPackage 使用默认图层参与地图显示，原始容器完整保存。

多边形图件导入时可识别微相字段（含 Shapefile 截成 10 字符的字段名，也可手填）。
能唯一对应工程三级分类或内置模板的微相，会补齐相和亚相，另存只读 GeoPackage 副本。
副本使用系统纹理，可按相、亚相、微相切换显示；编辑走独立副本，原始 Shapefile 不改。
同名微相有多个归属、未知类别、或图件没有有效坐标系时，只保留原图并提示，不生成三级相副本。
工程分类优先于模板；分类变更后再次导入会从原始图件重做副本。

工区概况保留地图，增加“统计与项目进度”页签：登记井及有坐标井、地震测区、资产与版本、
现有古地理图、输出版本，以及各层位测井预测／地震预测／单因素／编图／输出的登记状态。
统计采用目录登记口径（保留的历史版本、仍在目录中的回收记录包含在内），不代表质量验收。
测区面积为有效登记角点在局部米网格中的并集，重叠区不重复计数；无有效边界明确提示。
井位包络面积另外标明为估算，不冒充工区真实边界面积。

智能编图先选基础图，单因素按因子分别分类，地震相、其他相图、现有古地理图按层位筛选。
基础图可显示为参考；已分类矢量复制编辑，相栅格先转面，连续单因素明确阈值后生成相图。
既有综合编图、证据、相面编辑与来源版本链继续复用。

地图导出继续使用 QGIS 版面和地图元素，明确选择两类目的地：
- 工区管理：批次保存在工程 exports/maps，同时登记受管 OUTPUT 资产并按层位显示。
- 外部位置：只发表外部批次，保留版面和输入版本说明，目录资产不增加。

PNG、PDF、SVG 与可用环境中的 TIFF 沿用既有出口；相同图片字节按层位隔离去重。
版面预览在窗口布局后再次适配，避免首次显示时地图缩成角落中的小页。

验证：Debug 构建 paleo 与相关测试通过，编译／测试并行度不超过 8。
8 项 CTest（图件库、导出流水线、原始数据导出、存储治理、编图页、三项 layering）通过。
图件库覆盖真实 SHP 成套复制、仅 DBF 变化、原件删除后的受管读回、层位隔离、取消、
并发目录修改、面积并集、概况页签及 ribbon 入口，以及微相别名补齐三级归属、工程编码优先、
系统纹理图例、三级切换与编辑副本、未知或歧义类别只留原图。导出覆盖外部输出不改目录、工区层位登记、
跨层位同字节去重、目的地切换。检查了 ribbon、图件列表、基础图选择、统计和导出对话框截图。

严格 layering、UI 大小、界面不变量、文案和文档漂移检查通过；收紧了拆分后的文件预算。
