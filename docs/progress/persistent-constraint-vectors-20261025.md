# 约束绘制完成即保存，作为矢量叠加层持续显示

日期：2026-10-25

## 用户操作

选择方向线、间隔线等绘制入口，在地图上完成绘制后自动写入工程约束库。图层树中的约束保持为空间矢量图层，无需额外开启、保存一次编辑会话才可生成图件。后续选择、定位、顶点修改、删除仍使用矢量图层与原生编辑工具；主动开启的编辑会话仍支持撤销、重做和放弃。

生成单因素图时自动保存当前层位的约束编辑，再冻结计算输入；保存失败则保留编辑缓冲并报错，不能绕过失败使用旧约束。即使最后一条约束被删除，也先结束并保存这次编辑。

## 原因与实现

- 空的通用几何表，以及其他层位首条记录的几何类型，会影响 OGR 对约束图层类型的推断。单一几何层位现在在 URI 中明确点、线或面类型，空约束层默认按线管理；混合几何层位仍保留完整主层和对应的几何伴随视图。
- 约束图层重新声明时原位重开数据源，保留对象和图层身份、树中位置、勾选状态及选择，不删除图层再新建。原生编辑工作副本也保留几何类型参数；保存或放弃后重新同步主层与伴随视图。
- 绘制完成直接持久化。用户已主动开启编辑时，绘制仍加入该会话的原生撤销栈。
- 约束组原本位于因素栅格、相面下方，不透明成果可能盖住约束。默认树序及自定义绘制序现在将约束叠加在成果之上，井位等共享基准数据仍置顶。

未迁移约束库表结构，也未改写原始导入数据。旧工程中已有的约束可在加载约束时按当前层位几何重新声明。
