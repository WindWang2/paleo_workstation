## 明确限制和 A2 接缝

Pi 为可信可选组件，**`isSandbox=false`**。固定入口不加载文件/Shell 工具、coding-agent、
项目资源、认证或 provider 网络实现；这不等于 OS 禁止 Node 读写文件或联网。
不套用 Python profile，不执行生成 JS，不声称 OS CPU/内存/线程硬限额。A1 的五秒
deadline 包含队列与身份复核，之后有 kill/reap 清理；其实际生命周期机制需真实 C++
验收，不能由 Node watchdog 代替。WSL 证据不冒充原生 Linux 全栈或 Windows GUI。

A2 应复用宿主 `RuntimeConfig`/opaque `VerifiedRuntime` 和 codec，新增明确的 conversation
协议与固定审阅入口/供货锚；不能静默向 A1 hello/close 开新命令。`streamFn` 当前返回
`pi_model_transport_unconnected`，密钥与模型网络仍留 C++。工具 schema、权限、预算、
取消/上下文代次、稳定 call→operation 和提交事实恢复继续由 Host 持有；退出不是回滚。
长会话的资源能力及后代回收需独立验收，不能把短握手验收外推为长期编排就绪。
