## 操作与结果契约

- 无已保存方案的新工程，在真实井顶底数据到齐后由功能层建立默认方案，等比分界明确为
  provisional；默认方案跟随权威分层生成新修订，保留已解释的内部分界，用户自建方案不覆盖。
  数据尚未到齐时不伪造井出现。后台完成后选择器从草稿转到真实修订；已选择的历史修订保持不变。
- 单井综合面板将当前 UnitSelection 传给功能层；功能层按 Data Service 方案修订中的
  实际井出现范围裁剪提交样点。缺少 MD 米深度窗、没有具体子层段或样点不足时明确拒绝。
  切换分析层段取消本地等待并清除旧显示，缓存键包含完整层段身份。
- 地震预测输入仍按上界面解析，结果图层、资产和发布信号归属稳定分析键；两个子层段
  不再覆写同一个界面名结果。参数元数据不携带活 QGIS 输入对象。切换/重开工程后，
  上一会话任务不能发布到新会话。
- 单井预测保存独立不可变版本，保留预测区间、置信度、分类、模型、任务、层段修订与
  输入版本；原来的地质属性写回流程继续存在，属性写回失败也保留预测快照。
- 单因素参数和厚度链的发布身份保留完整 UnitSelection；融合/编图可由明确的父版本
  继承唯一层段身份。无法确认的旧界面标签不自动认作 S1。
- `syncAnalysisResults` 在工程绑定和目录提交后，复用可取消、合并请求的后台目录快照刷新，
  将已保存且有完整身份的井相、地震相、
  单因素、融合和相面版本投影到 Data Service。binding ID 来自不可变版本 ID，重复运行
  不新增记录；目录提交是事实源，投影失败不删除已提交文件，保留错误并在后续变更/重开时重试。
- 新增 Data Service `invalidateSubIntervalResult`，同步输入过时、删除及传递依赖失效。
  单向失效不恢复几何修订已经置为 stale 的结果；历史修订的迟到结果按实际几何变化标记。
  只读工程不做投影写入。Data Service 子模块固定到公开可取的工作分支提交。
- 合并产生的源码闸问题同时收口：补视图层标记，工程文件名读取收进 QGIS 接口，
  HTML 圆点改用等价 Unicode 字符；transitive 的视图 QtWidgets 记录基线 5→4，
  其余基线未扩大，qgs-audit 136、qgis-spread 170 保持冻结。
