# 编辑与右键改相保持当前地图视图

日期：2026-10-25

编辑副本创建期间，输入快照、版本登记和工作副本都会同步发送上图通知。原有显示通道默认缩放到图层范围，编辑入口又重复调用显示；右键改相完成后也重复显示。因此，局部编辑会被拉回全图，影响用户持续观察同一位置。

副本创建现在通过作用域状态覆盖其中全部同步上图通知，保持当前视图；正常返回和失败返回都恢复原状态。编辑入口复用已显示的工作副本，右键修改后使用既有样式刷新，不再重复定位。保存版本已有的保留视图规则继续生效；用户主动显示某张图件仍缩放定位。

验证使用实际主窗、原生画布、工作副本和右键菜单：

- 修复前，两条场景（进入编辑副本、右键修改相）均在范围守恒断言失败。
- 修复后，`tst_mappingworkbench editingActionsPreserveMapViewport` 为 4 passed，0 failed（含初始化/清理）。
- 设置局部视图及 17° 旋转后，进入副本、首次及连续右键改相、保存、重新选择工作副本并开启编辑模式，范围和比例尺保持一致；旋转角度保留。
- 右键修改实际更新相编码；随后主动“显示图件”仍能定位全图，保留视图状态未泄漏到普通显示操作。
- 分层、文件预算、UI 尺寸/令牌/不变量、国际化、文档漂移及 diff 检查通过。

测试在隔离编译输出与临时工程中运行，未替换或重启当前用户程序，未修改用户工程数据。实际工程需更新构建后验收。
