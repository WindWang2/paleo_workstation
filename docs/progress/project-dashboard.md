# 工区默认看板（2026-10-19）

工区打开后默认进入“数据管理 → 工区看板”。“工区概况”下列出“工区看板”和
“工区全景地图”两个独立入口，地图保留 QGIS 画布。看板右上角可直接打开工区地图。
原来的地图内嵌统计页签不再重复显示。

看板使用原生 Qt 滚动页，包含井数及坐标完整数、测区并集面积、资产及累计版本、
现有古地理图及输出版本四组主要指标，另保留井位包络面积估算。成果覆盖按测井预测、
地震预测、单因素图、编图成果、图件输出展示已有成果的层位数；分层位卡片展示各环节
“已有／未登记”及现有古地理图数量。登记包含历史版本，不表示质量验收或工程完成率。

页面采用 DESIGN 的字体、间距和活体主题令牌，宽窗口四列指标，常规中央区域两列，
窄区域单列；层位卡片最多两列，纵向滚动，避免原七列表格横向溢出。目录变化后合并刷新。
新建、同步打开、后台打开共用 projectOpened 之后的排队导航，检查会话编号及工程路径，
工程关闭时随其他预览释放，避免旧会话延迟导航影响后续工区。若用户已打开资料或切换流程页，
默认跳转保留其显式选择。概况节点不进入文件批量操作。
