用户确认当前井位与地震体均采用 EPSG:32650，并允许作为默认。此前工区已选
EPSG:32650 / m，但地震体自身 CRS 字段为空，范围接口拒绝合并，导致全景地图
只有井位，没有工区边框。

Data_service 新建工区即选择 EPSG:32650 / m。井、地震体、层位、剖面的公开
读取接口共用坐标继承规则：未声明项继承工区；已有声明优先，明确冲突仍不
合并范围。不重投影、不改 XY、不改外部 SEG-Y，也不默认深度或时间基准。
不再把空白井源声明写死为默认 CRS，避免切换工区约定后井与地震继承不一致。

宿主继续消费 `readProjectPlanarRange` 返回的井位、地震、合并三块范围；视图
