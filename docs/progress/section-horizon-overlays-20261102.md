# 各类地震剖面层位叠加（2026-11-02）

用户要求 inline、crossline、任意线及连井剖面提供同一类开关，叠加显示大层界面
与小层分界。二维数据预览、主地震剖面工作台及连井井间地震底图均接入
“地震层位”开关，默认关闭，换线保留开关状态但清除上一剖面的界线。

DataService 新增 `readSectionHorizons`：按实际显示道的 IL/XL 和缺道状态读取
结构化层位，返回大层及指定方案修订中的内部界线。小层采用关联资源和方案比例，
不在 UI 做固定时间四等分。缺失/显式空值/覆盖外不跨接，顶底倒置不生成小层；
局部完整网格可以插值。保留时间符号，明确的单位和单双程约定数值换算，未知
头约定由当前已获用户确认的 TWT/ms 显示约定补足；不推断时间基准或井时深。

数据服务使用一次只读快照及既有层位测线索引，无振幅读取及持久化写入。
大层实线、小层初始推导虚线，名称标注冲突时让位；开关改变只重绘，导出图件
随当前可见状态。井间地震缝通过同一时深函数的反解定位界线，保持校时平移、
拉平偏移和 MD/TVD 与底图一致。

用户补充参考剖面后，显示增加按名称固定的多色界线和 20% 半透明层间色带。
DataService 返回方案明确关联的顶、底曲线 ID 与 S1–S4 邻接关系，视图只按该
拓扑绘制，不把屏幕相邻曲线当作地质层段。小层使用同层段的明度变化，较厚处
标注层段名和 S 编号；保留振幅纹理。缺测、孤立点和顶底倒置处不生成填色。
共享绘制入口使各剖面、开关及导出保持一致。符号规范补入 DESIGN.md。
真实剖面验收发现导入层位采用 16/40 测线稀疏网格，邻域调整为默认 64、上限 128；
通过已有测线索引直接查询相邻行、列及完整网格角点，避免扫描整个邻域。显式空值、
覆盖外及缺少角点仍断开。新增 40 测线稀疏网格数值及显式小邻域约束测试。
