# 连井地震剖面井名（2026-10-24）

现场顶部只看到井位三角标记和长串解析诊断，没有可辨认的井名。数据模型中井名已存在，
但旧标签把井名、偏移距离及完整 alignmentStatus 拼成一个居中胶囊；当诊断很长时，
井名随标签左端落到视口之外，诊断反而横穿整条标尺。

修复让顶部标签只显示井名；未命名时回退井 ID，再回退“未命名井”。偏移距离和诊断
保留在标签悬停提示中，按纯文本转义后展示。标签按实际井位排序、限制在可见范围内，
相邻标签横向避让，以引线连接原井位；空间不足时省略显示，悬停仍可查看完整名称。
过滤条件与井曲线一致，遵循缓冲距离、显示开关和最多显示井数；每次绘制按当前缩放/
平移重新定位，原有井位和剖面数据不变。

验证使用隔离构建中的实际 SeismicSectionCanvas：

- 长诊断与空诊断的顶部标签截图相同，改动井名会改变文字像素；旧代码在前项断言失败。
- 悬停能取得完整井名及转义后的诊断文本。
- 十口合成井（含密集井位及两端边缘）在明暗主题下截图核对，井名均可见。
- 显示模式、双刻度、纵向拉伸、PNG 导出、书签视口恢复回归通过。
- QtTest **9 passed / 0 failed / 0 skipped**，含初始化/清理计数。无界面 Windows 验证显式
  设置 QT_QPA_FONTDIR，避免测试环境字体缺失把不同井名渲染成相同方框。
- 严格分层、文件预算、UI 大小/tokens/invariants、i18n、文档漂移与 diff 检查通过。
  井名绘制拆出后 paintEvent 冻结预算从 783 行收紧到 743 行。
