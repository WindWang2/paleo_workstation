# 属性优选与融合客户端（2026-11-13）

提供数据层 `SeismicAttributeFusionClient`、独立的 extra CMake 挂点及协议测试。
接口与部署说明见 [客户端契约](../seismic/ATTRIBUTE_FUSION_CLIENT.md)。本批不增加
界面，不将聚类标签映射为地质相，也不把外部 Python 服务纳入默认运行依赖。

## 实现与修正

- 去除开发机个人目录探测。优先调用身份及 API 版本匹配的回环 HTTP 服务，
  仅在显式配置脚本后允许可选 CLI；提交后不自动回退，避免重复执行。
- 同一时间预算覆盖健康检查、提交、轮询/进程与结果读取；取消可中断这些阶段。
  已知作业 ID 后发送并等待取消请求，停止清理另有最多 1 秒宽限。
- 对照独立服务 `service_server.py` / `service_core/coordinates.py` 的实际 API 1.0
  修正 CRS 层级：真实位置在 `grid.crs_auth/crs_wkt`，不是草稿测试假定的根对象。
- 严格核对像元外沿、北向上变换、轴序/单位、整数维度、结果预算与文件长度；
  分块按小端 int32 读取，核对聚类编码与有效计数。失败不返回半份成功成果。
- 进程使用绝对输入与控制文件路径；Unicode/空格路径、无末尾换行的进度、
  非零退出和控制文件清理均覆盖。中英文各补 44 条译文。

## 验证边界

本机原完整构建缓存指向的 Windows Qt 6.11/QGIS 前缀已缺失，本批没有将旧缓存
当作完整应用构建成功；验证对象是完整客户端及协议测试，应用集成仍由既有 CI 覆盖。
没有运行真实模型训练或用私有 SEG-Y 做推理验收；夹具 TIFF 只验证文件存在性，
不代表 GeoTIFF 解码或界面端到端结果。外部服务未作为源码依赖 vendored。

API 1.0 不支持提交请求幂等键：提交响应丢失且未取得 ID 时无法恢复/取消该作业。
已知 ID 的取消也是合作式请求，客户端不声称远端已确认停算。这些协议边界保留在
客户端文档中，未通过自动重试或隐藏失败处理。
