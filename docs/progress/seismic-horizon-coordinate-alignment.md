# Mock 地震层位坐标核验修复（2026-10-24）

D61 Mock 地震相预测原先在读取反射窗前报“层位坐标与所选地震测网不一致”。
原实现从地震四角中的三个角推断严格仿射测网，再与 SMI 三角点比较，阈值固定
为 1m；数据行又必须与 SMI 三角点推算位置相差不超过 0.001m。

这批统一到 EPSG:32649 的测网并非严格平行四边形。D61 第四角原始 XY 为
(227948.36, 4005825.36)，由 SMI 三角点推断会偏约 24m，但同号地震道头实际
XY 为 (227948, 4005825)。全量 263446 个层位点对照同 inline/crossline
地震道头，最大偏差 1.891798m、RMS 0.755462m；地震头坐标为整数米，处理记录
注明曾做坐标统一，最小道间距约 20m。无需改写原始层位或地震数据来满足旧检查。

实现改为：

- SegyReader 按索引实际采用的坐标字段、CDP 方言和有符号 scalar 提供逐道 XY。
  缓存恢复后的口径相同，不从三个角外推坐标。
- SMI 数据行以原始 inline/crossline/TWT 定位反射窗；每个相交点的 XY 必须与
  对应地震道头匹配。缺道留空、重复线道号报错，真正错测区或内部错点会给出线道号、
  实际偏差与容差。
- 已声明米制投影的输入容差为 max(1m, 最小边道间距的 10%, 道头量化半对角线
  加 0.001m)；局部测网保留 1m 基准及道头量化容差。该限值用于每个实际道坐标，
  不是放宽三角点拟合误差。超过 1m 的实际最大偏差进入 warnings。
- 原始层位 EPSG/UTM 提示复用 wellSourceCrsHint，转换为 WKT 传递至井点投票和输出；
  已声明但无效、非投影或非米制的 CRS 明确拒绝。
- 原始点实际 XY 装入同样行列数的北向上输出网格，半格外扩覆盖边界。多个点落入
  同像元只保留距格心最近的原始样本，数量进入 warnings；不插值、不补缺道。

  本地验收。覆盖缓存恢复、错测区、仅内部点错位、重投影量化误差、半道偏移、缺道、
  重复点、nodata 边界、原有取窗/投票/栅格 nodata 行为。
- 实际 D61：641×411，263332 个有效像元；114 个落入同像元的原始点按最近格心取样，
  最大坐标偏差 1.892m。此处执行与工作台相同的本地反射窗聚类函数，未执行完整 GUI
  流程，也未替换用户当前程序。
