# 地震平面／剖面联动（2026-10-30）

普通 IL／XL 剖面把数据服务返回的实际道 XY 和有明确单位的米制道距交给画布，
游标悬停及点击定位不再缺少空间坐标。图像命中 LRU 时仍核对最新来源和道几何；
首样整行为空时通过完整数据服务剖面获取几何，不把有效后续样点误判为无数据。

数据服务的坐标系声明随切片／任意线结果传播：剖面到地图定位、地图捕获到地震
测网，以及井位吸附共享 QGIS 画布变换上下文。已声明投影坐标不再按本地工程坐标
解释；未声明的旧工程保留既有本地测网约定。坐标变换失败不作数值直通。

地图捕获根据体的真实测线轴寻找最近存在的 IL／XL，再构建对应的源坐标折线；
不连续线号不会落到不存在的测线上。连井地图路径遇无效顶点或投影失败时整体
隐藏，避免跳过中间顶点后连接错误路径；地图销毁后，路径带通过 QPointer 失效。

回归覆盖：普通测线点击定位、EPSG:3857 与 EPSG:4326 双向转换、非连续测线轴
吸附、无效路径顶点、地图先关闭的生命周期，以及既有时深轴／缓存／取消回归。
