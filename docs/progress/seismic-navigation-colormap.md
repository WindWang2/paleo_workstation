# 三维地震导航与二维色标（2026-10-21）

对应反馈 10、12、13，基线 master `07193ce9`。

- 三维地震体普通左键在所有位置进入旋转，包括切片表面与交线。轨道相机横向增量反向，使可见表面跟随鼠标左／右移动；惯性和方向键复用同一旋转入口。
- 切片移动保留为 Alt+左键显式手势，右键／中键／Shift+左键仍为平移，滚轮缩放。悬停只有按住 Alt 才提示切片移动，普通悬停不误示为拖面。
- 剖面路径拾取保留单击加点；已有点时，橡皮线预览不再拦截 Ctrl+左键旋转及 Shift+左键平移，导航不会新增拾取点。
- 数据预览“二维测线”在测线选择行提供八种既有振幅色标。剖面和右侧图例使用同一调色板，换色不重新读取测线，也不改变时间轴或井标定；同一标签内换测线保留选择。选择行使用既有可横向滚动工具行，窄窗口仍可访问色标。
- 预览图像用 8 位索引表示显示振幅（255 档，零振幅居中），另保留缺测索引；色标切换只改调色板，原始地震数据不变，缺测不会变成有效振幅颜色。

护栏：layering --strict、i18n、ui_invariants、docs_drift、file_budget --strict、ui_size --strict、ui_tokens --strict 通过。

基线只缩：删除 viewport 的 file-budget、ui-size 各一条（1003 → 1000 行，回到阈值内）；buildSeismicContent 函数冻结值 777 → 770；删除固定图例 RGB 例外三条，ui-token 条目 354 → 351。
