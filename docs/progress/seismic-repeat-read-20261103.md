# 重复剖面读取延迟（2026-11-03）

用户现场同时有“解码剖面”和“读取地震剖面”任务，索引任务已完成。定位结果：

- 二维时间片在元数据返回时无条件排队，尚未选择该页也开始读取完整原生时间面。
  实际体为 3901×3241 道；隐藏读盘与当前二维测线、三维浏览竞争资源。此任务原名
  “读取地震剖面”，无法从任务标题判断它其实是在读水平时间片。
- 普通二维预览及原生剖面均重复访问 DataService 的振幅与层位读口。后者即使图像
  LRU 命中，仍读取首样点以取得几何，再查询全部层位；未命中又另读全剖面。
- 对用户提供体的 Inline 3552（3241×4096）单独测量，振幅热读 129ms，而 53 条
  大小层曲线的叠加查询为 6410ms。不能把所有延迟归因于索引或振幅解码。

修复：

- 时间片仅在选中该页时启动；退出即停 debounce、取消在途任务并抬世代，迟到结果
  不上图。时间片不再要求打开三维体。任务更名“读取水平时间切片”，分块完成回报
  真实进度；保持完整原始分辨率，不以缩小数据掩盖等待。
- 统一原生测线缓存，128MiB 有界 LRU，预览和剖面共用；键包含真实文件身份、
  首尾有界指纹、查询窗/预算/方向和 DataService 模型代次。同一键并发合并，等待者
  取消不影响读取者；失败/取消不缓存，读取期间来源变化拒绝结果。
- 层位叠加使用独立 16MiB LRU，按实际测线列序、缺道掩膜、来源及模型代次区分。
  数据库/方案变化不复用旧叠加，不改变时深口径、插值、断线或数值。
- 原生剖面一次全样点查询同时取得振幅和 XY；水平时间面复用既有图像 LRU，缓存
  命中仍异步回调并在发射前复核身份。首次测线读取显示振幅/层位阶段。

缓存身份核对是有界变更检测，不等于全文件内容审计；不改原始 SEG-Y、时深表或
工区数据，也不增加自动转码。实际分块取数仍调用既有 DataService 公开接口。

  更新使层位缓存失效，以及可选真实资料验收。
- 同一真实测线修复后振幅初读 165ms、重复 10ms；叠加初读 6498ms、重复 4ms。

  一致，层位曲线数量一致；没有降低分辨率或跳过层位。
