# 新测线剖面读取与交付（2026-11-03）

用户反馈已有缓存修复后，新测线仍停在 70%，要求通过 DataService 读取。
现有振幅和层位都已走 DataService；问题是读口内部的逐点层位 SQL，以及宿主等待
所有层位完成后才一次性交付振幅。重复缓存命中不能解决新测线首次读取。

DataService 的改动：

- 层位采样器复用当前快照内的局部块：任意线 64×64，inline 为 1×512，
  crossline 为 512×1，外围仅补当前插值半径。没有全表点数统计或整面载入。
- 原 `inline BETWEEN ... AND crossline BETWEEN ...` 使复合索引在 inline 范围之后
  不能继续按 crossline 定位。新查询用有界 inline 枚举和等值匹配，同时利用
  `horizon_line(horizon_id,inline_no,crossline_no)` 的两维范围，避免逐块扫描整行。
- 单块先限制到 131073 行再排序；最多接受 131072 个源点，超限回退原有逐点查询。
  不以截断网格产生结果。重复点的 seq/id 顺序、显式 null、负值及局部插值规则不变。
- 叠加和地震层段取窗共用采样器；缓存不跨事务，读口仍在单一只读快照内完成。

宿主改动：

- 异步剖面在振幅转换完成后先发当前世代的不可变快照，层位随后单独叠加。
  层位回包不再重建整幅振幅图；同步调用仍交付一次完整结果。
- 新请求或关闭标签仍取消旧世代并拒绝迟到结果。振幅已显示后的当前请求取消，
  保留振幅并明确提示层位取消，避免把已成功读取的图清空。
