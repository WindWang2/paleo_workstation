# 地震剖面与连井时深对齐（2026-10-30）

## 数据与取数

连井流程从工区检索已登记地震体，以有序井口 XY 调用 Data_service 的
`extractSection`。工程 CRS／单位与体元信息必须一致，未经确认不转换坐标。
无活动 3D 体时可以使用工区唯一地震体；存在多个体时要求明确选择。
取数不构造、不等待 3D 索引；维持 64000000 振幅预算和原始采样，超预算报错。
任务继续使用并发闸、协作取消及请求世代守卫。

时深查询以主时深资产来源和本井模型 ID（或唯一精确井名）筛选数据服务关系。
单位与时间类型明确后，深度 ft→m、时间 s→ms、OWT→TWT；文件行序不变。
多份同域关系不任意取首份；未知单位／时间类型／基准不作已对齐使用。MD 优先，
同一组时间样点及基准的 TVD 轴可同时保留。TVD-only 缺 MD 换算仍明确不可用。
旧工程未绑定数据服务的文本读口保留，未知时间基准不会通过连井叠加校验。

## 对齐修正

- 原先井间波形直接接收倒序图像纹理，现改为数值 DTO，行 0 是首个时间样点。
- 原先借用界面起始时间及 3D 体采样间隔，现使用同一取数结果的真实 `t0`、`dt`。
  普通切片和任意线剖面的时间轴、拾取和追踪同步采用数据服务返回值。
- 每井独立执行 `TWT = TD(MD) + shiftMs`，平移只应用一次；严格表范围外缺值。
  TVD 显示通过已有测斜反解 MD，拉平／基准面仅改变显示，不改原始时深值。
- 井间按两端 TWT 插值，按真实时间轴和实际沿线道距读取振幅。列距非均匀时
  不能用均匀列号代替距离。反向井序保持左右井与波形端点对应。
- 两端时深及地震体的时间基准须明确一致，地震体须声明 TWT；不一致或未知时
  显示原因。时深可用性或基准变化会使井间剖面缓存失效。
- 普通切片保留 LRU；键包含文件状态和工区模型状态，读取完成再次核对来源。
