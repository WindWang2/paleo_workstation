# 井道图上的地层界线解释

后续视图修正见 [复用预览井道图](stratigraphy-preview-reuse-20261030.md)：地层页现直接
使用预览的 WellCompositePanel，深度拾取沿用预览的单击操作。

用户补充明确：`地层对比_优选外推统一模板_20261029.zip` 定义完整的地层对比模块，
原生界面必须承接其中的操作逻辑，不能只显示算法输出或支持既有线拖动。

## 示例与原生入口

| 示例能力 | 本项目入口与处理 |
|---|---|
| 加载 GR、唯一来源自动匹配、异常来源选择 | 加载井道图；计算区域界面前只集中处理无法自动匹配的输入 |
| 时深候选优选与端部趋势外推 | 原始 `selectTimeDepthCandidates`、`calculateHorizons`，保留来源、候选和外推证据 |
| 区域段统一 L3/L4 模板 | 原始 `discoverQuickReferences`、`planQuickTemplates`、分段派生及模板传播；保留人工源及候选 |
| 人工界线、精确数值、保护与候选采用 | 井道图双击拾取 MD、点击选线、拖动、右侧属性；所有写操作由功能层统一校验 |
| 新增／删除内部界线 | 拆分所在四级旋回／合并同段同父级相邻四级旋回，共用端点；保护区域界面及三级端点 |
| 旋回方向及三级组合 | 原生属性表及连续子旋回分组表；禁止只改级别数字伪造父子结构 |
| 展平后的编辑 | 视图坐标转换回真实 MD，模型仍保存绝对 MD |
| 全图、范围及图片 | 按界线范围及 4% 余量适应井段；显示深度范围、拉平后相对深度；完整井组与深度尺导出 PNG |
| 撤销／重做与失效 | 100 步几何状态；一次拖动一次提交；保留计算数组和初始深度，恢复相关 current/stale 状态 |
| 标准井模板及曲线形态分组 | 原始 `makeManualInterpretation`、`extractTemplate`、`clusterWells`；人工分组修订保留标记 |
| 算法和坐标时深参数 | 原生表单；原 profile 默认值、范围、符号及外推约定，随解释修订保存 |
| 井序、分段重算、所选模板传播 | 更多设置中的井序、全部／E12／E3／E4、曲线重算及各井各段模板确认；按同组参考井推荐，可保留本段，标准井默认保留人工解释 |
| 曲线结果、CDMT、数值和 CSV | 读取保存数组；CDMT 单独使用旋回序号轴，分页和完整 CSV 保留质量标记 |
| 历史、保存重开 | 明确选择方案和修订；保存选中新修订；读版本清除旧选择及属性；SDK 原不可变提交协议 |
| 工程保存和离开保护 | 工程保存同时提交未保存解释；提交失败继续保留工程，计算期间不能关闭或切换工程 |

`src/services/stratigraphyediting.*` 从示例 `demo/stratigraphy/stratigraphywidget.cpp`
迁入人工编辑规则，不构建控件、不执行绘制。功能层按示例先记录几何状态，
应用并校验完整解释，失败时回滚几何、曲线状态、编辑记录和脏标记；不产生半个
修改或撤销项。视图只发操作信号。
历史只保存界线、旋回、警告和曲线状态，不为每步复制全部数值数组。

已逐字节比较 ZIP 的 `src/stratigraphy` 下 9 个核心／服务源文件，当前
Data_service 副本无差异。本次不修改这些算法源码，也不新增 Web 服务。
相／亚相／微相体系和 GIS 矢量拓扑编辑不在本轮改动范围。
