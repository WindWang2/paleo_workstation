# 地层对比直接复用预览井道图

用户明确要求井道图使用已有“预览可视化”组件。本次替换 2026-10-29 接入的
`WellCorrelationPanel` 标注展示，地层页直接创建 `WellCompositePanel`，使用
`WellCompositeCanvas` 的默认图道、比例尺、深度拾取、标志层拖动及配置功能。
未新增井道绘制器；原对比画布新增的标注辅助源文件及相关接口已移除。

## 接线

- `PreviewDocService` 共用工区预览数据装配，新增按井读取入口，提供可用的 MD
  曲线和区间道；英尺显式转米，未知／非 MD 基准不冒充 MD。
- 功能层在预览数据中接入解释版本冻结的原始曲线与 MD 派生曲线，旋回序号轴
  的 CDMT 继续使用数值结果入口，不画成深度道。
- 复用 `MultiWellView`，扩展任意井数横排与深度／缩放同步，外层横向滚动。
  连线位置从既有井道体取坐标；拉平后仍向工作流提交绝对 MD。
- 预览的标志层手势只发解释编辑信号，解释工作流执行 ZIP 对应校验、撤销、
  失效标记及保存，不修改预览原始分层的 `EditSession`。
- 人工改线保留面板实例及图道顺序、宽度和显隐；非法编辑回显合法位置。
  只读工程不能通过预览的编辑开关绕过限制。
- 首次显示以井道图为主要区域；并排井的状态读数固定行高，防止读数换行使
  拉平基准面像素错位。加载解释版本保留已保存的显示范围。

ZIP 数值算法源文件和人工编辑规则未改动。QGIS 主视图、五个 Ribbon 工具页、
矢量拓扑编辑及相／亚相／微相分类均沿用已有实现。
