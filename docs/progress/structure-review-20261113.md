  重复实现的证据。QGIS 封装继续归 `src/qgis`，不把它复制进其他层。
- 历史 Python/审计/原型资料已与默认构建分离；保留追溯用途，不通过删除历史材料
  制造代码缩减。未触碰本地私有 artifacts 或其他 worktree。
- 函数扫描中另一组重合是三种地图工具的键盘事件处理；复用输入行为具有合理性，
  本批未为这十余行增加泛型工具基类。
