# 水平时间切片可配置读取线程（2026-11-04）

用户要求当前原生地震体时间切片支持 4 线程并可设置线程数。

- 水平切片工具栏增加 1 / 2 / 4 线程选择，默认 4；通过 QSettings 保存选择，
  非法历史值回到 4。沿用 DESIGN.md 原生控件与单行工具栏。
- 线程数从视图传给 SeismicTaskService，再传给 DataService 的
  `TimeSliceReadOptions::workerCount`；没有在视图里创建读取线程。
- 切换沿用现有取消、generation 和渐进瓦片路由，重新请求当前采样。
  同一数据和分辨率的缓存可跨线程设置复用，避免已完成切片重新读盘。
  非法线程数即便命中缓存也拒绝，不返回残缺最终结果。
- 任务标题显示请求线程数。分页工作区采用自身调度时禁用这个 SEG-Y 设置，
  工具提示说明适用范围；预览与完整原生切片都可设置。
- Data_service 已具备独立只读 ReaderPool 和 1/2/4 并发接口，本轮无需更新子模块。

验证：Windows 编译（最多 8 并行），`tst_seismic_reads` 与
`tst_seismic_3dui` 串行通过。新增检查覆盖三种线程数的振幅/NaN 一致、
取消后没有最终部分数组、缓存跨线程设置复用、非法设置拒绝、默认值及设置恢复。

真实 HY 外部只读地震体在 128×128 ROI、16 个分块、关闭 DataService 结果缓存时，
实际工作线程数分别为 1/2/4；振幅及测线轴一致，实测 98/65/39 ms。
系统文件缓存未控制，后续读取可能受益；这不是整个地震体切片的加速倍数承诺。

最终 exe 另输出到独立 build/threaded 运行目录，保留当前旧窗口及其未保存编辑。
旧窗口不会热更新控件，重新启动本轮二进制后可用。构建初次链接发现旧目标文件
未随头文件重编，强制重编该目标后链接完成；没有用兼容桩掩盖旧 ABI。
验收日志在该 worktree 的 build/time-workers-*.log 与
build/time-workers-real-result.txt，本地私有路径/资料不提交。
