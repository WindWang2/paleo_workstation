# 工区资料统一与默认工作流（2026-10-22）

新建工程可指定米制投影基准，来源 CRS 独立声明；井点、层位栅格、固定道长 SEG-Y 和三级相矢量派生件转换到该基准。保留 RAW 输入，不用改标签代替坐标转换。未知 CRS、非法转换、地震道头单位不匹配、变长道/扩展文本头等不支持格式均报告失败。已有工程不能直接改计算基准，需在目标基准下新建并导入。

投影层位使用 XY 与线道号拟合仿射网格并检查残差和非退化性，允许真实旋转角点；旧局部正交网格契约保持。栅格转换使用双线性重采样，原地震振幅和深度/时间单位不变。通用非相图参考件仍保留原生 CRS，由 QGIS 负责显示转换。

`tools/prepare_comp_data.py` 是本批比赛资料的显式处理工具，固定 EPSG:32649；不适用于任意未知源坐标。缺省只检查，`--apply` 才写入，完整备份在源目录之外并校验 SHA256；中断后可用同一备份 `--resume`。依赖 openpyxl、xlsxwriter、numpy、pyproj、segyio。工具不会处理以下划线开头的历史归档。

本地源目录：`<Downloads>/paleo_comp_data`。修改前备份：`<Downloads>/paleo_comp_data_before_unification_20261022`。主 XY 原本已为 UTM 49N，本次校正不一致的声明、LAS 井头、层位角点和 SEG-Y 单位，不把原有近似配准说成实测定位。LAS 曲线字节与 SEG-Y 全部振幅已和备份逐字节比较。

20 个每井 `*_单因素.csv` 和总 CSV/XLSX 已实际写入。共 520 条井层记录，402 条完整可计算，118 条保持空值及原因。厚度为 MD，用每井时深表的 TVD/MD 对照内插，不外推。同类重叠按并集，跨岩性冲突和缺口不补零；真实零值参与计算。源岩屑表含历史 GR 补齐段，结果标注混合来源，不能视为全实测。XLSX 的层厚和比值公式缓存已独立对照 CSV。

显式因子 CSV 导入时解析至不可变版本元数据；提取按井名/层位关联，拒绝歧义井名及冲突重复输入。空值阻止旧逻辑重新推断，人工维护的非空数值优先；结果记录输入版本和质量说明。

新工程默认 27 个微相，模板共 91 条完整路径，保留原七类编码；新增湖泥、浊积水道、水下扇河道、风暴砂、潮汐砂脊纹理。三类三角洲变体按需应用。工程旧分类保留，不改旧编码；外部模型仍需具备对应类别的预测能力，本次没有训练或替换模型权重。

测井顶部保留常用按钮，“更多”代理原动作并同步可用/勾选状态，保留控件查找与信号接线。单因素默认砂厚 + Surfer IDW，提取后按跨度建议网格；人工改过的网格不覆盖。只有一个主按钮完成提取和成图，未实现的置信度隐藏；孔渗无数值时隐藏。高级入口渐进展开，取消和失败原因保留。

新增数值转换、旋转网格、CSV 空值/真零、CSV 到真实成图、默认布局和自动网格测试；比赛资料导入测试通过环境变量显式启用。源数据准备工具的区间并集/冲突/覆盖回归为独立 Python 测试，避免给常规构建增加可选 Python 依赖。

本批不增加任何闸门基线条目。主 checkout 保持 master，开发和构建均在独立 worktree，未合并 PR。
