# 地震层位单元内的预测与单因素获取

## 实现

- 井相、地震相、单因素共用 `analysisunitcontext`，读取 DataService 的不可变方案修订，验证父层段与 S1–S4 身份。单因素可显式汇总父层段。
- 层段深度窗优先使用 DataService 原生井 ID；仅缺原生 occurrence 时兼容旧 catalog hash ID。原生记录缺顶底时不以旧记录覆盖。
- 单井相分析的准备检查和正式运行共用曲线、模型与层段裁剪规则。MD 预测列表只要求曲线，不再额外要求时深换算；仅时深井仍被过滤。数据管理的井道图预览显式使用整井预测模式，不受全局层段或分层记录缺失的影响；分析页仍按选中子层段运行。
- S1–S3 含顶不含底，S4 包含底界，避免边界样点重复。单因素保存原生井 ID、实际 MD 窗和层段修订，读取已存值前检查来源与几何指纹。
- 地震预测显式选择来源地震体，DataService 窗口与剖面叠加共用索引化层位插值；显式空值、域外与负时间均保留，不做取绝对值或域外外推。
- 远端地震输入和 ONNX 的层段输入为实际逐道 RMS 的 64×64 网格，保留有效覆盖掩膜与真实 CRS/范围。ONNX 要求匹配 `[1,1,H,W]` 输入和 `[1,C,H,W]` 输出；缺模型不发布替代成果。Processing 自动输入使用同源 RMS；显式栅格输入必须有相同层段修订的登记来源。
- 地震预测输出重新应用输入掩膜，并校验网格、坐标系和成果路径。切换层段取消预测及准备检查；后台失败不提交成果。
- 预测和单因素通过 catalog 派生版本登记及 DataService 结果投影统一管理。批量井预测另登记逐井子绑定，重开幂等；层段几何或输入变化使成果失效，历史修订成果保留。

## 验证

- 合成工区覆盖原生/旧井 ID 冲突、非均匀分层、S1–S4 边界分配、空值与负时间、多地震体选择、取消、重开与失效。
- 本地 HTTP 替身验证实际井相请求只携带所选子层样点；不调用外部预测服务。
- 单因素全套：50 通过、1 跳过（既有可选条件）。验证模型原生井的砂地比及层段厚度，来源删除后仍可由 DataService 取数。
- 用户既有工区只读验收：T50–T60/S1 有 86 个完整井窗、38 口有曲线的井、708 条查询样点、1433 个有效地震网格单元；测试不导入、不改库、不发布预测。
- 源码闸门、最终回归、编译与启动结果见本 PR 验证记录。测试日志及用户资料不提交版本库。

## 预览入口修正

数据管理的 XML、模型原生井及 LAS 入口显式创建整井预览面板。全局分析层段缺失、
当前井没有所选父单元记录或切换地图层段，都不再影响预览预测；单井相分析的
S1–S4 窗口和成果身份保持原有契约。合成 HTTP 测试验证：无效全局层段下预览仍
提交整井 128 点，层段分析仍只提交目标子层 32 点。

预览遇到无效测井值或采样缺口时分成连续有效井段，分别满足模型最小窗口后提交，
缺测和过短段保持空白并记录跳过原因。严格层段分析口径不变。合成缺测测试验证
128 点中间缺 1 点时发出 64/63 两个连续请求，返回相段不跨缺口，也不凑窗口。
当前不可预测时点击按钮会显示明确原因，配置问题仍进入预测服务设置。
显式点击整井预测后，任务结束自动定位到首个预测深度和预测相道，避免结果在当前
视口之外；缓存恢复不主动移动用户视角。

用户指定 HZ19-2-1 的本地资料验证不再因 3865.38 m 的 GR 空值而整井拒绝；
单 GR 输入可取得 23083 点。进一步按用户已授权的真实服务配置和实际模型要求运行，
返回 1507 个预测样点、59 个相段。验收程序不绑定 catalog、不改项目库；网络结果
按正常工作流缓存，未提交私人资料或生成结果。井相套件 50 通过、2 个既有可选跳过。

预览画布上下各只有一个信息行。隐藏道及完整图例保留菜单入口，坐标放井名提示，
数据列表切换收进更多，表格和读取失败模式仍可返回井道图。布局测试验证画布获得
扣除两行后的剩余高度；默认分析面板保留原有控件。

## 真实推理边界

当前未提供地震 ONNX 模型，因此验证真实数据输入、无模型处理和成果数据流，不宣称完成真实地震相推理。井相真实服务验证见上文。稀疏 RMS 网格不等同于原始全体三维振幅；模型必须按此输入契约训练/声明。

预览总套件 `tst_datapreview` 在工区初始化辅助 `makeStack` 返回前超时（300 秒，
定向重现同样超时），未能完成该套件；井相及默认井道套件通过。此限制单独记录，
不以删除用例或增加基线规避。
