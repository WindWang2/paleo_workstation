# 地震层位单元内的预测与单因素获取

## 实现

- 井相、地震相、单因素共用 `analysisunitcontext`，读取 DataService 的不可变方案修订，验证父层段与 S1–S4 身份。单因素可显式汇总父层段。
- 层段深度窗优先使用 DataService 原生井 ID；仅缺原生 occurrence 时兼容旧 catalog hash ID。原生记录缺顶底时不以旧记录覆盖。
- 井相准备检查和正式运行共用曲线、模型与层段裁剪规则。MD 预测列表只要求曲线，不再额外要求时深换算；仅时深井仍被过滤。绑定工区上下文的井道图预测范围随顶部层段选择，避免两套范围冲突。
- S1–S3 含顶不含底，S4 包含底界，避免边界样点重复。单因素保存原生井 ID、实际 MD 窗和层段修订，读取已存值前检查来源与几何指纹。
- 地震预测显式选择来源地震体，DataService 窗口与剖面叠加共用索引化层位插值；显式空值、域外与负时间均保留，不做取绝对值或域外外推。
- 远端地震输入和 ONNX 的层段输入为实际逐道 RMS 的 64×64 网格，保留有效覆盖掩膜与真实 CRS/范围。ONNX 要求匹配 `[1,1,H,W]` 输入和 `[1,C,H,W]` 输出；缺模型不发布替代成果。Processing 自动输入使用同源 RMS；显式栅格输入必须有相同层段修订的登记来源。
- 地震预测输出重新应用输入掩膜，并校验网格、坐标系和成果路径。切换层段取消预测及准备检查；后台失败不提交成果。
- 预测和单因素通过 catalog 派生版本登记及 DataService 结果投影统一管理。批量井预测另登记逐井子绑定，重开幂等；层段几何或输入变化使成果失效，历史修订成果保留。

## 验证

- 合成工区覆盖原生/旧井 ID 冲突、非均匀分层、S1–S4 边界分配、空值与负时间、多地震体选择、取消、重开与失效。
- 本地 HTTP 替身验证实际井相请求只携带所选子层样点；不调用外部预测服务。
- 单因素全套：50 通过、1 跳过（既有可选条件）。验证模型原生井的砂地比及层段厚度，来源删除后仍可由 DataService 取数。
- 用户既有工区只读验收：T50–T60/S1 有 86 个完整井窗、38 口有曲线的井、708 条查询样点、1433 个有效地震网格单元；测试不导入、不改库、不发布预测。
- 源码闸门、最终回归、编译与启动结果见本 PR 验证记录。测试日志及用户资料不提交版本库。

## 真实推理边界

当前未提供地震 ONNX 模型，因此验证真实数据输入、无模型处理和成果数据流，不宣称完成真实地震相推理。外部井相服务的真实预测也未在本次验证中调用。稀疏 RMS 网格不等同于原始全体三维振幅；模型必须按此输入契约训练/声明。
