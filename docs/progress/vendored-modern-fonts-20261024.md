# 现代字体内置与跨平台验证（2026-10-24）

用户要求更现代的字体并vendor，确保Windows与Linux无需单独安装字体。本批将正文、
标签与新建图件的默认字体改为 **IBM Plex Sans SC**，同步更新DESIGN的字体规范。
字阶仍为正文9pt、标签8pt、标题12pt、图件标题15pt，保持现有专业工具密度与DPI缩放。
数值、坐标与深度仍用JetBrains Mono；Noto Sans SC保留为内置缺字及旧工程回退。

## 交付

- IBM官方`@ibm/plex-sans-sc` 1.1.0，完整、未改动的hinted OTF：Regular 400、
  Medium 500、SemiBold 600、Bold 700；不只截取当前界面的汉字，也不依赖系统合成字重。
- 上游固定在`71f558992315a12ca1f06a2215d57962a1992162`，文件URL、大小与SHA-256
  保存在`resources/fonts/ibm-plex.lock.json`。字体及许可按原字节检出，避免CRLF转码破坏校验。
- 字体编进原有Qt资源，Qt自动选择其构建支持的资源压缩算法；降低字体资源压缩阈值，
  本机全部字体资源包约28.1MB（含原有Noto及JetBrains），运行时不下载、不查源目录。
- 字体注册每进程一次，切主题不再重复解析、注册整套CJK字体。注册同时核对字体家族，
  失败保留原有回退行为。新建图件的标题、图例和井相注记同步使用新默认字体，
  不改写旧工程中保存的显式字体。
- 原始SIL OFL 1.1及来源说明进入资源、安装树`share/paleo/licenses/fonts/`和
  “帮助→关于→显示详细信息”。宿主Web页面的CSS优先家族同步；独立工作台源码和服务
  仍由外部项目持有，本次没有改动外部工作台。

## 验证

Windows Qt 6.11.2 / MSVC RelWithDebInfo：

- 主程序、selfcheck及相关测试构建通过，最大并行度8，Qt测试串行。
- `tst_uxtheme`、`tst_decorations`、`tst_layoutexport`、`tst_shortcuthelp`、
  `tst_stratigraphicweb`五组ctest通过；最后字体主题套件38通过、0失败。
  独立外部工作台的实服务烟测仍为按环境启用的可选用例。
- 新测试核对真实字体家族、OS/2真实字重、常用地质汉字/英文/数字字形、
  等宽中文单位无缺字、资源SHA-256和主题切换不重载字体。
- 原生`windows`平台分别在100%、150%、200%缩放运行7个字体功能用例
  （每次含初始化/清理共9通过），并输出新旧字体的明暗对照。
- 主流程与次级界面原生快照两例通过（含初始化/清理4通过），人工检查明暗界面及
  正文、表格、标题没有因字体替换发生可见缺字或新裁切。
- `cmake --install`到任务临时前缀通过，字体许可与锁定清单随安装树交付。

Linux（WSL Arch Linux，Qt 6.11.2）：

- 将本仓同一`paleo_fonts.qrc`编译为二进制资源，以独立Qt Widgets探针验证，
  不是一次全量QGIS应用重构建。字体仅从该资源注册。
- 1×与2×缩放均命中IBM Plex Sans SC四个真实字重，核对OS/2的400/500/600/700，
  中文、英文、数字及等宽中文单位混排无缺字；两种缩放下逻辑文字宽度一致。
- 字体文件和字号单位一致；Windows与Linux原生光栅器的抗锯齿允许细微差异，
  不承诺两平台逐像素相等。

12项源码闸门通过，所有基线未增加。本机验证产物位于`artifacts/modern-fonts/`，
包括明暗新旧字体对照、主流程截图、Linux资源探针结果和安装记录；不将构建产物入库。
