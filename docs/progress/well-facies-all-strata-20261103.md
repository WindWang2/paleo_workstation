# 井相模型可用于全部地层段（2026-11-03）

用户明确模型适用于全部地层段。此前把服务返回的 `formationGroup=恩平组`
解释为适用范围约束是错误的，造成其他组/段被拒绝，并使整井预览漏掉有效测井。

## 行为

- `prepareWellFaciesInput` 不再根据模型标注筛选井段。模型标注保留原值，用于追溯；
  多模型可据标注安排默认优先级，但未匹配的实际地层组使用所选/默认模型，绝不因
  组名不同拒绝预测。预览按实际地层组组织任务，每个样点只预测一次。
- 批量井相、单井分析和兼容编图的当前地层预测均覆盖此规则。分析页继续使用
  DataService 冻结方案的所选地震子层段；未扩大范围、未补值或伪造样点。
- 所需曲线、段名、岩性、有效样点数、连续性及 MD/单位校验继续生效。
- 模型要求、按钮帮助和中英文说明明确“全部地层段可用”，不再将模型组名作为门槛。
