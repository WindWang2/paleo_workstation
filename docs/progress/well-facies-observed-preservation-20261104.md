# 原始沉积相被预测回写覆盖（2026-11-04）

原始 XML／DataService 导入记录没有被预测改写，问题发生在宿主的可维护井段和
分层相属性。预测除单独建立“预测相”道，还经 `publishAttributes` 自动回写这些表。
`onlyMissing` 原来以相编码或 manual 标记判断已有解释，只有相名、没有编码的
原始解释会被视作空白，随后相／亚相／微相被模型值替换。刷新属性后，“沉积相”
道会显示该工作表，因此单纯区分两个图道不能避免这个持久化问题。

修复：任一级相名、已有相编码或 manual 标记都足以保护原解释，整套层级、编码及
纹理保持原值，包括原来空着的字段。预测结果、模型和任务元数据独立更新；再次
预测时，即使解释字段已齐全，也必须更新变化了的预测元数据。显式人工编辑仍可
改工作解释；无原解释井段原有的预测补空行为保留。

验证先复现后修复：未编码完整层级、仅大相、仅亚相、仅微相，以及未编码的地层
优势相共 5 种情况在旧实现均失败。新增回归还覆盖有编码解释、原始空字段、预测
切分井段、磁盘重读、再次预测及原始输入对象保持不变。

本次补丁保护后续自动预测；不据当前相名猜测历史人工修改，也不批量反写历史工程
属性。历史已经回写的值需要与原始资料核对后恢复。编译、完整相关回归与源码闸门
结果见 PR #901。
