# 三维（3D）

> wave/seismic-chain-deep · Phase 3 交付（D3.1–D3.12）
> 组件：`seismic3dviewportwidget`（GL 视口）、`seismicslicerenderer`（切片/
> 堆叠层渲染）、`volumeframerenderer`（包围盒/井/多体）、`seismiccameracontroller`、
> `seismic3dcolormap`（D3.5）、`seismic3dfallback`（D3.9）、`seismic3dviewpanel`（面板）

## 1. 渲染架构

```
paintGL
 ├─ SeismicSliceRenderer（内联着色器：uAlpha uniform + alpha<0.02 discard）
 │   ├─ 4 槽位四边形（IL/XL/Time/Line ribbon）
 │   └─ 体渲染堆叠层 ×16（D3.1）：深度写关+混合，水平面序无关
 ├─ VolumeFrameRenderer（GL_LINES）
 │   ├─ 包围盒 12 边 + 任意线路径高亮
 │   ├─ 井轨迹（白晕+蓝线）+ 标志层十字（D3.4）
 │   └─ 第二工区轮廓（青色，D3.12）
 └─ FPS 叠字（D3.10，QPainter 组合）
```

固定盒几何 `HorizontalScale=6.0 × HeightScale=4.4`（非真实纵横比——井震
标定语义在 2D 剖面，3D 是体浏览面）。切片纹理：vendor `ColorizeValues`
预烘焙 rgba 直传；**自定义色标/值域激活后**走 `Seismic3DColorMap::colorizeSlice`
CPU 重着色（缓存 values 保真副本 → LUT → 字节级 RGBA → 带外 alpha=0）。

## 2. 各交付项落点

| 项 | 行为 |
|---|---|
| D3.1 体渲染 LOD | 「体渲染」开关：16 层水平切片按体积分布半透明叠渲（uAlpha×0.55）；滑杆按下自动降 4 层、松手 350ms 后回 16 层（`setStackLayerCount`） |
| D3.2 切片可拖拽 | `pickSliceAt`：4 角 MVP 投影 + 点在凸四边形内测试（符号一致法）；拖面 → `sliceDragged(slot, idx)` → 面板滑杆 → `inlineChanged/crosslineChanged` → 数据页 `openSeismicLine` 联动 2D 剖面；Ctrl 按住强制旋转 |
| D3.3 透明度/裁剪 | 透明度滑杆 0.1–1.0（渲染期 uniform）；值域 min–max 带外像素 alpha=0 → 着色器 discard |
| D3.4 井位 | `Seismic3DWell{inlineNo, xlineNo, bottomFrac, tops[]}` → 井轨迹+标志层十字；调用者负责 XY→测线号与时深→比例换算 |
| D3.5 colormap | 8 预设（`Seismic3DColorMap::presetNames`）+ 自定义控制点编辑器（"pos #RRGGBB" 每行）+ 反转；`buildLut()` 线性插值 256 档 |
| D3.6 相机 | 预设（等轴测/俯视/正视/侧视）+ 相机书签（`CameraState` 快照，QSettings `seismic/3dCamBookmarks` 全局持久化） |
| D3.7 截图 | 「截图」→ `grabFramebuffer()` → PNG |
| D3.8 内存预算 | `checkMemoryBudget`：体字节 > RAM/2 → 橙色提示条 + 分页通道建议（`sysconf`/`GlobalMemoryStatusEx`） |
| D3.9 GL 回退 | 3s GL 看门狗（`glWatchTimer_`）无上下文 → `Seismic3DFallbackWidget`：2D 三切片并排 CPU 渲染 + 原因说明条 + 驱动建议；切片数据照常喂入 |
| D3.10 帧率 | 「fps」调试开关：0.5s 滚动均值右上角（JetBrains Mono） |
| D3.11 惯性 | 松手速度衰减 0.92/帧续转（16ms 节拍，<0.6 停）；`setInertiaEnabled` 可关 |
| D3.12 多体 | `setSecondaryVolume`：第二工区测网范围按主工区坐标系归一 → 顶面轮廓线 |

## 3. LOD 通道（与转码联动）

仅 `.sf3p` 显式通道：`startPagedOpen`（progressiveLod 从最粗层起步）→
拖动 `switchLod(coarsest)` → 静止 350ms `switchLod(0)` + 重取。

**wave/deepen-perf（A2 拖动链路取数合并）**：

- **粗层首见自动精化**：progressive 打开 + 初始三槽粗层贴图后，静止 350ms
  自动升 L0（此前要等用户拖一次滑杆——默认视图永远停在最粗层）。
- **在途请求顶替取消**：槽位在提取中新值到来 → pending 记录 +
  `requestCancel()` 在途任务（引擎 CancelToken 协作中止）——被拖过的索引
  不再占用整段读取时长；本端主动取消不再刷「提取失败」告警日志。
- **精化只补脏槽位**：`refreshVisibleSlices(onlyStale)` 跳过「内容已是 L0
  且索引未变」的槽位（`slotCoarse_` 按派发时 LOD 层级标记）。拖动只动
  一个滑杆时改前每手势固定 3 请求，改后 1 请求。
- **体渲染堆叠层体窗合并（A1）**：paged 通道且体量估算 ≤256MB 时
  `requestStackLayers` 改走**单次 `ReadVoxelWindow`**（全网格全采样窗，
  引擎按激活 LOD 缩减 IL/XL），16 层平面经
  `SeismicTaskService::slicePlaneFromWindow`（行 0=最大 inline 显示向，
  与 `ReadTimeSlice` 逐位同构）+ `SgyVolume::Recolorize` 预烘焙后贴图：
  **16 次逐层切片请求 → 1 次体窗请求**。直读/工作区后端不走此通道
  （引擎体窗是逐道顺序整读，逐层窄读反而更省）；估算超预算（大体量+细层）
  如实回落逐层并留告警日志。

**请求数对照（tst_seismic_3dui，24×24×128 paged 夹具，L1+L2）**：

| 场景 | 改前 | 改后 |
|---|---|---|
| 一次拖放手势（press→8 连发→release→精化收尾）的切片请求数 | 5 | 3（交错好时 2） |
| 体渲染堆叠开（16 层）取数请求数 | 16（逐层切片） | 1（体窗） |
| 初始打开后自动精化到 L0 | 不发生（需用户拖动） | 350ms 静止即精化 |

## 4. 性能（tst_seismic_budgets / baseline）

- 栅格化 0.054ms/帧（RTX 3080 FBO 同步）——瓶颈在提取 I/O 不在 GL
- **体渲染满配（16 堆叠层+混合+线框）0.075ms/帧（13,333 fps 同步口径）**
  ——堆叠混合的栅格化增量 ~0.02ms/帧，交互帧预算（≥15fps）余量 3 个量级
- LOD 交互态 15000fps（预算 ≥15fps，D6.2）
- 头 less GL 全链（FBO+着色器+堆叠+井）无崩（D7.6 断言）
