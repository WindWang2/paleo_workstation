# 单井综合柱状图用户指南

> wave/wellcomposite-deep 深度升级交付。适用组件：`WellCompositePanel`（数据页/
> 预览入口打开）、`MultiWellView`（多井对比容器）。

## 1. 打开柱状图

- **综合柱状图 XML**（辅助资料）：数据页选中井头资产 → 预览。面板标题徽章显示
  「参考井: XXX」（琥珀），因其只出现在辅助资料。
- **LAS 曲线**：数据页井 → 曲线预览。徽章「井号: XXX」（蓝，测区井）。
- 加载后自动恢复上次会话的道序/道宽/显隐/打印开关（按「项目 + 井」记忆，
  QSettings；数据本身永不被改动）。

## 2. 界面布局

```
┌───────────────────────────────────────────────────────────┐
│ 井名徽章 | 比例尺 | 缩放 | 跳深度 | 书签 | 吸附 | 道配置 |  │
│          导出 | TOPs 编辑        [ 大字号深度读数条 ]      │
├───────────────────────────────────────────────────────────┤
│ 道头区（三行：标题|刻度|单位，拖拽换位/分隔线调宽）          │
│ 道体区（滚轮锚点缩放 / 拖拽漫游 / Shift+拖拽区间统计）       │
│ 隐藏道管理条（chip 列，点击恢复）                           │
│ 底部：物理比例尺条 + 全井迷你导航条                         │
└───────────────────────────────────────────────────────────┘
```

## 3. 深度交互（D2.x）

| 手势/入口 | 行为 |
|---|---|
| 滚轮 | 以鼠标位置为锚缩放（可在设置中改为中心锚） |
| Shift+滚轮 | ×5 加速缩放 |
| Ctrl+滚轮 | ×0.2 微调缩放 |
| 左/中键拖拽 | 深度漫游 + 水平道平移 |
| Shift+左键拖拽 | 橡皮筋区间 → 弹区间统计（各曲线 min/max/mean/std、岩性占比、标志层计数，一键复制 TSV） |
| 双击道体 | 复位全井；双击深度标尺道 = 添加文字钉注 |
| 右键钉注线 | 编辑文字 / 跳转 / 删除 |
| Ctrl+G / 跳深度按钮 | 跳深度对话框（井深范围校验） |
| 书签菜单 | 视口顶部加命名书签 / 点击跳转 / 清除 |
| 吸附开关 | 深度滚动吸附整刻度与标志层线 |
| 迷你导航条 | 点击/拖拽全井定位 |
| 缩放上下限 | 最小显示段 10m、最大整井（超出自动夹取） |
| 标志层 gap | 间距 > 阈值时琥珀带高亮（面板 API setGapThresholdMeters） |

钉注与书签持久化到源数据旁 `<源名>.wc.json` sidecar（不污染源数据）。

## 4. 道管理（D1.x）

- **拖拽换位**：按住道头拖到目标位（蓝色投影线指示），松手提交，Esc 取消。
- **分隔线调宽**：道头分隔线处左右拖（≥24px）；宽度随「井+项目」会话记忆。
- **右键菜单**：隐藏 / 复制 / 导出该道 CSV（UTF-8 BOM）/ 跳深度 / 道配置 / 删除
  （深度标尺道不可删）。
- **道配置**（双击道头或菜单）：类型、标题、道宽、打印导出开关；曲线族道另含
  多曲线组合编辑器（勾选曲线集进同一道、各曲线独立量程线性/对数、单位、颜色、
  预置颜色集一键应用、重叠网格开关与密度）。
- **隐藏道管理条**：底部 chip 列出隐藏道，点击恢复。
- **tooltip**：悬停道体显示曲线名/当前深度值/量程/单位（或区间内容）。
- **键盘**：Tab/Shift+Tab 道间焦点（焦点环），Enter 打开焦点道配置，
  ↑↓ 滚动，+/- 缩放，Esc 逐级取消。

## 5. TOPs 编辑（D3.x）

1. 工具条「TOPs 编辑」进入编辑模式（道头染橙；只读资产会拒绝并给原因）。
2. 标志层线（琥珀虚线）直接拖拽改深度（松手吸附整刻度）；右键标志层改名/
   删除/插入。
3. 编辑进入 undo 栈（工具条撤销/重做，操作名显示，栈深 50）；脏状态跟踪。
4. 「保存」产出**派生版本文档**（RAW 源永不覆盖）：面板发
   `derivedDocumentReady(doc, manifest 摘要)` 意图信号由壳落 catalog 版本链；
   审计历史同时写入 sidecar 与派生 XML 的「编辑审计」工作表。
5. 源文件被外部改动（mtime 变化）→ 编辑时弹冲突警告（重载/分叉）。
6. 批量导入：CSV/剪贴板 `name,top[,base]`（逗号/Tab），预校验给行级错误与
   同名深度冲突报告，确认后应用（同名不同深=移动）。
7. 地层指派：未识别层名（如 A/C1）→ 显式指派系/统/组/段（程序不猜），
   存 sidecar，不污染源数据。

## 6. 导出与打印（D4.x）

导出菜单：PDF（矢量多页、页眉井名/项目/日期/比例尺、按比例尺分页）、
PNG（≥300dpi 等效）、SVG、打印、导出预设（sidecar 管理）。导出走导出档
渲染参数（全抗锯齿、曲线加粗），未开「参与打印/导出」的道自动跳过。
自动图例：当前井用到的岩性花纹/相纹理/曲线量程/标志层排两列图例区。

## 7. 多井对比（D5.x）

`MultiWellView` 容器：单井/双井并排/四井 2×2。锁步深度滚动（可开关）、
同名标志层 correlation 连线（可开关）、基准面校平（任选标志层对齐各井）、
井选择器（测区井蓝/参考井琥珀分区）、对比模板（井集+道集 sidecar 存取）、
井间层段厚度差表（TSV）。

## 8. 深度变换（D6.x）

- MD↔TVD：井斜测量表存在时最小曲率换算；缺表禁用并给原因 tooltip。
- 海拔基准：补心高程 KB 存在时 TVDSS = KB − TVD。
- 深度单位 m/ft：显示层换算，数据不动。
- TWT 副刻度列：时深表存在时深度标尺左列并列显示。
- 大图缩放曲线 LOD 抽稀（min-max 桶保极值）。

## 9. 主题与可达性（D7.x）

柱状图画布保持纸面白底（地质文档隐喻，DESIGN.md 2026-09-29 决策）；
面板/对话框 chrome 跟随明暗主题。高对比模式提升次级刻度/文字对比度。
空数据时画布给原因提示而非空白。
