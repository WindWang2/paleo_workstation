# 层位编图工作台

在「智能预测 / 单因素图 / 智能编图」右栏选择「编图流程」。智能预测/智能编图的原处理算法、厚度链、发布与 PDF 工具保留在「高级工具」；单因素的提取、约束与插值方法直接位于默认「编图流程」，旁页「图件与版本」保留图件历史操作。先打开工程，再选择画布上方的编图层位；尚无栅格的层位也可选择并开始预测。

## 1. 智能预测

- 地震解释层位在「数据管理 → 地震 → 层位」浏览；导入后保留原始 DAT，并登记对应层位及时间栅格。层位窗聚类可直接使用原始文件中的 Inline、Crossline 和时间，也可在「层位文件」选择工程外的 SMI DAT。
- 地震预测选择一个已导入、关联工区角点的地震体；生成带空间范围的 GeoTIFF 相栅格。
- 测井预测勾选一口或多口已有有效井位、测井文件和当前地层分层的井；复用测井面板「预测服务」的地址与 API 密钥，按远端模型要求上传实际曲线、段和维护后的岩性。逐井、逐地层组调用远端服务（支持 202 任务轮询），生成一份当前地层的测井预测点矢量：每井一点，相属性取该地层内累计厚度最大的相，同时保留相厚度、占比、覆盖率及模型/任务来源。
- 测井远端结果同时更新工区共用的井段与地层相属性表；仅覆盖实际返回井段及有预测观测的地层，保留岩性、自定义列和其他井。未配置服务、缺少当前分层、输入不可用、服务失败或取消时不发布结果。地震层位窗聚类仍是明确标注的 Mock 模式。
- 当前层位优先取工区维护的地层顶底深；原始分层先读取主关联。主分层不含当前层位时，读取唯一包含该层位的已关联分层文件，并把实际分层版本纳入图件来源。多份候选来源存在歧义时，提示在数据管理中指定主关联，不自动映射不同地层名称。
- 测井预测在参数区和任务中心显示读曲线、获取模型、远端推理、统计地层相及登记图件的进度。任务阶段直接显示在任务行，参数区在结束后保留完成或失败状态。
- 完成后自动在当前层位显示新结果；若任务期间切换了层位，结果仍保存到提交时的层位。
- 在结果表选中相栅格，点击「相栅格转相面」。连续单因素栅格需先设置分相阈值。转面默认做一遍 3×3 多数平滑，再把小图斑吸收进相邻最大相斑：阈值取 `MIN_CELLS`（默认 4 像元）与 `MIN_FRACTION`（默认占有效区 0.25%）的大者——大栅格上按占比吞掉逐像元聚类的碎斑，高级工具里可调。

## 2. 单因素图

单因素图是沉积相与储层物性编图的核心基础图件。系统支持从钻井样点属性出发，在断层硬隔断、走向引导线及相边界软约束的共同控制下，生成连续属性分布栅格。

### 2.1 成图流程与算法选择

1. **井点因子提取**：勾选一个因子，在「井点因子」选择**直读字段**或**比值（分子 ÷ 分母）**。下拉只列工程真实数值字段；有主分层与解释岩性/岩屑段时，还列「分层层厚（MD，m）」和「解释砂岩厚度（MD，m）」。选择砂厚作分子、层厚作分母得到同层段砂地比；井段按当前编图层位及其下一底界裁剪，重叠砂段合并。缺层界、覆盖不足、冲突解释、零分母和缺井位在结果表逐井记因，不猜测井值，不把其他数值字段冒充选定因子。孔渗目前直读已有属性；净毛比需另定有效层判据。点击「提取井点因子」，查看各井因子值与来源/缺失原因。有效井点保存为工程 DERIVED 点图层；改变层位或口径会清空旧预览，生成图时按当次口径重新提取，并把该不可变点版本作为插值输入。原始井资料保持不变。地层厚度的整面引擎继续通过顶/底构造面相减，井段 MD 层厚用于独立核对。
2. **约束线导入与绘制**：导入已有地质约束线，或点击「画布绘制约束线」逐点交互绘制并右键闭合。导入文件需预先配准至当前工程局部米制 CRS。约束线分**方向线族**（方向引导、解释软边界、制图绕行）与**打断线族**（硬屏障、等值停止——完全阻断/仅显示停线/不阻断）；两族的类型及新线参数直接保存，已绘线的参数修改需在次级「编辑已绘约束 / 其他形状」面选线并保存。地质语义三类：
   - **硬屏障 (Hard Barrier / Fault)**：构造断层，切断连通域并采用测地绕距计算；
   - **走向引导线 (Direction Guide)**：物源方向、河道延伸轴向或构造走向；
   - **解释软边界 (Interpretive Boundary)**：相变过渡带、沉积相带边界或储层尖灭线。
3. **选择成图算法**：
   - **局部反距离加权 (Local IDW)**：经典的距离反比加权，支持走向引导张量变形与断层绕距；
   - **普通克里金 (Ordinary Kriging)**：基于空间自相关变差函数的地质统计学最优线性无偏估计（BLUE），全面支持走向各向异性与平滑软边界约束；
   - **协克里金 (Co-Kriging)**：以致密连续属性（如地震属性、构造趋势）为次级协变量，与稀疏井样点协同插值。
   其余方法参数各列：结构 IDW 用成图边界与格网分辨率；局部 IDW 有幂次、支撑邻域、井群权重；Surfer IDW 有幂次与全局各向异性；地统 Kriging/SGS 显示模型、块金、拱高、变程、方位和邻域，SGS 另列实现数、种子及集合保留；旧 IDW 无可调参数。方向比值/影响半径是逐线参数，仅方向 IDW 族使用；局部 Kriging 的方向/软边界权重不参与求解并列入 issues，地统 Kriging/SGS 不消费逐线屏障参数。Ribbon「插值计算」按钮显示所选方法，并触发同一生成入口。
4. **生成与派生**：点击「生成单因素图」。约束源、样点集均在任务启动时生成不可变输入快照。计算完成后在结果表选择连续栅格，配置等值线步长并提取等值线。真实数值等值线来自分析场；「解释性绕行」来自独立制图工作场，不能用于定量融合/分相/统计。砂地比等无长度量纲因子的间距不显示 m。原始井字段 IDW 的兼容入口单独收起；成图方法中的旧 IDW 同样经过本次井点提取。

### 2.2 克里金约束语义消费机制

在普通克里金成图模式下，系统深度消费地质约束线语义，确保插值曲面具备地质真实性与数值严密性：

- **走向引导线 (DirectionGuide) 调制局部各向异性**：
  克里金并非全局单一各向异性，而是采用 Moving Local Anisotropy (MLA) 黎曼度量张量场机制。根据待估点与引导线走向夹角及引导强度，构建局部黎曼度量张量 $M(x_0) = I - g(x_0) r T(x_0)$，将样点间欧氏距离变换为有效测地度量 $h_{\text{eff}} = \sqrt{\Delta x^T M(x_0) \Delta x}$。变差函数协方差等值线沿引导线走向展布、垂直走向收缩，实现地质轴向引导。
- **解释软边界 (InterpretiveBoundary) 连续距离膨胀**：
  相较于硬屏障的直接隔断，软边界表征地质属性的平滑相过渡。系统采用 $C^\infty$ 连续可微距离膨胀公式：
  $$\text{opposite} = (1.0 - q_{\text{Side}} \cdot w_{\text{Side}}) \times 0.5$$
  $$\text{penalty} = \max(\text{penalty}, \text{strength} \times \text{gate} \times \text{opposite})$$
  $$h_{\text{eff}} = \frac{h}{\sqrt{1 - \text{penalty}}}$$
  样点跨越软边界时有效距离平滑膨胀、权重连续衰减；边界正上方两侧惩罚严格对称相等。该机制彻底消除了传统 Heaviside 阶跃引入的 26.93% 跨界断崖跳跃与边界线尖点 V 形折痕，确保曲面处处连续光滑且严格精确过井。
- **诚实回执 (Honest Receipts) 审计元数据**：
  算法在求解前后严格校验约束条件，在派生结果的质检元数据（QC `issues`）中输出真实入模核算回执：
  - `direction_guide_applied:<count>`：真实参与克里金张量场调制的走向线数量；
  - `soft_boundary_applied:<count>`：真实参与距离膨胀的软边界数量；
  - 对无法有效耦合的井丛去簇（`wellClusterLocality`）等语义保留诚实未消费原因，杜绝虚假上报。

### 2.3 协克里金 (Co-Kriging) 协同成图工作流

当工区钻井稀疏（如评价初期或深层系井网稀疏），但具备全区覆盖的连续次级信息（如地震三维属性切片、地震波阻抗反演体、古地貌趋势面）时，推荐采用协克里金方法：

1. **次级协变量图层配置 (`covariateLayerId`)**：
   在作业参数中指定有效的次级栅格图层标识 `covariateLayerId`。
2. **共置相关性分析与正定性保护**：
   工作流在主变量井位处对次级栅格进行双线性内插采样，自动计算主变量与次级变量之间的 Pearson 样本相关系数 $\rho$。为避免强相关导致鞍点协方差矩阵奇异，系统将 $\rho$ 严格钳制在 $[-0.99, 0.99]$ 区间，采用 Markov MM1 交叉变差函数模型（$\gamma_{12}(h) = \rho \cdot \gamma_1(h)$）自洽构建 $(n_1 + n_2 + 2)$ 阶双乘子鞍点线性方程组。
3. **诚实报错拒绝机制**：
   协克里金方法以次级变量的存在为数学前提。若 `covariateLayerId` 为空、未配置或所引用的图层不存在/非有效栅格，工作流在 `prepare` 阶段立即报错拒绝（`tr("协克里金方法需要有效的次级协变量图层 (covariateLayerId)")`），终止任务且绝不回落为假伪克里金或普通 IDW，确保数据血缘的真实性。
4. **双重产物栅格发布**：
   协克里金计算完成后，自动向工程资产库发布两套协同产物：
   - **主因素估值栅格 (`factor.tif`)**：融合了主变量高精度井控与次级变量高密度空间纹理的插值图；
   - **不确定性方差栅格 (`variance.tif`)**：克里金估计方差分布图，直观展现预测不确定性。在次级变量强相关区域，估计方差较普通克里金显著降低。

约束源、每次约束快照、单因素栅格、方差栅格与等值线均登记到工程文件目录；旧结果保留可供对照。

井点因子、约束、栅格和等值线均登记工程版本与父输入。色带继续遵守因子语义配色；等值线采用墨/白双描边和 JetBrains Mono 数字，`level`/`ELEV` 均带沿线白 halo 注记。注记密度与线宽统一在 `FactorStyleWriter`，详见 DESIGN.md「单因素地图符号」。明暗主题使用同一地图符号，图层名称始终区分数值分析与解释性产物。

## 3. 智能编图与人工编辑

- 自动编图：勾选当前层位输入，用上下移按钮调整优先级。第一个有效相值优先；预测相点使用类别最近邻。连续单因素使用按相类别顺序填写的 N−1 个递增阈值（例如三类相填写 `10,25`）。不同量纲单因素应分别分相后再组合。输出综合相栅格与相面，保留输入顺序与阈值。
- 已有相图：选择矢量相图，点击「复制底图并编辑」。QGIS 原生要素、顶点、撤销、属性编辑作用于独立工作副本。
- 保存编辑：画布「保存编辑」提交成功后自动生成图件新版本；也可在工作副本选中状态使用「保存图件新版本」。原预测和历史版本保持只读。
- 多窗参考：选中图件后点击「打开参考窗口」。每次打开一个独立画布，可平移缩放；切换主图层位后参考窗保留原图。要参考其他层位，先切到该层位打开参考窗，再回主图。
- 删除图件：确认框列出所选图件及关联派生图件的名称、版本数；确认后原子删除整套目录记录，清理图层声明、受管文件及工作副本，刷新列表和画布并关闭已删除图件的参考窗。任一图层仍在编辑，或被非图件资产引用时拒绝删除并显示原因。目录提交失败恢复声明。

## 图例与文件追踪

相分类（编码、名称、颜色）按层位单独保存。未配置时提供明确标记的 Mock 分类。图件保存生成时的分类快照，因此后来修改当前分类不会重解释历史图件。

主画布前景显示左上指北针、左下比例尺、右上层位相图例。连续单因素显示数值色带图例，约束与等值线不套用相类别图例。选中历史图件时显示其版本相分类。参考画布使用自己的图件分类。

文件链以 `artifacts/metadata/catalog.json` 为主：

```text
源文件版本 + 层位相分类版本
  → 预测栅格 / 预测井点
    → 综合相栅格（输入顺序、阈值）
      → 相面
        → 人工工作副本 → 编辑快照 v1 → 编辑快照 v2
约束源 → 约束快照 + 样点快照 [+ 次级栅格] → 单因素栅格 (factor.tif) [+ 方差栅格 (variance.tif)] → 等值线
```

不可变结果在 `artifacts/derived/<asset>/<version>/`，人工工作副本在 `artifacts/working/<draft>/`。每个派生版本记录父版本、层位、参数、生成方法、校验和及 Mock 来源。工程重新打开时可从目录记录恢复图件声明和工作副本。

## 图层切换与删除性能

- 参数页判断图件类型只读元数据或已加载图层的字段，不因选中图件加载井点明细。打开井道时才读取完整结果。
- 图层声明按 ID 查询；版本别名和路径索引随 catalog 修订号、内存变更序号失效。图件列表共用缓存，父子版本关系一次建立；声明变化和工程重绑会清缓存。
- 页面刷新合并到事件队列，隐藏页延迟到显示时刷新。已实例化图层不因“显示 / 定位”重复重建分类样式；批量可见性和删除期间暂停地图重绘，结束后统一刷新。
- 删除按资产反向谱系遍历关联图件，图层清单一次事务删除，QGIS 实例一次批量移出；仍先校验编辑状态，catalog 提交失败恢复声明。
- 目录记录成功删除后，使用路径和保留版本的值快照在后台清理受管文件及草稿目录。后台不访问 QGIS 或活 catalog；沿用目录文件回收锁，清理期间避免新版本引用待删路径，图层查看仍可用。未能移除的文件通过错误信号报告。工程视图仍在主线程保存。
- 此次只编译 `paleo`，尚未测量实际工程的切换与删除耗时。

## 服务扩展

`RemotePredictionService` 是可替换的 QObject 服务接口，输入冻结层位、源版本、井集合、网格和相分类。服务返回结果时再次验证请求标识、层位、网格大小、相编码和井集合；取消、切换工程后旧响应不能写入新工程。真实远端接入应实现该接口，并保留请求 / 完成 / 失败 / 进度 / 取消语义。

为保留局部测网的具名工程基准，生成 GeoTIFF 同时在文件内部保存 `PALEO_CRS_WKT` 元数据；QGIS 封装、等值线生成与参考画布恢复此定义，不依赖外置坐标系辅助文件。

## 测井预测相与修订

- 编图测井预测在提交前将曲线、岩性及分层裁至当前地层的 [顶深, 底深) 范围，每口井只匹配一个模型、提交一次。当前地层外的缺口或无效曲线不参与本次校验。
- 远端返回的分段仅用于内部统计：取地层内累计厚度最大的类别作为最终“预测相”。地图每井一个点；井道只画当前地层的一列预测相；右侧表格只有一行顶深、底深和预测相。旧图件打开井道时也使用这一显示规则。
- 新测井图件的 `facies_intervals`、`predicted_intervals` 只含当前地层的一条最终类别记录，移除分段构成和重复的统计相字段。`predicted_facies` 保存最终预测相，`facies_code` 保存编码；范围为 `formation_top/base`，来源版本、服务模型、任务标识及实际观测覆盖率仍保留。分类快照保留修订可用的类别，图例只显示井点实际使用的最终类别。
- 单井缺少曲线、分层、井段有深度缺口、远端失败或结果未覆盖当前地层时跳过并继续；结果保留该井点，预测相及编码为 NULL，状态“未预测”，记录原因。工区该井该地层的旧预测值清空，保留岩性及人工维护信息。模型列表或服务配置获取失败终止整批；取消也终止。
- 任务中心及页面进度显示读取曲线、等待服务、写图件等阶段；完成时进度为 100%，列出成功和未预测井数。
- 每井每地层的最终预测相同步工区共用的井段与地层属性表，仅更新当前地层。维护表保留统计列及人工维护值的存储契约，见 `docs/WELL_VECTOR_ATTRIBUTES.md`。
- “查看井道 / 修订预测相”打开当前地层范围内的源 LAS 曲线与最终预测相。修订直接修改该井该地层的单一类别；首次修订保留不可变原件，创建修订副本，支持撤销和保存修订版本。
- 测井点的标注和图例始终使用最终类别，不随比例尺切换相／亚相／微相。原版 QGIS 属性表默认展示一列“预测相”，隐藏井段 JSON、重复层级名称及历史统计相字段；历史源文件保持不可变。
