# 层位编图工作台

在「智能预测 / 单因素图 / 智能编图」右栏选择「编图流程」。智能预测/智能编图的原处理算法、厚度链、发布与 PDF 工具保留在「高级工具」；单因素的提取、约束与插值方法直接位于默认「编图流程」，旁页「图件与版本」保留图件历史操作。先打开工程，再选择画布上方的编图层位；尚无栅格的层位也可选择并开始预测。

## 1. 智能预测

- 地震解释层位在「数据管理 → 地震 → 层位」浏览；导入后保留原始 DAT，并登记对应层位及时间栅格。层位窗聚类可直接使用原始文件中的 Inline、Crossline 和时间，也可在「层位文件」选择工程外的 SMI DAT。
- 地震预测选择一个已导入、关联工区角点的地震体；生成带空间范围的 GeoTIFF 相栅格。
- 测井预测勾选一口或多口已有有效井位和测井文件的井；生成包含井标识、层位、相编码的预测点图件。
- 本次交付使用异步 Mock 服务，界面、图件及后续派生版本保留 Mock 标记。它验证操作和文件链路，不代表真实地质推理。
- 完成后自动在当前层位显示新结果；若任务期间切换了层位，结果仍保存到提交时的层位。
- 在结果表选中相栅格，点击「相栅格转相面」。连续单因素栅格需先设置分相阈值。

## 2. 单因素图

1. 勾选一个因子，在「井点因子」选择**直读字段**或**比值（分子 ÷ 分母）**。下拉只列工程真实数值字段；有主分层与解释岩性/岩屑段时，还列「分层层厚（MD，m）」和「解释砂岩厚度（MD，m）」。选择砂厚作分子、层厚作分母得到同层段砂地比；井段按当前编图层位及其下一底界裁剪，重叠砂段合并。缺层界、覆盖不足、冲突解释、零分母和缺井位在结果表逐井记因，不猜测井值，不把其他数值字段冒充选定因子。孔渗目前直读已有属性；净毛比需另定有效层判据。
2. 点击「提取井点因子」，查看各井因子值与来源/缺失原因。有效井点保存为工程 DERIVED 点图层；改变层位或口径会清空旧预览，生成图时按当次口径重新提取，并把该不可变点版本作为插值输入。原始井资料保持不变。地层厚度的整面引擎继续通过顶/底构造面相减，井段 MD 层厚用于独立核对。
3. 绘制两族约束线。**方向线族**选择方向引导、解释软边界或制图绕行；**打断线族**选择硬屏障或等值停止，并选择完全阻断/仅显示停线/不阻断。两族的类型及新线参数直接保存；已绘线的参数修改需在次级「编辑已绘约束 / 其他形状」面选线并保存。多边形、矩形、点、圆与椭圆等通用绘制仍在该次级面。
4. 选择**成图方法**，读取常驻说明并设置当前方法参数。结构 IDW 使用成图边界与格网分辨率；局部 IDW 有幂次、支撑邻域、井群权重；Surfer IDW 有幂次与全局各向异性；两种 Kriging 显示模型、块金、拱高、变程、方位和邻域，SGS 另列实现数、种子及集合保留；旧 IDW 显示无可调参数。方向比值/影响半径是逐线参数，仅方向 IDW 族使用；局部 Kriging 的方向/软边界权重不参与求解并列入 issues，地统 Kriging/SGS 不消费逐线屏障参数。Ribbon「插值计算」按钮显示所选方法，并触发同一生成入口。
5. 点击「生成单因素图」，完成后设置等值线间距提线。真实数值等值线来自分析场；「解释性绕行」来自独立制图工作场，不能用于定量融合/分相/统计。砂地比等无长度量纲因子的间距不显示 m。原始井字段 IDW 的兼容入口单独收起；成图方法中的旧 IDW 同样经过本次井点提取。

井点因子、约束、栅格和等值线均登记工程版本与父输入。色带继续遵守因子语义配色；等值线采用墨/白双描边和 JetBrains Mono 数字，`level`/`ELEV` 均带沿线白 halo 注记。注记密度与线宽统一在 `FactorStyleWriter`，详见 DESIGN.md「单因素地图符号」。明暗主题使用同一地图符号，图层名称始终区分数值分析与解释性产物。

## 3. 智能编图与人工编辑

- 自动编图：勾选当前层位输入，用上下移按钮调整优先级。第一个有效相值优先；预测相点使用类别最近邻。连续单因素使用按相类别顺序填写的 N−1 个递增阈值（例如三类相填写 `10,25`）。不同量纲单因素应分别分相后再组合。输出综合相栅格与相面，保留输入顺序与阈值。
- 已有相图：选择矢量相图，点击「复制底图并编辑」。QGIS 原生要素、顶点、撤销、属性编辑作用于独立工作副本。
- 保存编辑：画布「保存编辑」提交成功后自动生成图件新版本；也可在工作副本选中状态使用「保存图件新版本」。原预测和历史版本保持只读。
- 多窗参考：选中图件后点击「打开参考窗口」。每次打开一个独立画布，可平移缩放；切换主图层位后参考窗保留原图。要参考其他层位，先切到该层位打开参考窗，再回主图。

## 图例与文件追踪

相分类（编码、名称、颜色）按层位单独保存。未配置时提供明确标记的 Mock 分类。图件保存生成时的分类快照，因此后来修改当前分类不会重解释历史图件。

主画布前景显示左上指北针、左下比例尺、右上层位相图例。连续单因素显示数值色带图例，约束与等值线不套用相类别图例。选中历史图件时显示其版本相分类。参考画布使用自己的图件分类。

文件链以 `artifacts/metadata/catalog.json` 为主：

```text
源文件版本 + 层位相分类版本
  → 预测栅格 / 预测井点
    → 综合相栅格（输入顺序、阈值）
      → 相面
        → 人工工作副本 → 编辑快照 v1 → 编辑快照 v2
约束源 → 约束快照 + 样点快照 → 单因素栅格 → 等值线
```

不可变结果在 `artifacts/derived/<asset>/<version>/`，人工工作副本在 `artifacts/working/<draft>/`。每个派生版本记录父版本、层位、参数、生成方法、校验和及 Mock 来源。工程重新打开时可从目录记录恢复图件声明和工作副本。

## 服务扩展

`RemotePredictionService` 是可替换的 QObject 服务接口，输入冻结层位、源版本、井集合、网格和相分类。服务返回结果时再次验证请求标识、层位、网格大小、相编码和井集合；取消、切换工程后旧响应不能写入新工程。真实远端接入应实现该接口，并保留请求 / 完成 / 失败 / 进度 / 取消语义。

为保留局部测网的具名工程基准，生成 GeoTIFF 同时在文件内部保存 `PALEO_CRS_WKT` 元数据；QGIS 封装、等值线生成与参考画布恢复此定义，不依赖外置坐标系辅助文件。

## 测井相井道修订与纹理（本次扩展）

- 测井预测完成后自动打开底部「测井相预测与修订」面板，也可在结果表选中测井相图件，点击「查看井道 / 修订测井相」。批量结果通过井下拉框切换。
- 左侧显示源版本 LAS 曲线与单一预测相道（井道图式样：相／亚相／微相三栏、微相地质纹理填充）；右侧显示顶／底深与类别。预测仍为 Mock：按测井深度范围产生 12 个模拟井段，不作真实地质推理；源曲线无法读取时明确标注模拟深度 0–120 m，不伪造实测曲线。
- 地图相点按井段累计厚度最大的类别显示（等厚时采用较小编码），并在 QGIS 画布上以白底胶囊标注类别名称（`facies_label`）。
- 点击井道或表格选中井段，从相列表选择类别直接应用修订：预测原件不可变，首次修订自动创建修订副本并切换到副本。井段修改可撤销，点击「保存修订版本」同时保存图件文件和派生版本。原始预测井段单独保留。
- 地图编辑副本提供相选择列表，可一次修改选中的多个要素。右键已有相要素可直接选择新相；若图件为只读预测／历史版本，会先创建副本。对测井相点整体改相会同步修改该井全部修订井段，保留原始预测。
- 相矢量和测井相点包含 `facies_code`、`facies_name`（相）、`subfacies`（亚相）、`microfacies`（微相）、`facies_label`（类别名称）、`texture`。测井相点额外保存 `facies_intervals`、`predicted_intervals` 和 `log_version_id`，随同一图件文件与版本保存。属性表直接改编码时，保存前同步名称和井段；未知编码及空类别仍按「其他 / 未分类」渲染。
- 层位分类表可从随应用打包的纹理库选择符号，并编辑相／亚相／微相。库中未给出的层级名称保留为空，不根据纹理臆造。新工程默认分类来自库内的河流相、三角洲相、湖泊相；历史图件继续使用其版本保存的分类。
- 转相面、编辑副本、综合编图和独立参考窗口共用相属性与纹理渲染。原始 SVG 库位于 `resources/geology/`，工程仅记录库内相对路径，可随程序迁移。
