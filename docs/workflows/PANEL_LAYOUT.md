# 面板与布局

数据管理页的「数据列表」「数据属性」与编图页的图层、参数、底部面板均为原生停靠窗口。主窗口右上角的「布局」菜单统一提供面板显隐、浮动、四边停靠、自适应布局、保存当前布局、恢复保存的布局和恢复默认布局。图件设计器在「设置 → 布局与面板」提供相同操作，布局快照与主窗口分开保存。

拖动面板标题栏时，主窗口四边出现带方向文字的停靠目标。指针进入目标后，高亮目标并显示预览，松开后停靠到对应边。目标以外的区域继续使用 Qt 原生分割和标签式停靠；按住 Ctrl 可避开四边目标，按 Esc 取消当前提示。双击标题栏切换浮动与停靠，也可通过菜单用键盘完成操作。

层位等地图预览中的「图层 / 识别 / 剖面」和「统计与分析」同样可停靠、浮动和调节尺寸，可在「布局 → 当前预览面板」统一管理。浮动的预览面板随所属预览标签隐藏和恢复。

数据列表默认只显示搜索行；「选项」展开类型筛选、视图、排序和标签等工具。层位的网格信息、版本选择与「在地图上显示」集中在右侧数据属性区，中央直接显示可视化内容。

拖动面板边缘或面板间的分隔条可调整尺寸。中央 QGIS 画布和测井预览使用面板调整后剩余的空间；长工具栏独立横向滚动，不再限制侧栏拉宽。内容超出可用区域时出现横向或纵向滚动条；切换参数页、增加表格行和异步刷新内容不会根据内容尺寸重新调整面板。浮动窗口不随主窗口缩放。停靠面板的可用区域由 Qt 主窗口布局约束，在主窗口缩放、增加或移除停靠面板时重新分配。

「自适应布局」是用户主动执行的一次调整，不会在切页、选择数据或内容刷新时自动运行。「恢复默认布局」会将浮动面板收回，并隐藏默认未打开的附加面板。主窗口退出时仍沿用已有的窗口位置、尺寸和停靠状态保存机制。

实现：`src/ui/paleodockmanager.{h,cpp}`。统一管理器只处理视图布局；稳定尺寸提示的滚动容器隔离内容尺寸与停靠尺寸。新增面板通过 `PaleoMainWindow::addDockWidget` 注册，图件设计器通过其 `addDockWidget` 注册；持久化的面板必须提供稳定且唯一的 `objectName`。

验证：`tst_dockmanager` 覆盖拖动目标、内容溢出、页切换、手动尺寸、浮动尺寸、布局恢复与延迟创建的面板；`tst_ui` 用真实 LAS 预览及主 QGIS 画布检查左右/底部面板调整；`tst_previewmap_assets` 检查预览侧栏、统计区、浮动显隐和属性区版本切换。`tst_layoutshell`、`tst_layoutdesigner_full` 和 `tst_uxtheme` 覆盖壳集成。
