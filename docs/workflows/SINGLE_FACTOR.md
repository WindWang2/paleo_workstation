# 单因素图：数据到编图证据

单因素页按 **输入 → 处理 → 输出（IPO）** 三段组织（反馈 #19）。页首步骤条
`factorIpoStepper` 以 ✓/▶/○ 标出当前阶段，底部固定操作栏始终给出下一步：

- **① 输入**：层位、因素、井点数据（取值方式 + 提取）。技术字段映射与逐井
  明细默认收起。
- **② 处理**：成图方法与必需参数（默认值即可直接生成）。高级插值参数、
  **可选的断层/边界/方向约束**（`factorConstraintsOptionalSection`）默认收起；
  当约束门控需要补齐时，「添加约束」按钮自动展开并定位；本层位已有约束的旧工程
  首次刷新时自动展开，避免已绘约束不可见。
- **③ 输出**：生成后可选提取等值线，成果版本支持显示预览、追溯来源、
  到编图中引用（发布）。末尾「更多工具」折叠段收纳兜底工具：原始字段 IDW、
  厚度样本、不确定性集合。

**一键默认路径**：选层位 → 选因素 →「提取并生成」。它依次触发「提取并保存井点
数据」与「生成单因素图」两个原按钮，进度条标注「一键 1/2 / 2/2」；任一步失败、
取消或被约束门控（#606）拒绝时立即停下，状态行写明「一键成图已停止：原因」。
逐步按钮保留，可分步执行。

**Ribbon**：单因素图页为「输入（参数面板、提取井点）/ 处理（提取并生成、生成单因素图、
绘制约束、方向线族、打断线族）/ 输出（提取等值线、送交验证）/ 要素编辑 / 更多」。
「更多」菜单收纳连井剖面、井震剖面、地图导航、相图显示、捕捉与撤销。
各段内部的细节依次为：

1. **获取当前地层数据**（见下条）与**可选的约束线**相互独立：井点提取是输入
   准备，不要求先绘制任何约束线。间隔线沿用 `break_line / hard_barrier`
   语义，方向线沿用 `direction_line / direction_guide`。SHP、GeoJSON、GPKG
   需使用工程局部米制坐标；导入源副本与约束快照均登记为工程资产。
   约束就绪由 `assessConstraintReadiness(ConstraintUsePlan)` 单一判定，分五态：
   无约束可运行 / 当前方法使用 / 有约束但当前方法未使用 / 仅无效约束（不参与）
   / 当前方法会因约束参数越界整次拒绝（唯一阻止生成的状态）。地统计
   （克里金、SGS、协克里金）不读逐线约束，界面明确提示“未使用”。
2. **获取当前地层数据**。选择砂层厚度、砂地比或其他指标的真实字段，
   或选择分子/分母。解释砂厚只统计当前地层顶底 MD 范围内的解释岩性；
   砂地比用同一层段的砂厚除以层厚（0–1）。缺失分层、解释覆盖不足、
   字段缺失、零分母、坐标缺失等按井列明原因，缺失井不参与插值。
   属性维护、数据提取在后台任务运行，提取结果为不可变井点 GPKG 版本。
3. **生成单因素图（等值面）与等值线**。使用现有方法与参数；先生成单因素图（保存等值面），
   再从该分析场计算并保存数值等值线。井点插值复用步骤 2 的确切版本，
   不再次提取；计算前冻结当前约束版本。非结构格网沿用 400 万像元上限。
   地层厚度保持已有顶底构造面等厚算法，要求选择不同的顶、底面。
   解释性绕行等值线仍独立标明，不能用于连续融合、分相或厚度统计。
4. **保存成果与编图引用**。成果列表显示当前地层、当前指标的井点、等值面
   和等值线版本。文件缺失不会显示为可用成果；保留具体版本及其输入父版本，
   支持显示、数据图谱追溯以及在编图的解释证据来源中引用。
   改动输入不覆盖旧成果，重新计算形成新版本。重开工程可以复用仍有效的井点版本。

## 后台与发布

- 活 QGIS 井点/属性表在所属线程捕获，目录采用 `createStagingCopy` COW 快照。
- 分层、岩性读取与厚度/比值计算在 worker；井点 GPKG 写出、指纹计算在 worker。
- 约束导入的文件快照、解析与指纹计算在 worker；目录写入、约束编辑和图层声明
  在 owner 线程发布，批量导入合并视图通知。
- 页面进度与任务中心共享同一任务。输入控件在任务期间锁定，支持取消；工程、
  会话、目录版本或发布代次变化时丢弃过期结果。
- 结果文件和目录成功提交后才进入“已保存”状态。既有无任务服务调用保留同步入口。

本模块不接入独立的地层对比 Web 工作台。
