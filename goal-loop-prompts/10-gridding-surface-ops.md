# Goal Loop — goal/gridding-surface-ops：网格化算法与面运算（功能深化）

你接手一个自治迭代循环。方向：**网格化与面运算能力加深**——在既有散点→栅格
基建上补主流网格化算法选项、栅格代数（面与面运算）、等厚/体积量算。属功能
深化+新功能混合，数据层断言面厚。

## 背景事实

- 既有面：`src/io/horizonbinner.*`（散点收栅格，Grid_size 上界问题已在审计
  口径记档——先核实现状）、约束 IDW（wave 早前落地，`welldist`/`distancetransform`
  有距离场基建）、约束线差分/绕障距离引擎在 PR #64 已上 master。
- 栅格分析：`src/qgis/previewrasteranalysis.*`（统计/拉伸/直方图/剖面/极值）。
- 真机层位数据：8 层位散点可实测；合成夹具做法看 `tst_segy_fixture`/
  `tests/` 现有夹具风格。

## 范围（建议子项，按需取舍/排序）

1. **网格化算法选项**（`src/algorithms/` 纯数据层）：
   - 最小张力/最小曲率面（迭代松弛求解）或克里金-lite（实验变异函数 + 
     普通克里金）——先勘察取舍，二者其一做到数值可信；
   - 统一接口：散点集 + 网格参数 + 约束线/断层屏障 → 栅格输出 + 质量标记。
2. **栅格代数**：面-面/面-常数运算核（加减乘除、min/max、条件表达式），
   null 传播语义钉死；典型用法：等厚图 = 下层位 − 上层位。
3. **体积量算**：层位面对之间的体积/面积统计（等厚积分、给定基准面上方
   体积），结果进报告面板/可导出。
4. **质量面**：网格化不确定性输出（距数据点距离加权空白度/交叉验证残差），
   QC 用例：留一法交叉验证数值断言。
5. **UI 挂点**：层位右键「网格化…」参数表（算法选择/网格尺寸/约束源）→
   任务服务异步执行 → 结果图层上图；面运算入口走栅格面板。

## Oracle

1. 新算法 ≥1 落地：合成曲面（解析面：平面/二次面/正弦面）采样散点 → 
   网格化结果与真值 RMS 误差断言；留一法 CV 用例。
2. 栅格代数 ≥5 用例（含 null 传播与零除）；等厚图端到端用例。
3. 体积量算解析断言：规则几何面（楔形/锥形已知体积）≥2 用例。
4. 网格尺寸上界护栏：超规模参数拒绝而非 OOM（审计 #33 同类防御断言）。
5. 任务可取消、进度单调；分层绿（`--strict`）；ctest 全绿；ledger；
   push + `gh pr create`。
6. 真机 8 层位网格化实测耗时入 docs/progress。

## 禁区

- 不改屏障/约束线引擎契约（作为输入消费）。
- 不引重量级数值库；克里金若做，限普通克里金小球形/指数模型——泛克里金/
  协克里金出范围。
- 栅格坐标系/旋转测网语义必须如实处理或如实拒绝，禁静默剪切（审计口径）。

## 迭代协议

- 轮0-1：勘察散点→栅格现状 + 算法选型 → 定型入 ledger。
- 中段：算法核→代数核→量算→质量面→UI 挂点，每件一轮。
- 完成定义 = Oracle 6 条全绿，ledger 轮次齐全。

## 交付协议（必守）

1. **新建 worktree 分支开发**：`git worktree add .worktrees/gridding-ops -b goal/gridding-surface-ops-<日期>`

2. **完成后先仔细 review 再开 PR**——逐条执行，全部通过才准推送：
   - `git diff origin/master...HEAD` 自审全部改动：删掉调试残留、printf、注释掉的死代码；
     每个文件头三行层标记在；分层 `tools/check_layering.py --strict` 绿；
   - 全量构建无新警告；ctest 全绿（含新增测试）；
   - Oracle 每条在 ledger 里有对应验证证据（命令+输出摘要），不是「应该没问题」；
   - review 发现的问题先修再验，直到干净为止。
3. 推送 + `gh pr create`（标题 conventional，body 写 `## Summary`/`#### Test plan`/
   自审结论清单）。
