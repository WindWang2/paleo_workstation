# Geological symbol library

Copied from the user-provided `paleo_project/main/svg_output` library on 2026-09-29.
The original SVGs, catalog and descriptions are preserved. Runtime resources are
bundled at `:/geology/`; project metadata stores relative paths such as
`strata/strat_fluvial.svg`, never a developer-machine path.

`catalog.json` supplies symbol labels and colors. Classification names, facies,
subfacies and microfacies remain horizon-specific project data. A texture is a
visual symbol and does not itself assert a geological classification hierarchy.
